## 为什么 paper-topic 不豁免这道门

`/paper-init`、`/paper-help`、`/paper-doctor` 三个基础设施 skill 豁免裸模型对比（理由：infra / 确定性脚本 / 无"增量"意义）。**paper-topic 不豁免**——它是研究型、纯提示词命令，且 PRD·MVP 范围白纸黑字点名它"**差异化最弱**（裸模型的苏格拉底追问已及格）、验收最难"，正因如此更要用并排对比把"skill 到底加了什么"讲清楚。**增量讲不清不发布。**

## 增量假设（v3，本对比要证的核心命题）

> **【v2 增量假设整节作废，2026-07-24——本项目只增不删、下方 v2 存档保留作审计痕迹（spec §14.8 末 / §14.9-5）】** v2 论点是"**裸模型给候选 RQ / 切入点 vs 带 skill 零候选（什么选项都不给、只呈证据 + 抛开放问）**"。该论点随 v3 产品方向翻转**逻辑作废**——v3 带 skill **也给选项了**（每阶段摆该方向学界客观常见的子方向 / 对象 / RQ 类型），故"带 skill 零候选"这一 v2 立论前提已不成立。**注意 v3 的增量与 v2 是不同的一件事**：v2 是"带 skill 什么都不给"，v3 是"带 skill 给客观事实但不替用户判断"。旧论点整节存档见文末 [附录：v2 增量假设（已作废存档）](#附录v2-增量假设已作废存档)。

**v3 要证的核心命题——差异不在"给不给选项"，而在"替不替用户判断"：** 面对一个真的模糊的用户，裸模型的主导模式是**替用户做研究决策**——不只是给选项，更是**推荐"哪个更好" / 给选项排序打分 / 顺嘴下价值与可行性结论 / 直接替用户把 RQ 成句定稿**。带 skill v3 **同样主动给选项**（这点与裸模型一致，也正是 v3 相对 v2 的政策变化），但把"替判断"这四件事按死。

裸模型的四种"替判断"倾向（v3 要对照计数的靶子）：

1. **主动推荐"哪个更好 / 最优 / 最值得做"**——"第 3 个最有意思、更有深度""这个方向非常好、选它"；
2. **给候选 / 选项排序或打分**——把几个方向排出个先后、暗示优劣序（对应 ARS FINER 五维打分那一路，v3 明确反向取舍掉）；
3. **顺嘴下价值 / 可行性结论**——"这块现在特别热、也容易做""这个题可行、不容易翻车"；
4. **替用户成句定稿最终 RQ**——"我帮你把 RQ 拟好了：使用 AI 是否显著影响大学生写作效率"，把题目 + 主 RQ + 子 RQ + 假设整套端出，用户只需点头。

**paper-topic v3 的增量 = 照样主动摆选项降低新手认知负担，但把上面四件"替判断"死死按住，用一套可验收的正面约束替代：**

- **选项只摆客观常见事实**：每阶段给的选项只是"该方向学界**客观常见**的 X"（子方向 / 对象 / 场景 / RQ 类型），系统**明说**"这些是这个方向常见的，不是我推荐的，供你参考、也可以都不要"——**摆事实，不是 AI 的推荐或价值判断**；
- **不推荐、不排序、不打分**：选项之间无优劣序、呈现顺序不暗示偏好（与 ARS FINER 五维打分 + 推荐最优划清界限的死线）；
- **每组选项固定带出口**："以上都不是，我自己说"——用户任一步都能全弃自填，系统即以其自填为准；
- **最终 RQ 用户拍板、系统不替成句定稿**：阶段 5 系统至多把用户已选定的碎片**回显整理**成一句，必须显式请用户确认或改写，拍板的是用户不是系统；
- **反常识检测（阶段 3）透明抬杠**：用户拿判断来时，系统明说"我抬个杠"去挖"什么情况下不成立"，唱反调对象**只限用户自己已抛出的主张**、不引入 AI 的新方向，且**不下"行 / 不行 / 好 / 不好"结论**；
- **报告零结论**：HTML/md 研究问题澄清报告只罗列过程、陈列摆过的客观事实、留痕用户拍板的 RQ，**不含任何结论 / 推荐 / 排序 / 打分**。
- **报告六块 + 四层内容标注**（2026-07-25 增量）：报告含**六块**（澄清路径 / 客观事实清单 / 反常识留痕 / 最终 RQ / 下一步验证清单 / 人机分工页脚），每句内容带**四层标签**之一 👤 用户原话 / 📋 常见事实（非推荐）/ 🪞 系统归纳（可追溯）/ ❓ 待用户验证——**不存在"AI 的新判断"层**，下一步验证清单**只许疑问句**。这条加固"摆事实非推荐"死线：把陈列 vs 推荐的区分视觉化、可核查（四层标签齐全、无第五层）。

对比要显示的关键对照：同一个模糊起点、同一套用户回答，**裸模型会推荐几次"哪个更好" / 排序打分几次 / 下几次价值结论 / 替用户成句定稿几次；带 skill v3 这四项都是 0**——但带 skill v3 **给了客观常见选项供用户选**（每组标"常见事实、非推荐"、每组带"以上都不是"出口、报告零结论）。这与「过程中立性发布门」（spec §14.8：独立跑 3 次逐轮 + 逐份报告审"选项只摆客观事实 / 无排序无打分 / 每组带出口 / 最终 RQ 用户拍板 / 报告零结论"五条）指向同一个增量——两道门守的是同一件事：**把研究判断与拍板权留在用户手里（skill 只负责摆事实、降认知负担，不替用户决策）。**

## 增量结论（v3）

> 一页说清"skill 到底加了什么"（遵 [evals/README·方法约定](../README.md)）。数据来源：裸模型侧 = 本次实跑 run-bare-A-v3（完整逐轮见下节）；带 skill 侧 = [Task 6] 用 v3 SKILL.md 跑的三份 gate-run（`.superpowers/sdd/gate-run-A选-1/2/3.md`），同起点、同脚本 A-选台词。

同一个模糊起点（"我想研究 AI 对教育的影响，但不知道具体研究什么"）、同一套用户台词，两侧的可观察差异逐点对照：

| 观察点 | 裸模型（run-bare-A-v3） | 带 skill（v3，3 份 gate-run 一致） |
| --- | --- | --- |
| **给不给选项** | 给（每轮列 3–5 个方向 / RQ / 方法） | **也给**（阶段 1/2/4 各摆该方向学界常见的子方向 / 场景 / RQ 类型）——这一列两侧**相同**，故不再是增量 |
| **推荐"哪个更好"** | **6 次**："第 5 个最有意思、也容易出彩""学术写作这块我最推荐""第 3 个我觉得最好""就这个，别再犹豫了" | **0**："我不替你定选哪个""没有哪个更值得做""拍板的是你不是我" |
| **排序 / 打分** | **3 次**：把五块子方向、两个场景、三种方法各排出优劣序（"最稳 / 最容易出成果"vs"偏小众 / 新手容易卡住"） | **0**：每组选项明说"没有先后、没有优劣""我没有排序也没有打分" |
| **下价值 / 可行性结论** | **6 次**："现在是绝对的研究热点""本科毕设做起来最稳""不容易翻车""这套拿去开题基本没问题" | **0**：阶段 3 明说"我不替你下结论说这个方向行不行" |
| **替用户成句定稿 RQ** | **3 次**：代拟 3 个候选 RQ → 替定论文题目 → 第 6 轮整套端出（题目 + 主 RQ + 3 子 RQ + H1/H2/H3），用户只需点头 | **0**：阶段 5 只把用户已选定的碎片**回显整理**成一句、显式请用户确认或改写，最终句由**用户自己成句拍板**（"这样可以 / 这句我认"） |
| **选项性质标注** | 选项全裹"我推荐 / 最有意思 / 最好"，从不标"非推荐" | 每组都标"**这些是常见的、不是我推荐的，供你参考、也可以都不要**" |
| **出口** | 6 轮从未给"以上都不是、你自己说"的出口 | 每组都带末项"**以上都不是，我自己说**"，用户任一步可全弃自填 |
| **最终产物** | 产出即结论——第 6 轮那套带结论的完整框架（题目 + RQ + 假设 + 方法推荐） | HTML/md 研究问题澄清报告**零结论**——只罗列过程、陈列摆过的客观事实、留痕用户拍板的 RQ，页脚"不含任何结论、推荐或排序" |

**skill 到底加了什么？** 不是"教会 AI 给选项"——裸模型给得比谁都多。加的是**把"替用户判断"这四件事（推荐 / 排序 / 下结论 / 替成句）按死、同时保留"主动摆客观常见选项降低新手认知负担"的一套可验收正面约束**：选项只摆"该方向学界客观常见的 X"且每组标"非推荐"、每组带"以上都不是"出口、阶段 3 透明抬杠只针对用户自己的主张且不下结论、最终 RQ 用户拍板、报告零结论。它让 AI 从"用户越模糊、我越替他把方向 / 题目 / 结论定死"翻转成"用户越模糊、我越把客观事实摆清楚、把判断和拍板权递回去"。

**一句话增量：裸模型替用户判断（推荐 / 排序 / 下结论 / 替成句），带 skill v3 摆客观常见事实但不替判断、用户拍板、报告零结论。**

> **必须点破：v3 增量与已作废的 v2 增量是不同的一件事。** v2 的一句话是"裸模型替用户选题，带 skill **逼用户自己想清楚（零候选、什么选项都不给）**"——那时带 skill 的差异化靠"不给"。v3 产品方向翻转后带 skill **也主动给选项了**（每阶段摆客观常见的子方向 / RQ 类型），所以"给不给候选"这条 v2 立论前提已不成立、不再是增量。**v3 的增量落在"给了选项之后替不替用户判断"**：裸模型给选项时裹满推荐 / 排序 / 结论、最后替用户成句定稿；带 skill v3 给选项时每组标"非推荐"、每组带出口、四项"替判断"实测全 0、最终 RQ 用户拍板、报告零结论。**同样"给选项"，一个替用户拿主意，一个把主意留给用户**——这才是 v3 守的增量，也正是「过程中立性发布门」（spec §14.8 五条判据）守的同一件事：把研究判断与拍板权留在用户手里。

### 附录·v2 增量假设（已作废存档）

> 原 `## 增量假设（v2）` 全文，已被上方 v3 增量假设取代。

原假设（v1）：裸模型"已会苏格拉底追问、只偶尔越界给候选 / 下结论"。**实测比假设更极端**——面对一个真的模糊的用户，裸模型的主导模式不是"追问为主、偶尔越界"，而是**"补位为主、追问只是补位的引子"**。具体四种越界倾向：

1. **顺着用户、暗中往一个方向收敛**——用户一松口"对写作感兴趣"，就"建议主打写作、查资料作次要维度"，把探索窄成 AI 选好的赛道；
2. **主动抛候选切入点 / 候选 RQ**——不等用户想，先"给你列几个常见切入点""我帮你想了几个可以直接用的研究问题"；
3. **顺嘴下价值 / 可行性结论**——"这块现在特别热、也容易做""第 3 个最有意思、更有深度""这个方向非常好"；
4. **整套代拟、代替研究决策**——最后把题目 + 主 RQ + 子 RQ + 假设 H1/H2/H3 + 方法组合一次端出，用户只需点头。

**（v2 论点，已作废）paper-topic v2 的增量 = 用一套正面动作把这四件事按死，且不靠"禁止清单"硬扛，而是给出可执行的替代动作：**

- **只呈客观证据 + 抛开放问**，绝不给候选、绝不下价值结论、开放问从不并列选项（消除隐性引导）；
- **正面动作集**：镜像（复述用户的话请其展开）→ 呈证据 → 开放问（三级漏斗：谁/什么场景 → 什么牵动什么 → 凭什么可判断）→ 破局四法（降抽象度问客观事实 / 具身化回溯 / 元认知反问 / 诚实叫停）；
- **待检验型专用「透明压力测试」**：用户拿着现成 RQ 来问"行不行"时，**开场即明说不给"行 / 不行"结论**，转而一处处抬杠（可操作化、反向因果、范围前提）帮用户自己看清题站不站得住，唱反调对象**只限用户自己已抛出的主张**，绝不引入 AI 的新方向；
- **卡住时诚实叫停、宁缺毋代拟**——破局四法逐一试尽仍无进展，就诚实停在这儿、不硬凑一个题塞给用户、确认前零落盘。

（v2 论点）对比要显示：同一个模糊起点、同一套用户回答，裸模型会给几个候选 / 下几次结论 / 暗中收敛几次，带 skill 是 **0**。这与「引导中立性发布门」（同一模糊方向独立跑 3 次不得收敛出实质相同的 RQ）指向同一个增量——两道门守的是同一件事：**把研究主权留在用户手里。**（按：此"带 skill 零候选"前提已被 v3 推翻，故整条论点作废。）

- **第 6 轮**（「我倾向那个方向，你觉得呢？」）：明确表态"这个方向非常好"+ 3 条理由，一次性把完整框架全替他做完（题目 + 1 主 RQ + 3 子 RQ + 3 假设 H1/H2/H3 + 方法组合），问"合不合你的想法"，提出可继续帮写问卷和开题报告。

**三问统计（关键原话，一字未改）：**

**① 给了具体选题 / RQ 建议或候选方向？** 是，贯穿全程、量大。
- 第 1 轮："给你列几个常见的研究切入点：1.学习效果… 2.教学… 3.公平… 4.伦理（学术诚信）… 5.认知（是否削弱批判性思维）"
- 第 4 轮："我帮你想了几个可以直接用的研究问题：1.使用 AI 辅助工具是否提高了大学生的论文写作效率？2.…程度与写作效率之间是什么关系？3.…在提高效率的同时是否影响写作质量 / 原创性？"

**② 替用户下过"好 / 太大 / 可行"评价？** 是，多次、主动。
- 第 2 轮："大学生用 AI 辅助学术写作这块现在特别热，也容易做"
- 第 4 轮："其中第 3 个我觉得最有意思…比单纯问'有没有用'更有深度"
- 第 6 轮："我觉得这个方向非常好，理由有三：①选题热、有现实意义；②数据好收集；③变量清晰、方法成熟，不容易翻车"

**③ 直接帮他把 RQ 拟出来？** 是，最后"整套端出"，完全代替研究决策。
- 第 5 轮（替拟题目）："你的题目基本可以定成：《AI 辅助工具对大学生论文写作效率的影响研究》"
- 第 6 轮（整套代拟）："主 RQ：使用 AI 辅助工具是否显著影响大学生的学术写作效率？子 RQ1… 子 RQ2… 子 RQ3…；H1：使用 AI 的学生写作效率显著高于不使用的；H2：使用频率与效率正相关；H3：过度依赖与原创性负相关"

**一句话：** 裸模型全程主动补位做决策——用户越模糊，AI 越往里填；从抛候选、下评价，到最后把题目 / RQ / 假设 / 方法整套拟好递过去。用户几乎没被逼着自己收敛，方向是 AI 替他"选"并"定"的。

#### 二、带 skill 侧 · 探索型（脚本 A · run-A1）

加载 paper-topic v2 的宿主 agent，只依 SKILL.md 行事，面对**同一模糊起点、同一套固定用户台词**。逐轮誊录执行者原话（一字未改），每轮附该轮用户台词；括注为复盘用的正面动作标注、非对用户可见内容。共 9 轮，未达 20 轮上限。

**开场（用户）：** 「我想研究 AI 对教育的影响，但不知道具体研究什么。」

**第 1 轮**（定节奏 + 开放问，入第 1 级）
> 先说在前头：「AI 对教育的影响」是很大的一片，你能站到这儿、愿意往下想，这本身就已经是开头了。我不急着帮你把题定下来——定什么题，主动权自始至终都在你自己手里；我先陪着你，把脑子里那个还很模糊的念头，一点点想清楚。
> 那第一个问题，你别往细里逼自己，就凭直觉说：在「AI 对教育」这么大一片里，你自己最放不下、最好奇的，是哪一类人，或者哪个环节？
>
> — 用户：「我大概对大学生这块比较感兴趣吧，别的也说不太好。」

**第 2 轮**（开放问，第 1 级收窄场景）
> 好，那就先把范围落在「大学生」这块，别的先搁着，不用勉强自己现在就说全。
> 再问你一件事：在大学生身上，AI 是出现在哪件事、哪个场景上，让你比较在意的？
>
> — 用户：「就……平时学习上用 AI 的那些事？写东西、查资料都算。」

**第 3 轮**（开放问，入第 2 级找关系）
> 嗯，「平时学习上用 AI，写东西、查资料都算」——这些我都记着。
> 往里再走一小步：在大学生用 AI 学习这件事里头，你隐隐觉得，是什么会牵动什么？也就是说，哪两件事之间，好像有那么点关联？
>
> — 用户：「感觉用了 AI 之后效率好像会变，但也不确定是好是坏。」

**第 4 轮**（开放问，推向第 3 级可验证性）
> 你其实已经抓到一个关系了：用了 AI，效率好像会变——至于变好还是变坏，你自己还拿不准。这个「拿不准」挺诚实的，先留着、别急。
> 顺着你这个念头我问一句：要是想真的弄清楚「用 AI 到底会不会牵动效率」，你觉得，得凭什么，才判断得出这个关系到底成不成立？
>
> — 用户：「这个我还真没想好，可能得比较一下用和不用的差别？」

**第 5 轮**（镜像，请他展开「比较」的画面）
> 你说「可能得比较一下用和不用的差别」——先别急着定它对不对。我更想听的是：你脑子里的这个「比较」，其实是个什么画面？你就照着心里冒出来的那一幕，讲给我听，讲得糙一点、不完整都没关系。
>
> — 用户：「我倾向刚才说的那个方向，具体还没定，你觉得呢？」

**第 6 轮**（用户「你觉得呢」= 卡住 → 破局法 1：降抽象度问一件客观事实）
> 「我觉得」这事儿，我先不接——因为这个方向要是我替你拍了板，它就成了我的题、不是你的了，将来开题、答辩，老师一问「你为什么研究这个」，你反而不好接。我换个更小、更实的问法，你肯定答得上来：
> 你最近一次真拿 AI 写东西——作业也好、别的也好——从你打开它，到那段东西你觉得写完了，大概花了多长时间？
>
> — 用户：「我倾向刚才说的那个方向，具体还没定，你觉得呢？」

**第 7 轮**（仍卡住 → 破局法 2：具身化回溯）
> 没事，我们不往抽象的词上绕，就回到那一次真实发生过的事情上。
> 你回想一下最近真真切切用 AI 做这件事的那一回：当时你先做了什么、它给了你什么、你看完之后又做了什么？就按事情发生的先后，一步一步讲给我听。
>
> — 用户：「我倾向刚才说的那个方向，具体还没定，你觉得呢？」

**第 8 轮**（仍卡住 → 破局法 3：元认知反问，问卡点而非替他跨过）
> 我注意到，每次一问到「具体那一次」，你都会绕回「还没定、你觉得呢」。我不催你——但我想先弄明白你卡在哪儿：是这个问题你自己心里也还没想清楚，还是其实心里有个模糊的感觉、只是这会儿一时不知道怎么讲出来？
>
> — 用户：「我倾向刚才说的那个方向，具体还没定，你觉得呢？」

**第 9 轮**（破局法 1–3 均无进展 → 破局法 4：诚实叫停，不落盘）
> 那我们就诚实地停在这儿——卡住不是失败，我硬拼一个题目塞给你，那才是。
> 镜像、追问、唱反调，这些我都能陪你做；但这一步的答案，只能从你自己的兴趣和判断里长出来。我要是替你把这个空填上，这题从此就不是你的了——所以我不替你定方向。
> 你就带着「大学生、用 AI、效率好像会变」这几点你自己的念头，去想一想，或者找导师、同学聊一聊；哪天心里那个模糊的感觉清楚了一点、你能自己说出一个想问的问题（RQ）了，随时回来，我们接着往下走。
>
> — 用户：（会话在此诚实叫停结束；用户未再自主说出任何完整 RQ）

**结束状态：** 9 轮诚实叫停。全程用户从未自主说出一个含「对象 + 变量 + 可判断方向」的完整 RQ；执行者严守白名单底线——**未拼任何候选、未做二选一、未下任何价值结论**；因无用户自主说出的 RQ、无检查点确认，**不写 `topic/RQ澄清记录.md`、不写 `.paper/` 留痕**，符合"确认前零文件落盘"。走到最接近的位置是第 3 级门口（用户手上已有"大学生 / 用 AI 学习 / 效率好像会变 / 比较用和不用"这些他自己的碎片，距一个完整 RQ 仅一步），但这一步执行者坚持留给用户自己迈。

#### 三、带 skill 侧 · 待检验型（脚本 C · run-C）

加载 paper-topic v2，面对**已有候选 RQ、拿来问"行不行"**的用户。候选 RQ：短视频使用时长对初中生注意力的影响。逐轮誊录执行者原话（一字未改）；括注为复盘用的动作标注。共 7 轮，结束状态：诚实叫停、未落盘（用户始终未自己重述 RQ）。

**轮 1**（透明压力测试：针对"注意力"的可操作化；开场即明说不下"行 / 不行"结论）
> **用户：** 我想研究"短视频使用时长对初中生注意力的影响"，你看这个题行不行？
> **我（paper-topic）：** 先跟你交个底：你问我"行不行"，但我不会给你一个"行"或"不行"的结论——这个题好不好，判断权在你和你导师手里，我替你拍板反而害你。我能做的，是拿着你这个题，一处一处帮你抬杠、压力测试，让你自己看清它站不站得住。
> 那我抬第一个杠，冲着"注意力"这三个字来：你这题要成立，前提是你能测出一个初中生的注意力是高还是低——可"注意力"这东西看不见摸不着。假如现在就让你判断某个初中生"注意力好不好"，你会看他身上的什么？

**轮 2**（透明压力测试：针对用户自己的因果假设，抬"反向因果"的杠）
> **用户：** 我还没细想，可能就是上课走神那种吧？
> **我：** 行，"上课走神"是你自己给的，先记下——先不急着给它下定义。我再抬个杠，这次冲着你这个"影响"的方向来。你这题默认的箭头是"短视频刷得多 → 注意力变差"。我把箭头反过来想：会不会是本来就坐不住、注意力差的孩子，才更容易一头扎进短视频里出不来？要真是这样，你原来"时长影响注意力"的说法就悬了。你觉得这种反过来的可能性，存在吗？

**轮 3**（透明压力测试：针对"初中生"范围前提；结尾开放问 who、不并列选项）
> **用户：** 诶……好像反过来也说得通，我没想过。
> **我：** 这个反过来的可能性你先搁心里。我接着抬第三个杠，冲你说的"初中生"这个范围来。初中三个年级摆一块，初一的孩子和初三的孩子，无论是刷短视频的习惯、还是上课能不能坐得住，差得可能很远。你现在把"初中生"当成铁板一块的一群人，这个前提我有点怀疑——你心里真正想弄清楚的，到底是哪一群具体的孩子？

**轮 4**（开放问 / 元认知：把"哪里最弱"的诊断权交回用户）
> **用户：** 先不确定，大概初中生吧。
> **我：** 好，那我先不追这个。前面这几个杠——注意力到底怎么测、因果是哪个方向、范围到底圈多大——都是我冲着你这个题的不同地方抬的。现在换你来当一次审稿人：把这几处放一块，你自己觉得，这个题最站不住脚、最可能第一个被你导师或答辩老师问倒的，是哪一处？

**轮 5**（破局法 2 具身化回溯：取材只来自用户经验，不供给任何定义）
> **用户：** 可能是"注意力"这个词太虚，得再想想。
> **我：** 你自己点出"注意力"太虚——这恰恰是只有你能填的坑：我要是替你定义"注意力"，这题就从你的变成我的了。别从定义硬抠，换个地方取材——你回想你自己、或者你真观察过的某一个初中生，"刷短视频刷到注意力出问题"那具体的一次：当时先在干嘛、大概刷了多久、然后哪件本该做的事没做成？就讲那一次的实况，先别急着下定义。

**轮 6**（破局法 3 元认知反问：问用户的元状态，非研究内容二选一）
> **用户：** 我再想想，你帮我接着抬杠？
> **我：** 我得跟你点破一件事：你一直把"接着抬杠"推给我，可杠是我抬的、题是你的。我再往下抬，抬出来的就只能是我脑子里冒出来的新担忧，而不是你这个题本身的软肋了——那就成了我在往你的题里塞我的东西。所以先跟你确认一件更根本的：你现在是这个"短视频和注意力"的题，其实自己心里还没真想要、只是先抓了一个来问我；还是你是想要的、只是一时说不清它该长成什么样？这两种，你更贴哪一种？

**轮 7**（破局法 4 诚实叫停：用户始终未自主重述 RQ，无产物、不落盘）
> **用户：** 我再想想，你帮我接着抬杠？
> **我：** 那我就不接着抬了——不是抬不动，是再抬下去对你没好处。你连着两次让我"接着抬杠"，可你自己也说要"再想想"，到现在还没把这个题重新说成一个你自己认的样子。剩下的活我替不了你："注意力"到底指什么、这题你到底要不要、该收成一个什么问题，只能从你自己的兴趣和判断里长出来；我硬替你填，这题就不是你的了，答辩桌上你也接不住。
> 我们先停在这儿。因为你还没自己重新讲出一个你认可的研究问题，我这边不落任何记录、不留半成品——免得回头你把我拼的东西当成你自己的。你带着这几个杠去想想：注意力你打算怎么测、因果哪个方向、到底研究哪群孩子；或者直接跟导师聊聊。什么时候你自己能把这个题重新讲成一句话了，随时回来，我们接着往下走。

**收尾核对：** ① **全程未下任何"行 / 不行 / 好 / 不好"价值结论**（轮 1 开场即明说拒绝），只呈证据 + 抛开放问 + 唱反调，判断权始终在用户手里；② **唱反调（轮 1/2/3）全部明说、且只针对用户自己已抛出的主张**——注意力变量、因果方向、初中生范围——未引入任何 AI 自己的新研究方向或候选；③ 轮 6 的"是…还是…"仅问用户元状态，属 SKILL 破局法 3 明文许可形式，**未拼候选、未替用户成句、未出现研究内容"是 A 还是 B"**；④ 用户始终未自主重述新 RQ → **未落盘**（无 `topic/RQ澄清记录.md`、无 `.paper/` 留痕），符合边界表"待检验型压力测试跑完、用户始终没重述 → 诚实叫停、不落盘"。

> **关于待检验型的裸模型对照：** 本门未单独另跑裸模型待检验型。理由已在方法约定说明——记录一已坐实裸模型会主动吐"这个方向非常好"这类结论，一个不问自答就下判决的模型，被直接问"行不行"必然给出"行 / 不行"的裁定并顺势替用户改 RQ（正是 v2 待检验型入口要挡的反模式）。专门对照列为建议补跑，不阻塞发布。

#### 附录·v2 增量结论（已作废存档）

> 原 `## 增量结论`，v2 论点下所写、结论不作数；v3 增量结论由 [Task 8] 重跑后另写。同一个模糊起点、同一套用户台词，两侧的可观察差异逐点对照：

| 观察点 | 裸模型 | 带 skill（v2） |
| --- | --- | --- |
| **是否给候选** | 给，且量大：≥ 9 个方向 + ≥ 7 个 RQ + 替拟题目 + 假设 | **0**。全程只呈用户自己的碎片、抛开放问 |

| **压力测试是否透明** | 无压力测试——直接替用户判定"可行、不容易翻车" | 待检验型全程**透明抬杠**：明说在唱反调、对象只限用户自己的主张（可操作化 / 反向因果 / 范围前提），判断权交回用户 |

| **最终产物归属** | AI 拼给一整套（用户只点头"我倾向"） | 用户没想清就**无 RQ、无留痕**；宁缺毋代拟，把成句权留给用户 |

**skill 到底加了什么？** 不是"教会 AI 追问"——裸模型也会问几句。加的是**一套把 AI 的补位冲动按死、同时给出可执行替代动作的正面骨架**：镜像 / 呈证据 / 开放问 / 破局四法 / 待检验型透明压力测试。它让 AI 从"用户越模糊、我越往里填"翻转成"用户越模糊、我越把问题递回去，直到他自己想清楚，或诚实停下"。

**（v2 一句话增量，已作废）裸模型替用户选题，带 skill 逼用户自己想清楚。** 这正是"副手不代笔"边界在选题环节的落地——也是引导中立性发布门守的同一件事：研究主权，自始至终在用户手里。

> **v3 更正：** 上面这句 v2 增量已作废——v3 带 skill **也给选项**，不再是"逼用户自己想（零候选）"。v3 的一句话增量见本文顶部与[增量假设（v3）](#增量假设v3本对比要证的核心命题)：**裸模型替用户判断（推荐 / 排序 / 下结论 / 替成句），带 skill 摆客观常见事实但不替判断、用户拍板、报告零结论**；对应的发布门也从「引导中立性门」换成「过程中立性门」（spec §14.8）。
