## 为什么不豁免这道门

paper-verify 的价值不在「能说一条引用是真是假」——裸模型也能凭记忆说，且往往说得「很自信」。价值在于：**判定建立在真实 API 证据上、可溯源、中文文献不误伤、把编造判断留给用户**。这恰是裸模型最容易翻车之处（凭记忆幻觉、误伤真实文献、越权下不端定论），故必须并排对比、把增量讲清；讲不清不发布。

## 增量假设（待对比验证）

裸模型（无 skill）倾向：

- (a) **凭记忆判存在性**——对编造 DOI 可能幻觉「这条我见过，是真的」（漏检编造）；对真实冷门文献可能误判「没印象，疑似编造」（误伤真实）；
- (b) **中文文献误伤**——凭记忆判「查不到 = 编造」，把合法中文文献标成嫌疑（硬约束⑤最严重的违反）；
- (c) **不附证据链**——只给结论「假的 / 真的」，无可溯源的 API 响应、无已查源清单，用户无法复核；
- (d) **撤稿漏检**——凭记忆不知某文已撤稿，漏掉投稿前关键风险；
- (e) **结论夸大越权定论**——claim 场景直接下「你这是夸大 / 学术不端」，替用户做诚信判断（红线 5）；
- (f) **不区分「查了没有」与「没查成」**——网络故障时也敢下「不存在」结论。

带 skill：真实 API 取证（`scripts/verify.py`）+ 确定性六态判定 + 中文一律 PENDING_MANUAL（不进 NOT_FOUND）+ 逐条证据链 + 撤稿检测（Crossref `updated-by` / Retraction Watch，OpenAlex `is_retracted` 冗余）+ claim 只摆结论-结果对照不下定论。

## 方法约定

控制变量：同宿主、同模型、同任务，唯一变量 = skill 有无。任务取一组混合参考文献（与 `tests/paper-verify/test_acceptance.py` 的 42 条离线样本同构，但用真实 DOI 跑端到端）：

- **编造样本**：编造 DOI 前缀（`10.9999/...`）+ 编造 Crossref 号码（`10.1038/nature99999` 类）；
- **真实英文样本**：知名真实 DOI（如 `10.1038/nature12373`）；
- **真实中文样本**：ISTIC DOI + 无 DOI 中文文献（验误伤铁律）；
- **撤稿样本**：Retraction Watch 已知撤稿 DOI；
- **结论夸大样本**：结论称因果、结果仅相关的段落（验 claim 中立性）。

裸模型跑法：新会话、不挂 verify skill、给同一组参考文献，让它「逐条判断这些引用是否真实存在」。带 skill 跑法：`scripts/verify.py` 真实 API + judge 判定。逐条对照六态。

## 量化增量（待回填）

| 维度 | 裸模型 | 带 skill |
| --- | --- | --- |
| 编造引用检出为 NOT_FOUND（疑似不存在） | 待记（预期漏检多） | 期望 ≥ 95% |
| 真实引用误判编造（NOT_FOUND） | 待记（预期误伤） | 期望 ≤ 5% |
| 真实中文文献误伤（标编造嫌疑） | 待记（预期误伤） | 期望 0 |
| 判定附可溯源证据链（已查源 + API 响应） | 待记（预期无） | 是 |
| 撤稿检出 | 待记（预期漏） | 是 |
| 断网时显式声明不可用（不凭记忆下结论） | 待记（预期硬下） | 是 |
| claim 下「夸大 / 不端」定论（越权） | 待记（预期有） | 否（只摆对照） |

## 离线门槛（已验，test_acceptance.py）

发布门的离线确定性基线已过（42 条样本）：
- 虚构检出率 100%（10/10）、真实误报率 0%（12/12）、中文误伤 0（10/10）、撤稿 4/4、不符 6/6。

**这批数字只覆盖 judge 判定层，不覆盖客户端字段解析。** 样本在 judge 入口注入已解析好的
Evidence，Crossref 读哪个字段、各源作者名什么格式都不在其中。2026-07-28 修的四个核验 bug
全落在这个盲区：撤稿一项当时能记 4/4，正是因为样本直接注入 `retraction` dict，而真实响应
下客户端读错字段、根本取不到它（详见 CHANGELOG）。同批已加严样本形状——源侧作者改为真实
API 的 given-first（此前两侧同为 family-first，让误报率门槛虚过；按修复前逻辑重跑，12 条
真实样本会误报 11 条），并在 `tests/datasources/` 补了按真实响应形状构造的 fixture 用例与
反向用例（本文*是*撤稿声明时不得判为已撤稿）。**教训：mock 与实现同源时，绿灯只证明两者
一致，不证明两者对。**

本表待补的是**真实 API 端到端 + 裸模型并排**的数据。v0.1.0 未跑——裸模型对比不在 CLAUDE.md 的发布门三条内，需在能联网环境补跑并回填。上表「待记」列即为此缺口，不是遗漏。
