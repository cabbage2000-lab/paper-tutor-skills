# 学科三梯队（共享权威定义）

| 项 | 内容 |
| --- | --- |
| 类型 | 共享约定权威定义（跨 skill 复用） |
| 范围 | 全部学科敏感的 skill（文献检索、引用核验、方法论辅助、模拟评审、图表、投稿……） |
| 上游 | PRD·学科适配（**PRD 是内部稿、不随仓库发布**，故本文件是分发单元 `skills/` 里的权威副本） |
| 校验 | [`tests/test_shared_conventions.py`](../../../tests/test_shared_conventions.py) |

## 为什么需要这份副本

三梯队源自 PRD·学科适配，被 9 个以上 skill 复用。但 PRD 是内部设计稿、不随仓库发布，于是分发单元里此前没有任何权威定义——各 skill 只能各自复述一遍，复述就会漂移，新 skill 也无处可抄。本文件是那份权威。

## 划分依据（两因素相乘，不是支持/不支持清单）

- **文献基础设施** —— 该学科文献能否被已接入的开放 API 覆盖（arXiv / OpenAlex / Semantic Scholar / Crossref / PubMed / ERIC）。
- **论文形态** —— 实证 / 理论 / 诠释型与方法论模板、论证链检查的匹配度。

学科中立的环节全学科同等可用：选题澄清、写作辅助、GB/T 7714 著录检查、披露留痕。只有**学科敏感**的环节才按梯队分层声明。

## 三档基准

| 梯队 | 覆盖程度 | 学科 | 关键约束 |
| --- | --- | --- | --- |
| **第一梯队** | 全环节适配 | 实验 / 实证型理工农医（计算机、电子信息、化学、材料、生物、农学、医学等）；实证型社科（教育学、心理学、管理学、经济学、定量社会学等） | API 覆盖最好、DOI 普及率高。医学补 PubMed，撤稿检测价值最直接；教育学补 ERIC。涉人类被试的伦理提示清单与涉患者数据的隐私警示已内建 |
| **第二梯队** | 文献环节适配，个别环节按类型调整 | 证明 / 理论型学科（数学、理论物理、理论计算机等）；规范文本依赖重的学科（法学、公共管理、马克思主义理论等） | 理论型：论证链检查只核「RQ—方法—结论」的结构对应，**不核验证明的数学正确性**（超出能力边界，产品语言必须明示）。规范文本型：**法条 / 判例 / 政策文件引用不是学术题录、不进入存在性核验**，单独标「非文献引用、须人工核对」，绝不混入「未查到」 |
| **第三梯队** | 部分环节可用，能力边界首次使用即明示 | 人文学科（文学、历史、哲学、艺术等） | 文献以专著、古籍、档案为主，开放 API 以期刊文献为中心、对专著与古籍覆盖弱 → 存在性核验大比例落 `PENDING_MANUAL`；诠释 / 思辨型论文没有实证式论证链，方法论模板不适用。此梯队 skill 须在**首次使用时主动声明哪些环节降级**，而不是静默给出低质量结果 |

> **梯队是当前文献基础设施的现实描述，不是价值排序。**第三梯队的降级路径（人工核对包、格式检查）仍优于裸模型的凭记忆作答；梯队边界随中文开放数据源等调研结论滚动更新。
>
> 这句话必须传达到用户可见处——丢掉它，第三梯队用户读到的就只是一句「你的学科排第三」。

## 各 skill 的适配轴（有意差异，不要求统一）

三梯队是**基准**。各 skill 按自己关心的维度在基准上适配，适配轴不同是有意设计，不是漂移。新增 skill 时照此填一行。

| skill | 适配轴 | 第一梯队 | 第二梯队 | 第三梯队 | 让路 |
| --- | --- | --- | --- | --- | --- |
| `paper-logic` | 论证链可核性 | 全核 | 核结构、不核证明 | 让路不产 | 有 |
| `paper-screen` | PRISMA 适用性 | 全走（含偏倚评估） | 走台账与流程图、偏倚评估让路 | PRISMA 通常不适用、整体让路 | 有（两种粒度：偏倚整块省略 / 27 项仅个别条目标不适用） |
| `paper-method` | 方法论模板匹配度 | 全核 | 按类型调整、不强套实证模板 | 轻量让路 | 有（**让路不让伦理义务**） |
| `paper-abstract` | 摘要式 | 结构化 | 理论型 | 诠释型 | 无 |
| `paper-proposal` | 研究方法部分写法 | 实证 | 理论 | 诠释 | 无 |
| `paper-review` | 评审维度 | 全维度 | 按类型调整 | 按类型调整 | 无 |
| `paper-revise` | 修订方向 | 补实验 / 统计 | 补推导 / 命题 | 补文本证据 | 无 |
| `paper-figure` | 常见图类 | 柱 / 折 / 箱 / 散 / 误差 / 直方 / 热图（+ 子领域 KM / 森林 / ROC） | 函数曲线 / 推导图 / 交换图（+ 相图 / 概念关系图 / 算法流程图） | 时间线 / 地图 / 谱系图 / 年表 | 无 |
| `paper-plot` | 代码生成范围 | v1.0 P0 覆盖 7 类图 | 部分留 v1.1+（TikZ 等） | 专项留 v1.2+，当前给 Mermaid 轻量替代 | 部分（标明版本计划） |
| `paper-submit` | 期刊生态 | 实证理工（SCI / 英语） | 实证社科（CSSCI） | 人文社科（中文核心、集刊） | 无 |

**「让路」的语义**：该梯队下本 skill 不产出主产物，明确告知原因并指向可用的替代命令——而不是硬产一份不适用的结果。

## 学科判定来源

按优先级：① `project.paper.yaml` 的 `discipline` 字段（由 `/paper-init` 收集）；② 从用户 RQ 形态推断；③ 当轮直接询问。判定结果写进产物元信息，让用户能看到「系统按哪个梯队处理了我的学科」并纠正。
