## 0. 使用方式

### 0.1 两种消费路径

| 路径 | 写法 | 何时用 |
|---|---|---|
| **A. 直接 utility** | 在 HTML 元素上写 `class="max-w-[880px] mx-auto ..."` | 一次性结构、不需复用的版式 |
| **B. 自定义 class** | 在模板 `<style>` 段定义 `.page { @apply ...; }` 或原样 CSS | 多处复用、命名即语义的组件（如 `.tag-inline.t1`） |

**推荐混合用法**：通用骨架（`.page` / `.doc-head` / `.legend` / `h2.section` / `footer`）和语义组件（`.tag-inline.t1-t4` / `.badge.g/y/r`）走路径 B（保留命名）；其他内容直接 utility。

### 0.2 引入方式（每个模板 `<head>` 必备）

```html
<!-- 基础层：所有 12 模板 -->
<script src="https://cdn.tailwindcss.com?plugins=typography"></script>
<script src="../_shared/tailwind.config.js"></script>

<!-- 按需层：仅 paper-review 等图表模板 -->
<script src="https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js"></script>
<script src="../_shared/echarts-theme.js"></script>
```

### 0.3 字体栈与正文排版

正文用 `<article class="prose">` 接管（typography 插件已在 `tailwind.config.js` 里覆盖为衬线宋体 + 墨色正文 + 1.85 行距）；标题用 `class="font-sans"` 切到无衬线黑体。不再手写 `font-family` 与 `line-height`。

### 0.4 命名锚点 class 保留规则

重构时，原有 named class 的处理遵循以下判定：
- **保留为锚点**：brief 列出的专属组件（如 `.path` `.fact-card` `.rebuttal`）——即使 CSS 已转为 utility，class 名保留为语义锚点，方便宿主 agent 和下游读者识别区块结构。
- **删除**：纯视觉性的辅助 class（如 `.rebuttal-item` 只是一个 margin 间距）——没有语义价值、CSS 已被 utility 替代时，直接删除 class 名、用 utility 表达。
- **判定标准**：如果下游 agent 读 HTML 时需要靠这个 class 名识别"这是什么区块"——保留；如果只是视觉样式——删除。

## 2. 页面骨架（全 13 skill 必备）

### 2.1 `.page`

**用途**：880px 居中纸面容器，模拟档案卡视觉。顶部 6px 墨色色带 + 右上角 `page::before` 标签。

**class**：`.page`（必备）

**HTML 骨架**：

```html
<article class="page">
  <header class="doc-head">...</header>
  <section class="legend">...</section>
  <!-- 多个 <section> -->
  <footer>...</footer>
</article>
```

**Tailwind 等价**：

```html
<article class="
  max-w-[880px] mx-auto mt-12 mb-20
  bg-paper relative
  border border-rule border-t-[6px] border-t-ink
  px-16 py-14
  shadow-[0_1px_0_#ece5d6,0_30px_60px_-30px_rgba(60,45,20,0.25)]
">
  <!-- page::before 标签：右上角墨底纸字小条，需在 <style> 段保留 ::before 伪元素
       （content 文案随 skill 变，如 "paper-topic · 选题澄清档案"） -->
</article>
```

**`page::before` 伪元素**（建议各模板 `<style>` 段保留）：

```css
.page::before {
  content: "paper-<skill> · <档案名>";
  position: absolute; top: -6px; right: 0;
  background: theme('colors.ink.DEFAULT'); color: theme('colors.paper');
  font-family: theme('fontFamily.sans').join(', ');
  font-size: 10px; letter-spacing: .14em; text-transform: uppercase;
  padding: 5px 12px 4px; font-weight: 600;
}
```

**出现于**：全部 13 skill（必备）

**特殊**：paper-revise 的 `.page` 用 `max-w-[920px]`（比其他宽 40px，容纳 5 列对照表）。

### 2.2 `.doc-head` / `.doc-eyebrow` / `.doc-title` / `.doc-meta`

**用途**：档案头区——眉头小字（skill 名 + 档案类型）+ 主标题（衬线宋体 2.1rem）+ 元信息（日期 / 来源 / 学科等）。

**HTML 骨架**：

```html
<header class="doc-head mb-10">
  <div class="doc-eyebrow font-sans text-[11px] tracking-[0.28em] uppercase text-ink-faint mb-[0.6rem]">
    Paper-<Skill> · <档案类型>
  </div>
  <h1 class="doc-title font-serif text-[2.1rem] font-bold leading-[1.25] mt-0 mb-4 tracking-[0.01em]">
    档案标题 <em class="italic font-medium text-ink-soft font-[Georgia,'Songti_SC',serif]">English Title</em>
  </h1>
  <div class="doc-meta flex flex-wrap gap-x-6 gap-y-2 pt-4 border-t border-rule text-ink-soft text-[0.9rem]">
    <span><b class="text-ink-faint font-medium mr-1.5">日期</b><日期></span>
    <span><b class="text-ink-faint font-medium mr-1.5">学科梯队</b><实证/理论型></span>
    <!-- 各 skill 自有字段 -->
```

**Tailwind 等价（精简）**：

| 子元素 | 等价 utility |
|---|---|
| `.doc-head` | `mb-10` |
| `.doc-eyebrow` | `font-sans text-[11px] tracking-[0.28em] uppercase text-ink-faint mb-[0.6rem]` |

### 2.6 `body` 底纹（纸面网格）

**用途**：在 `.page` 容器外的 body 背景画 28px 网格线，模拟档案室检索卡纸面。

**Tailwind 等价（用任意值 + 背景图）**：

```css
body {
  background-color: theme('colors.paper');
  background-image:
    linear-gradient(theme('colors.paper-edge') 1px, transparent 1px),
    linear-gradient(90deg, theme('colors.paper-edge') 1px, transparent 1px);
  background-size: 28px 28px;
  background-position: -1px -1px;
}
```

由于 Tailwind 任意值不支持 `theme()` 函数嵌套 + 多层 background-image，建议这段保留在各模板 `<style>` 段（共用即可）。

**出现于**：全部 13 skill（必备）

### 2.7 入场动画 `.page > *` rise（建议保留 `<style>`）

**用途**：page 内子元素逐个 8px 上浮 + 淡入，600ms ease、错峰 70ms；`prefers-reduced-motion: reduce` 时自动失效。

**Tailwind 等价**：Tailwind 的 `animate-*` 工具不直接支持 nth-child 错峰，建议这段统一保留在各模板 `<style>` 段：

```css
@media (prefers-reduced-motion: no-preference) {
  .page > * { opacity: 0; transform: translateY(8px); animation: rise .6s ease forwards; }
  .page > *:nth-child(1) { animation-delay: .05s; }
  .page > *:nth-child(2) { animation-delay: .12s; }
  /* ... 按子元素数量补到 nth-child(n+10) */
  @keyframes rise { to { opacity: 1; transform: none; } }
}
```

**出现于**：全部 13 skill（必备）

### 2.8 `@media print` 打印规则（建议保留 `<style>`）

**用途**：打印时去掉 body 网格、page 边框/阴影/最大宽、page::before 标签；强制取消 rise 动画。

**Tailwind 等价**：用 Tailwind 的 `print:` 前缀逐个改也行（`print:bg-white print:shadow-none ...`），但条目多、写起来比保留 CSS 段还啰嗦。建议共用 `<style>` 段：

```css
@media print {
  body { background: #fff; }
  .page { box-shadow: none; margin: 0; max-width: none; border: none; border-top: 6px solid #000; }
  .page::before { display: none; }
  .page > * { opacity: 1 !important; transform: none !important; animation: none !important; }
}
```

**出现于**：全部 13 skill（必备）

## 3. 语义标签与徽章

### 3.1 `.tag-inline.t1` / `.t2` / `.t3` / `.t4`

**用途**：行内四层来源标签（👤/📋/🪞/❓）。出现在段落首、列表项首、标题尾——读者一眼看到"这条信息的来源归属"。

**class**：`.tag-inline` + `.t1`（或 `.t2` / `.t3` / `.t4`）

**HTML 骨架**：

```html
<span class="tag-inline t1">👤</span>用户原话段落
<span class="tag-inline t2">📋</span>常见事实
<span class="tag-inline t3">🪞</span>系统归纳
<span class="tag-inline t4">❓</span>待用户验证
```

**Tailwind 等价**：

| 子元素 | 等价 utility |
|---|---|
| `.tag-inline`（共用） | `inline-block font-sans text-[10px] font-bold tracking-[0.04em] px-1.5 py-px rounded-sm mr-1 align-top`（注：原文用 `vertical-align: 2px`，等价 `align-[2px]`，但 Tailwind 不直接支持——可用 `align-top mt-[-2px]` 或保留 `.tag-inline` 命名 class） |
| `.t1` | `bg-l1-bg text-l1 border border-l1` |
| `.t2` | `bg-l2-bg text-l2 border border-l2` |
| `.t3` | `bg-l3-bg text-l3 border border-l3` |
| `.t4` | `bg-l4-bg text-l4 border border-l4` |

**出现于**：11 skill（review/topic/outline/draft/logic/method/daily/revise/disclose/abstract/proposal；import 改用 `.st` 状态徽章族，语义同源）。

### 3.2 `.badge.green` / `.yellow` / `.red` / `.miss`（对应度徽章族）

**用途**：三档对应度陈列（绿 >60% / 黄 30-60% / 红 <30%）+ miss 兜底（无对应）。徽章只陈列 `X/Y` 数字、**不下"够/不够"结论**（产品死线）。

**class**：`.badge` + `.green`（或 `.yellow` / `.red` / `.miss`）

**HTML 骨架**：

```html
<span class="badge green">对应度：7 / 10</span>
<span class="badge yellow">匹配度：4 / 10</span>
<span class="badge red">覆盖率：2 / 8</span>
<span class="badge miss">对应度：0 / 5（未挂锚点）</span>
```

**Tailwind 等价（色值见 §1.4）**：

| 子元素 | 等价 utility（用任意值色） |

**`.rs-dim` 等价**：`[&.rs-dim]:opacity-25 transition-opacity duration-200` 或保留 `<style>`。

**切换器 JS**（必须内联在模板 `<body>` 末、纯静态无依赖）：

```javascript
(function() {
  var boxes = document.querySelectorAll('#readerSwitcher input[type=checkbox]');
  var targets = document.querySelectorAll('[data-readers]');
  function apply() {
    var checked = Array.prototype.map.call(boxes, function(b){
      return b.checked ? b.dataset.reader : null;
    }).filter(Boolean);
    if (checked.length === 0) {
      targets.forEach(function(t){ t.classList.remove('rs-dim'); });
    } else {
      targets.forEach(function(t){
        var rs = (t.dataset.readers || '').split(/\s+/);
        var hit = rs.some(function(r){ return checked.indexOf(r) >= 0; });
        t.classList.toggle('rs-dim', !hit);
      });
    }
  }
  boxes.forEach(function(b){ b.addEventListener('change', apply); });
})();
```

## 7. 图表组件

### 7.1 唯一图表：paper-review `#reviewRadar`（5 维评分雷达图）

**陈列什么**：5 维模拟评分各 X/10 的剖面形状（新颖性 / 方法严谨性 / 结果可靠性 / 写作清晰度 / 贡献度）。

### 7.2 图表交互统一规范（产品死线，详见 `echarts-theme.js` 注释）

| 项 | 开/关 | 规则 |
|---|---|---|
| **Tooltip** | 开 | 静态显示数据点精确值。tooltip 内禁超链接、禁按钮、禁富文本。 |
| **Hover 高亮** | 开（轻量） | 数据点放大（6px→9px）。**关**：crosshair、zone highlighting、其他系列变灰。 |
| **入场动画** | 开（单次） | 600ms ease，与 `.page > *` rise 动画同步。`prefers-reduced-motion: reduce` 时降为 0ms。 |
| **循环动画** | 关 | 禁数据更新动画、禁 loading spinner、禁 pulse/glow 循环。陈列型报告不"动"。 |
| **Legend** | 关 | 轴标签/数据标签自说明。多系列场景才开 legend，且用文字不用色块图标。 |
| **Split area（分区色块）** | 关 | 分区=达标带=优劣暗示。splitLine 极淡保留（rule 色）。 |
| **Data zoom / brush / timeline** | 全关 | 这是陈列型报告，不是探索工具。 |
| **配色** | 单色优先 | 数据系列用 `l2`（赭石·模拟常见）。多系列才依次取 paper 主题色板，禁渐变、禁发光。 |
| **面积填充** | α ≤ 0.1 | 仅辅助识形。禁实心填充（面积=大小=价值暗示）。 |
| **数据标签** | 开 | 数据点旁标精确值（如 "7/10"）。衬线宋体 11px ink-soft。 |
| **Renderer** | SVG | 屏幕阅读器可读 DOM、打印矢量清晰。 |
| **Print** | 静态 | `@media print` 下强制无动画。灰度可辨（用形状/标签区分，不只靠色相）。 |
| **Responsive** | 开 | 容器 `width:100%; height:320-340px;`。`window.addEventListener('resize', ...)`。 |

### 7.4 未来新增图表的准入门槛

只有满足以下条件才考虑加图：

1. 数据是真正的多维数值或时间序列（非小计数分类）；
2. 图表投影已有表格/列表数据、**不引入派生指标**（均值/排名/达标线）；
3. 每张图必须带说明性 caption：写明"陈列什么、不下什么结论"；
4. 配色限定 §7.3 的 paper 主题色板，禁渐变、禁发光、禁 3D 阴影。

当前 13 skill 中只有 paper-review 满足以上条件。详见设计稿 §4.1-§4.2 的专家决策清单。
