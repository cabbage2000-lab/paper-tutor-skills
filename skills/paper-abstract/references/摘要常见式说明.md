# 摘要常见式说明（paper-abstract references）

> **陈列性、非推荐性**——本库陈列的是各学科**摘要常见结构**，
> 非"唯一正确"的摘要范式。各期刊 / 各校学位要求有差异（字数、结构、是否要求结构化），
> 用户按目标场合调整。
>
> 本库供 paper-abstract **第 2 步提炼**时引用：按学科梯队选用对应摘要式、逐要素
> 从正文提取要点、按常见句式重组生成摘要初稿（每句标正文锚点可追溯）。

---

## 三式（按学科梯队）

### 一、结构化摘要（实证型，第一梯队：实验/实证型理工农医、实证型社科）

适用于实证研究——论文有清晰的 IMRAD 结构（引言-方法-结果-讨论）。

| 要素 | 从正文哪提取 | 常见句式（📋 示例、非推荐） |
|---|---|---|
| **背景** | 引言段开头 | "<领域>中，X 问题备受关注 / X 现象日益普遍..." |
| **目的** | 引言末 / RQ 段 | "本研究旨在探讨 <RQ> / 本研究聚焦 <具体问题>..." |
| **方法** | 方法章 | "采用 <方法>（如问卷调查 / 实验法），对 <对象> 进行 <数据收集>..." |
| **结果** | 结果章 | "发现 <主要结果> / 数据显示 <核心发现>..." |
| **结论** | 结论章 | "研究表明 <结论>；<理论或实践意义>；<局限或展望>..." |

**要素齐全度徽章**：五要素每句标正文锚点；缺要素标"⚠️ 正文未涉及"。

### 二、理论型摘要（第二梯队：数学、理论物理、理论 CS、理论经济学等）

适用于理论研究——以定理 / 命题 / 模型推导为核心、无实证数据。

| 要素 | 从正文哪提取 | 常见句式（📋 示例、非推荐） |
|---|---|---|
| **问题** | 引言 / 问题提出 | "<理论问题>长期悬而未决 / <概念>的形式化尚不充分..." |
| **方法**（推理工具 / 论证框架） | 方法章 / 推导章 | "本文基于 <公理体系 / 模型框架>，通过 <推导方法>..." |
| **主要命题 / 论证** | 定理 / 命题 / 推导结果 | "证明了 <主要定理> / 得出 <核心命题>..." |
| **意义** | 结论 / 讨论章 | "该结果 <理论意义> / 为 <后续研究>奠定基础..." |

规范文本型（法学、公共管理、马克思主义理论等）归此梯队、加"规范主张"要素（本研究主张应如何理解 / 规范某制度 / 文本）。

### 三、诠释型摘要（第三梯队：文学、历史、哲学、艺术等）

适用于诠释 / 思辨研究——以文本 / 历史材料 / 思辨分析为核心、无假设-验证链。

| 要素 | 从正文哪提取 | 常见句式（📋 示例、非推荐） |
|---|---|---|
| **研究对象** | 引言 / 研究对象段 | "本文以 <文本 / 作家 / 历史现象 / 概念>为研究对象..." |
| **视角或框架** | 方法 / 理论框架章 | "立足 <视角（如接受美学 / 历史人类学 / 现象学）>..." |
| **主要阐释** | 分析 / 阐释章 | "指出 <主要阐释 / 发现> / 揭示 <意涵>..." |
| **贡献** | 结论章 | "本研究 <学术贡献> / 为 <领域>提供 <新理解>..." |

## 字数常见区间（📋 常见事实、非硬规则）

| 场合 | 常见字数（中文） |
|---|---|
| 期刊论文摘要 | 150-300 字 |
| 硕士学位论文摘要 | 500-800 字 |
| 博士学位论文摘要 | 800-1200 字 |
| 会议论文摘要 | 150-250 字 |

skill 摆的是常见区间、用户按目标场合调整；不硬限字数。

## 提炼规则（所有摘要式通用）

1. **每句标正文锚点**：摘要每句末标 `[正文锚点：引言段/方法章/结果章等]`，可追溯回 draft 正文具体段落（不变②）。
2. **不添加正文没有的内容**：正文未涉及的论断、结果、结论——一律不写入摘要；缺要素标"⚠️ 正文未涉及"。
3. **不夸大结果**：如实陈列正文结果、不升级措辞（"相关"不写成"因果"、"部分"不写成"全面"）。
4. **关键词从正文提取**：关键词从正文高频术语 / 核心概念提取、用户确认；不凭空生成。
5. **句子是 AI 重组生成的新句**：非正文原句复制（摘要是凝练）、但每句可追溯；属成句生成级（留痕如实披露）。
