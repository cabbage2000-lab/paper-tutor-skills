# 论断类型库

| 项 | 内容 |
| --- | --- |
| 类型 | 分类规范（论断 → 支撑要求 → 找不到时的出口） |
| 服务对象 | `paper-anchor` 主流程第 1 步（摘论断、分类、摆支撑要求） |
| 上游 | `scripts/anchor_scan.py` 的零引用段定位 + 用户 / 导师指出的位置 |
| 死线 | 三条不变③ —— **每条缺口至少给两个出口**，价值判断类只给「改写或删」 |

「这段缺文献支撑」是一句模糊的意见。它之所以模糊，是因为它把五种完全不同的问题
说成了一种——**不同类型的论断需要的支撑不同，找不到支撑时该做的事也不同**。本文档
把这五种拆开。

分类是本命令全部后续动作的输入：类型决定检索什么（见
[`论断检索式规则.md`](./论断检索式规则.md)），也决定找不到时给用户什么出口。**分类
错了后面全错**，所以第 1 步的停点必须让用户能改判（见第三节）。

## 0. 三条通用禁令（高于逐类口径）

1. **禁替用户判断某文献能否支撑某论断**——你能做的是把「该文献说了什么」与「你的
   论断说了什么」并排摆出来。「这篇支持你的观点」「可引此文支撑」「相关度高」全部
   禁止，无论多么明显。
2. **禁只给一个出口**——每条缺口都要同时摆「补文献」与「改弱表述或删除」。只给前者
   就是在教用户 citation shopping（先有结论后找文献）；那不是辅导，是替他埋一颗
   会在答辩现场炸的雷。
3. **禁完成态措辞**——「已为您找到支撑」「支撑已补齐」「问题已解决」。检索只是把候选
   摆出来了，是否构成支撑要用户读完原文才知道。

## 一、五类总表

| 类型 | 一句话 | 需要什么支撑 | 找不到时 |
| --- | --- | --- | --- |
| ① 事实陈述 | 关于世界的可证伪断言 | 实证研究 / 统计来源 | 改弱到有据的强度，或删 |
| ② 方法依据 | 「我用了某方法 / 量表 / 模型」 | 该方法的**原始出处** | 确认是引用还是自创；自创须声明 |
| ③ 理论框架 | 「我基于某理论」 | 理论原始文献 + 应用先例 | 核对术语是否标准、是否记错来源 |
| ④ 对比 / 创新 | 「与已有研究不同 / 本文首次」 | **被对比的那些研究** | 降级为「据我们所知」式表述 |
| ⑤ 价值判断 | 「这很重要 / 很有必要」 | **通常无文献可支撑** | 删，或改写成可支撑的事实陈述 |

## 二、逐类详解

### ① 事实陈述

**定义**：关于世界状态的断言，原则上可被数据证实或推翻。

**判定线索**：时间副词 + 趋势词（「近年来」「日益」「逐渐」「越来越」）；数量词
（「大多数」「普遍」「显著」）；现象描述句式（「X 存在 Y 问题」「X 呈现 Y 特征」）。

**需要什么支撑**：报告过该现象的实证研究，或权威统计来源（统计年鉴、行业报告、
官方公报）。

**找不到时的出口**（两条并列）：
- 补文献：检索该现象的实证研究（见检索式规则的策略 a）。
- **改弱到有据的强度**——原句的强度超出了你能证明的范围，把范围缩回来：

| 原句（强度过高） | 示例改法（示例、非定稿） |
| --- | --- |
| 「近年来大学生学术写作能力普遍下降。」 | 「已有研究在 X 地区的样本中报告了学术写作能力的下降趋势（待补锚点）。」 |
| 「AI 工具已被广泛应用于论文写作。」 | 「已有调查显示部分高校学生在论文写作中使用 AI 工具（待补锚点）。」 |

改弱不是认输——**把话说到你能证明的地方为止，这是学术写作的基本功**，也是答辩时
最难被追问倒的写法。

### ② 方法依据

**定义**：声明本研究使用了某个既有的方法、量表、模型、算法、编码框架。

**判定线索**：「采用」「使用」「借鉴」「参照」+ 具名对象；量表名（含缩写，如
SCL-90、TAM）；「按 X 的做法」。

**需要什么支撑**：该方法的**原始出处**（首次提出它的那篇），而非用过它的任意一篇。
量表还需注明版本与信效度来源；本土化修订过的量表须引修订版。

**找不到时的出口**：
- 补文献：按方法名检索原始文献（检索式规则的策略 b，往回追溯）。
- **确认来源性质**——这类论断找不到出处通常不是「缺引用」，而是三种情况之一，须
  问用户是哪种：
  1. 方法是你自己设计的 → 正文须明确声明为自创，不能写成「采用」；
  2. 方法名记错或用了非标准简称 → 核对准确名称再检索；
  3. 方法来自教材 / 讲义 / 二手转述 → 须追到原始文献，不能引二手转述。

**为什么这类不能含糊**：方法来源不明会让审稿人怀疑整个研究的可复制性——它比一句
缺引用的事实陈述严重得多。

### ③ 理论框架

**定义**：声明本研究以某个理论、模型、视角作为分析框架。

**判定线索**：「基于 X 理论」「以 X 为理论视角」「运用 X 框架」「从 X 出发」。

**需要什么支撑**：① 理论的原始文献（提出者的原著或原始论文）；② 该理论在本领域
的应用先例（证明这样用是站得住的）。两者缺一都算不完整——只引原著不能说明它适用
于你的对象，只引应用先例则来源不明。

**找不到时的出口**：
- 补文献：检索理论名 + 该理论在本领域的应用（检索式规则的策略 b + c）。
- **核对术语**——这类检索不到，最常见的原因是术语不标准：中译名有多种（如
  「计划行为理论」／「计划行动理论」）、简称与全称混用、或把某学者的一个说法误当成
  一个「理论」。核对准确的原始术语（含英文原名）再检索。

### ④ 对比 / 创新

**定义**：声明本研究与已有研究不同、优于已有做法、或首次做了某事。

**判定线索**：「与已有研究不同」「不同于以往」「已有研究多集中于…而本文」「首次」
「尚未有人」「填补了空白」「率先」。

**需要什么支撑**：**被对比的那些研究本身**。「与已有研究不同」这句话的支撑不是
一篇支持你的文献，而是**你所对比的那批文献**——没有它们，这句话没有对照物。

**找不到时的出口**：
- 补文献：检索该方向近 N 年的同类研究（检索式规则的策略 c）。
- **降级为「据我们所知」式表述**——这是学术写作的标准做法（英文的 "To the best of
  our knowledge"），承认检索范围有限，而不是断言绝对的「首次」：

| 原句 | 示例改法（示例、非定稿） |
| --- | --- |
| 「本文首次研究了 X 对 Y 的影响。」 | 「据我们所知，尚未有研究直接考察 X 对 Y 的影响。」 |
| 「已有研究均忽略了 Z。」 | 「我们检索到的研究中，尚未见对 Z 的直接讨论。」 |

**这类最危险**：「首次」是可被一篇文献推翻的断言。审稿人只要找出一篇同类研究，
整段创新性声明就失效，且会连带影响他对全文严谨性的判断。**创新性声明缺对照物，
不是小瑕疵。**

### ⑤ 价值判断

**定义**：关于重要性、必要性、意义的断言。**没有可证伪的内容**，因而通常无文献
可支撑。

**判定线索**：「重要」「必要」「亟需」「具有重要意义」「不容忽视」「值得关注」
「有助于推动」——句子拿掉这些词以后，如果不剩任何可查证的内容，就是这一类。

**需要什么支撑**：**通常没有**。这类句子不是缺引用，是它本身不构成可支撑的论断。

**找不到时的出口**——**只给一条**：删，或改写成可支撑的事实陈述。

| 原句（价值判断） | 示例改法：改成可支撑的事实（示例、非定稿） |
| --- | --- |
| 「研究大学生 AI 使用具有重要意义。」 | 「已有调查显示 X% 的大学生在写作中使用 AI 工具（待补锚点），而其对写作能力的影响尚缺乏实证研究。」 |
| 「该问题亟需解决。」 | 「该问题已在 X 个省份的政策文件中被列为待解决事项（待补锚点）。」 |

改法的共同点：**把「我觉得它重要」换成「有人报告了这个现象 / 有制度在处理它」**——
后者可以挂锚点，前者不能。

**这一类为什么不进检索步**：为一句价值判断去检索，等于替用户找一篇文献来给他的
主观评价背书。那正是 citation shopping 的典型动作。本命令**不做**这件事——第 1 步
判定为第五类的论断，直接给改写出口，不生成检索式、不调用检索。

## 三、分类可改判（必须给的入口）

分类由你（宿主 agent）判断，不是脚本算出来的，**会错**。常见错法：

- 一句话同时含两类（「本研究采用 X 量表，该量表已被广泛应用」——前半句是②、后半句
  是①），须拆成两条分别处理；
- 「本文首次采用 X 方法」既是②也是④，两个支撑都要（方法原始出处 + 对比对象）；
- 貌似价值判断实为事实陈述（「该现象在实务中影响很大」——若作者指的是有数据的影响
  范围，则是①而非⑤），须问用户本意。

所以第 1 步的停点里，每条论断的类型都要**标出来并可改**：

```text
⏸ 等待确认：缺口清单与论断分类
（回复要补的条目编号；类型判错可直接说「第 3 条是方法依据不是事实陈述」）
```

用户改判后按新类型重走支撑要求与检索策略。**不要坚持自己的分类**——用户知道自己
那句话想说什么，你只看到字面。

## 四、学科三梯队下的支撑形态

梯队定义见共享层的 [学科三梯队](../../_shared/references/学科三梯队.md)。**本命令不设
整体让路**（各学科都会被说缺文献支撑），但「什么算支撑」按梯队变：

| 梯队 | ① 事实陈述 | ② 方法依据 | ③ 理论框架 | ④ 对比创新 |
| --- | --- | --- | --- | --- |
| 第一梯队（实证理工农医 / 实证社科） | 实证研究、统计来源 | 方法学原始文献、量表原始出处 | 理论原著 + 本领域应用 | 同方向近年实证研究 |
| 第二梯队 · 理论型（数学 / 理论物理 / 理论 CS） | 已证定理、既有结论 | 证明技术的原始出处 | 公理系统 / 理论框架原文 | 同问题的已有定理与界 |
| 第二梯队 · 规范文本型（法学 / 公共管理 / 马理论） | 法条、判例、政策文件、统计公报 | 解释方法的学说出处 | 学说谱系与代表作 | 既有学说与争点梳理 |
| 第三梯队 · 诠释型（文学 / 历史 / 哲学 / 艺术） | **一手史料 / 文本**（首要）+ 二手研究 | 释读方法的学术传统 | 理论原著 | 既有阐释与研究史 |

**自动检索覆盖率按梯队差别很大，必须显式声明**（不变② 的延伸）：

- 第一梯队与理论型：Crossref / OpenAlex / Semantic Scholar / arXiv 覆盖较好，双轨可用。
- **规范文本型：法条与判例不在这些库里**，自动轨基本无效，须明说并转引导轨（知网、
  北大法宝等由用户检索回填）。
- **诠释型：一手史料 API 查不到**（古籍、档案、手稿），这部分如实让路、不硬套；只对
  二手研究走检索。

绝不能让用户以为「自动检索没找到」等于「没有支撑可用」——那对后两类学科是系统性误导。

## 五、不属本命令的情形

| 情形 | 归谁 |
| --- | --- |
| 已挂了引用，但怀疑引用是编的 / 查不到 | `/paper-verify`（存在性核验） |
| 已挂了引用，但引用与论断对不上 | `/paper-verify` 的元数据不符 + 本命令的比对表 |
| 结论超出了自己数据的支撑范围 | `/paper-claim`（结论夸大检查，那是「结果 → 结论」而非「文献 → 论断」） |
| 参考文献格式不合国标 | `/paper-format` |
| 要系统性地筛一批文献 | `/paper-screen` |
| 从 RQ 出发做综述、找研究缺口 | `/paper-search` |
