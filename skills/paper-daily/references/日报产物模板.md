# paper-daily 日报产物模板（MD + JSON schema + HTML 骨架）

> 本文件是 `/paper-daily` 三产物（`daily/YYYY-MM-DD.md` / `daily/YYYY-MM-DD.html` / `daily/.paper/YYYY-MM-DD.json`）的格式权威。宿主 agent 生成产物时：
> - **MD 产物**：照抄本文 §1 的模板，把 `<尖括号占位>` 替换为真实实例内容，删掉未触发的块（如完全降级时删抢发检测整段、走 §1 末尾的降级版）。
> - **JSON 留痕**：照抄本文 §2 的 schema 字段，每个字段必填、字段缺失时按规则标状态（不可静默填 LLM 猜测值）。
> - **HTML 产物**：复制 `references/报告样式模板.html` 为起点（本文 §3 只给结构骨架，完整样式在那个文件）。

---

## §1 MD 日报模板（五段式）

```markdown
# Paper 日报 · YYYY-MM-DD

> RQ: <用户一句话>
> 时间窗: 今日 | 最近 N 天
> 生成时间: YYYY-MM-DD HH:MM（本地时区）
> 数据源状态: ✅ arXiv 自动 / ✅ 用户补充（X 条） / ⚠️ 中文库未自动检索

---

## 📋 今日概览

- **抢发对照**: 全源检索命中 X 篇（高 H / 中 M / 低 L）
- **新发自动轨**: arXiv 命中 Y 篇（高 H / 中 M / 低 L）
- **新发补充轨**: 用户补充 Z 篇
- **⚠️ 中文缺口提示**: 英文库没检索到 ≠ 没人研究过。
  本次未纳入中文库自动检索，如研究涉中文语境，
  请用 `/paper-search` 走中文引导轨（知网/万方）补检。

---

## 🚨 抢发检测

**已发相关文献 X 篇**（数据源: Crossref + OpenAlex + Semantic Scholar + arXiv）。

> 陈列标准: 概念块（对象 / 干预 / 结果 / 场景 / 方法）与 RQ 至少一项重叠。
> **「是否仍可做」的判断归用户与导师，以下陈列仅为客观线索。**

### 🔴 概念高度重叠（H 篇）

- **[标题]** — 一作者 et al. (年份). *Venue*. DOI:10.xxxx/y.
  - 概念比对: 对象=重叠 / 方法=重叠 / 结果=不同 / 场景=重叠 / 干预=不同
  - 标签: 高相关（4 维重叠）

### 🟡 部分概念重叠（M 篇）

- **[标题]** — 一作者 et al. (年份). *Venue*. DOI:10.xxxx/y.
  - 概念比对: 方法=重叠 / 场景=重叠
  - 标签: 中相关（2 维重叠）

### ⚪ 弱重叠 / 仅上下文相关（L 篇）

- **[标题]** — 一作者 et al. (年份). *Venue*. DOI:10.xxxx/y.
  - 概念比对: 对象=重叠
  - 标签: 低相关（1 维重叠）

## 🎯 下一步行动

> 以下是程序化陈列（基于上面的命中数量），**不是 AI 替你拍板**。
> 每条是否执行由你决定。

- 🚨 抢发命中（高相关 ≥ 1 篇） → 是否进入 `/paper-topic` 重审 RQ？
- 📖 高相关新发 ≥ 1 篇 → 是否进入 `/paper-search` 对该篇做深检？
- 🟢 全部低相关 → 是否照常推进当前研究？
- 📚 中文缺口 → 是否进入 `/paper-search` 走中文引导轨补检？

---

**留痕指针**: `.paper/YYYY-MM-DD.json`（检索参数、原始命中、概念比对依据、用户补充原文）
```

```markdown
---

## 📋 今日概览

- 自动轨: ❌ 不可用
- 用户补充: Z 篇

   → 建议: 用 /paper-doctor 排查环境后重跑

## 📰 新发泛读 · [仅用户补充轨]

- **[标题]** — 一作者 et al. (日期). 来源: 用户补充.
  - 标签: 高|中|低相关
  - 链接: <用户提供的链接或 DOI>
  （用户补充为空时，本段写「今日无补充」，不自动填充）

## 🎯 下一步行动

> 以下是程序化陈列，**不是 AI 替你拍板**。

- 自动轨不可用 → 是否先跑 /paper-doctor？
- 用户补充有高相关 → 是否进入 /paper-search 深检？

---

**留痕指针**: `.paper/YYYY-MM-DD.json`（fallback_declared: true）
```

### 关键约束

- **概念比对维度固定 5 项**：对象 / 干预 / 结果 / 场景 / 方法（对齐 PICO + 方法维）。
- **高 / 中 / 低的判定依据必须可追溯**：每条旁标"哪些概念块重叠"、几维重叠，不空泛打标签。
  - 高 = ≥3 维重叠
  - 中 = 2 维重叠
  - 低 = 1 维重叠或仅上下文相关
- **每段顶部固定陈述本段判定标准**，让用户读得懂为什么这样归类。
- **禁用语扫描**（生成 MD 后必跑）：`最相关` / `最重要` / `必读` / `Top` / `最该读` / `推荐阅读` / `已被抢发` / `做不了了` / `晚了` / `没有意义` 任一命中需返工。

## §2 JSON 留痕 schema

```json
{
  "date": "YYYY-MM-DD",                     // 本根日期（用户跑命令的日期，本地时区）
  "rq": "<用户一句话>",                     // 第 1 步收到的 RQ 原文
  "time_window": "today | last_N_days",     // today=今日；last_N_days 时 N ≤ 14
  "discipline": "<来自 project.paper.yaml，可空>",
  "language_pref": "<同上>",
  "citation_style": "<同上>",

  "search_params": {
    "scoop": {                              // 抢发对照轨：全源 search.py
      "script": "skills/paper-search/scripts/search.py",
      "args": "--query '<RQ 概念块组查询串>' --sources crossref,openalex,semantic_scholar,arxiv --per-source 20 --limit 30",
      "network_status": "online | offline | partial",   // 直接读 search.py 返回值
      "coverage": {                         // 逐源命中数 + 状态
        "crossref": {"hit": 12, "status": "ok | timeout | error"},
        "openalex": {"hit": 8, "status": "ok"},
        "semantic_scholar": {"hit": 5, "status": "ok"},
        "arxiv": {"hit": 3, "status": "ok"}
      }
    },
    "digest_arxiv": {                       // 新发自动轨：仅 arXiv
      "script": "skills/paper-search/scripts/search.py",
      "args": "--query '<2-5 个核心概念词>' --sources arxiv --days <N> --per-source 50 --limit 30",
      "network_status": "...",
      "coverage": {"arxiv": {"hit": 25, "status": "ok"}},
      "date_window": {"from": "2026-07-29", "to": "2026-07-29"},  // 照抄脚本输出的 filters
      "warnings": []                        // 照抄脚本输出的 warnings，非空必在产物里原文呈现
    }
  },

  "user_supplement_raw": "<用户粘的原文，完整保留，不删不改>",  // 失败可追溯
  "user_supplement_parsed": [
    {
      "title": "...",                       // 缺失标 null
      "authors": "...",
      "doi": "...",
      "link": "...",
      "date": "...",
      "parse_status": "ok | partial_fields | parse_failed",  // 强制每条标
      "parse_missing_fields": ["doi", "date"]                // partial_fields 时列出缺失字段
    }
  ],

  "scoop_hits": [                           // 抢发检测命中（来自 search_params.scoop）
    {
      "title": "...",
      "authors": "...",
      "year": 2024,
      "venue": "...",
      "doi": "10.xxxx/y",
      "concept_overlap": {                  // 5 维布尔
        "object": true,
        "intervention": false,
        "outcome": true,
        "context": false,
        "method": true
      },
      "overlap_count": 3,                   // 上面 5 维中 true 的个数（用于判高/中/低）
      "relevance": "high | medium | low",   // ≥3=high, 2=medium, ≤1=low
      "source": "crossref | openalex | semantic_scholar | arxiv"
    }
  ],

  "digest_arxiv_hits": [                    // 新发自动轨命中（来自 search_params.digest_arxiv）
    {
      "title": "...",
      "authors": "...",
      "arxiv_id": "2401.12345",
      "submitted_date": "2026-07-25",       // 用于时间窗筛选
      "abstract_first_sentence": "...",
      "concept_overlap": {"object": true, "intervention": false, "outcome": false, "context": false, "method": true},
      "overlap_count": 2,
      "relevance": "medium"
    }
  ],

  "digest_user_hits": [                     // 新发补充轨命中（用户补充解析后的）
    {
      "title": "...",
      "authors": "...",
      "link": "...",
      "date": "...",
      "source_label": "用户补充",            // 固定值，不可谎称"自动检索"
      "concept_overlap": {"object": true, "intervention": false, "outcome": false, "context": false, "method": false},
      "overlap_count": 1,
      "relevance": "low",
      "parse_status": "ok | partial_fields | parse_failed"  // 来自 user_supplement_parsed
    }
  ],

  "chinese_gap_declared": true,             // 概览段是否原文给出"英文库没检索到 ≠ 没人研究过"提示（必为 true，除非纳入了中文库自动检索）
  "fallback_declared": false,               // 是否触发完全降级（F1/F2/F10 时为 true，顶部 banner 显示）

  "actions_suggested": [                    // 第 4 段「下一步行动」程序化陈列
    {"trigger": "scoop_high ≥ 1", "action": "进入 /paper-topic 重审 RQ？", "activated": true},
    {"trigger": "digest_high ≥ 1", "action": "进入 /paper-search 深检？", "activated": true},
    {"trigger": "all_low", "action": "照常推进当前研究？", "activated": false},
    {"trigger": "chinese_gap", "action": "进入 /paper-search 中文引导轨？", "activated": true}
  ]
}
```

### 关键约束

- `user_supplement_raw` **完整保留用户原文**——失败可追溯、不静默篡改用户输入。
- `parse_status` 字段强制每条标状态，**绝不允许"部分字段失败"被静默填上 LLM 猜测值**（继承 paper-import 的字段缺失标占位惯例）。
- `network_status` 是 search.py 已有的字段，直接读回、不做二次判断。
- `chinese_gap_declared` 与 `fallback_declared` 是发布门自检字段，每天日报至少其一为 true（前者基本总为 true，因为本最小实现不接中文库自动检索）。

## §3 HTML 结构骨架（完整样式见 `references/报告样式模板.html`）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Paper 日报 · YYYY-MM-DD</title>
  <style>
    /* 复用 paper-topic / paper-logic 报告样式模板：四层语义色 + 段落标签轴 */
    /* 仅新增四个 daily 专属语义类（配色沿用模板四层变量，不引新配色）：*/
    /*   .scoop-alert    抢发检测段区块样式（警示层 / 砖红色系）*/
    /*   .digest-item    新发泛读每条样式（信息层 / 青灰色系）*/
    /*   .action-card    下一步行动每条样式（建议层 / 赭石色系）*/
    /*   .fallback-banner 完全降级顶部 banner（醒目警示色）*/
  </style>
</head>
<body>
  <header>
    <h1>Paper 日报 · YYYY-MM-DD</h1>
    <div class="metadata">
      <span>RQ: <一句话></span>
      <span>时间窗: 今日 | 最近 N 天</span>
      <span class="source-status">数据源状态: ✅ arXiv 自动 / ✅ 用户补充 / ⚠️ 中文库未自动检索</span>
    </div>
    <!-- 完全降级时插入 <div class="fallback-banner">⚠️ 自动轨不可用：<原因></div> -->
  </header>

  <section id="overview">
    <h2>📋 今日概览</h2>
    <!-- 三段统计 + 中文缺口提示原文（红线 2 必现）-->
  </section>

  <section id="scoop" class="scoop-alert">
    <h2>🚨 抢发检测</h2>
    <!-- 完全降级时整段省略 -->
    <!-- 高/中/低三档分组，每条带概念比对徽章 + 维度数 -->
    <!-- 顶部固定陈列标准 + "是否仍可做归用户与导师"声明（红线 1）-->
  </section>

  <section id="digest">
    <h2>📰 新发泛读</h2>
    <div class="track-arxiv"><h3>[arXiv 自动轨]</h3><!-- 每条 .digest-item --></div>
    <div class="track-user"><h3>[用户补充轨]</h3><!-- 每条 .digest-item，来源标签固定「用户补充」--></div>
  </section>

  <section id="actions">
    <h2>🎯 下一步行动</h2>
    <!-- 每条 .action-card + 疑问句式 + 顶部"程序化陈列非 AI 拍板"声明 -->
  </section>

  <footer>
    <p>留痕指针: <code>.paper/YYYY-MM-DD.json</code></p>
  </footer>
</body>
</html>
```

### HTML 与 MD 的内容必须一致

- 同一份产物两种呈现：HTML 加样式 + 可折叠交互；MD 给 grep / 命令行用户读。
- 生成时用同一份内部数据（即 §2 的 JSON）渲染出两份。
- **完全降级时**：HTML 的 `<section id="scoop">` 整段省略、顶部插 `<div class="fallback-banner">`。
