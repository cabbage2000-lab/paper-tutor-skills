# 段落写作参考（paper-draft references）

> 本文件陈列学术段落学界**客观常见**的写作模式。**不是推荐的、不是最优的**——
> 用户可全弃自定、可混合、可只取一部分。段落写作取舍权 100% 归用户。
> 与 paper-topic「选项死线」、paper-outline「骨架非推荐」一脉相承：摆事实、不推荐、不排序、不打分。

## ① 论点-证据-反例（Argument-Evidence-Counter）

**适用**：实证研究、量化分析的正文段落（如引言贡献声明、结果讨论段）。

**段落骨架**：
- 论点句（本段核心主张，一句话）
- 证据陈述（引用文献或数据，挂锚点）
- 反例 / 边界条件（增强严谨性）
- 段尾回扣论点（呼应段首、过渡下段）

**常见变体**：
- 反例可省略（综述类段落常见）。
- 论点句可放段尾而非段首（演绎式段落）。
- 证据可并列 2-3 条（堆叠证据强化论点）。

## ② 因果链（Cause-Effect Chain）

**适用**：理论机制叙述、影响路径分析、过程解释段。

**段落骨架**：
- 现象陈述（起点）
- 因果环节 1（A → B）
- 因果环节 2（B → C）
- 结论（最终结果 / 理论含义）
- 挂锚点：每个因果环节尽量挂文献支撑

**常见变体**：
- 单因果链（线性 A→B→C）vs 多岔因果链（A→{B,D}→C）。
- 因果环节可加稳健性检验（控制变量 / 反事实）。

## ③ 比较对照（Compare-Contrast）

**适用**：文献综述段落、方法对比段、跨样本比较段。

**段落骨架**：
- 比较对象 A 与 B 引入
- 维度 1 对比（如理论假设）
- 维度 2 对比（如方法选择）
- 维度 3 对比（如结论差异）
- 综合判断（A 与 B 的本质分歧 / 互补关系）

**常见变体**：
- 二元比较（A vs B）vs 多元比较（A / B / C / D）。
- 综合判断可省略、让读者自行推断（中立综述常见）。

## ④ 过程叙述（Process Narrative）

**适用**：方法章节、实验流程、研究设计段落。

**段落骨架**：
- 步骤 1（含决策理由）
- 步骤 2（含操作细节）
- 步骤 3（含质量控制）
- 信效度声明（为什么这个流程可信）

**常见变体**：
- 步骤可按时序 vs 按重要性（不按时序则按"关键决策优先"）。
- 信效度声明可单列成段 vs 并入末步骤。

## ⑤ 定义-展开（Define-Elaborate）

**适用**：概念框架、理论建构、引言核心概念引入段。

**段落骨架**：
- 概念定义（核心术语的一句话界定，挂锚点权威来源）
- 内涵展开（定义的子维度）
- 外延界定（本研究的适用范围、与近义概念区分）
- 操作化（如何在本研究中测量 / 应用）

**常见变体**：
- 操作化可单列段 vs 并入定义。
- 内涵展开可加反例（"不属于本概念的情形"）。
