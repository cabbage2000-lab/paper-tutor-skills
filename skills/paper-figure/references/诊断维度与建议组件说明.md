## B 诊断 5 维度

每维度顶部一个**诊断覆盖徽章**（仿 logic 对应度徽章）：

- **文字只说 "X / Y 项可视觉识别"**（X = 当前路径可识别的检查项数、Y = 总检查项数），**绝不写"好/差/合规/违规"**
- **颜色按客观比例**（仅视觉提示、不含价值判断）：
  - 🟢 绿：X/Y > 60%
  - 🟡 黄：30% < X/Y ≤ 60%
  - 🔴 红：X/Y ≤ 30%

### 维度 ① 图类适配

**检查项**：
- 表达"比较"关系是否用了柱状/条形图（而非折线）？
- 表达"趋势"关系是否用了折线图（而非柱状）？
- 表达"分布"关系是否用了直方图/箱线图（而非柱状）？
- 表达"相关"关系是否用了散点图？
- 表达"构成"关系是否用了饼图/堆叠柱状图？
- 陈列"该图表达 X 关系、你的图为 Y 图类"的对应事实（陈列、不判对错）

**AI 视觉可靠性**：高（~80%）

**两条路径行为**：
- **贴图路径**：AI 视觉识别图类 + 推断数据关系类型 → 陈列对应事实
- **代码静态分析路径**：从 `plt.bar`/`plt.plot`/`plt.scatter`/`plt.hist`/`plt.boxplot` 等函数调用精确识别图类

### 维度 ② 图注与图例完整性

**检查项**：
- 图注是否含：图序号、简述、坐标轴/图例/符号说明、样本量、统计标记、来源？
- 图例是否遮挡数据？
- 子图 (a)(b)(c) 编号是否与正文引用一致？
- 图注六槽（详见 C 组件 b）逐项标"📋 有 / ⚠️ 缺"

**AI 视觉可靠性**：中（~60%）

**两条路径行为**：
- **贴图路径**：AI 视觉识别图注文字与图例位置
- **代码静态分析路径**：从 `plt.legend()`、`plt.title()`、`fig.text()`、`xlabel`/`ylabel` 等调用分析图注/图例设置

### 维度 ③ 坐标轴与刻度

**检查项**：
- 坐标轴是否截断（truncated y-axis 误导）？
- 零点是否标全（柱状/条形图 Y 轴起始值是否为 0）？
- 双 Y 轴是否易误读？
- 对数轴是否显式标注？
- 刻度数量是否适中（不过密、不过稀）？

**AI 视觉可靠性**：低（~40%）

**两条路径行为**：
- **贴图路径**：降级为**结构化自查清单**（不直接下结论）
- **代码静态分析路径**：精确静态分析 `set_ylim`、`set_yscale('log')`、`twinx()` 等调用

**低可靠性自查清单模板**（贴图路径触发）：
```
⚠️ 视觉判断可靠性有限、建议自查：
  ① Y 轴起始值是否为 0？（柱状/条形图必查）
  ② Y 轴是否截断（如从非零值起）？截断是否必要、是否标注？
  ③ 是否使用对数轴？对数轴是否在轴标签或图注中显式说明？
  ④ 是否使用双 Y 轴？双轴的刻度对应关系是否易引起误读？
  ⑤ 刻度数量是否适中（建议 5-8 个主刻度）？
```

### 维度 ④ 配色与可读性

**检查项**：
- 是否色盲友好（避免红绿对比区分数据系列）？
- 对比度是否充足（前景/背景、数据系列间）？
- 灰度打印是否可分辨（不仅靠颜色区分）？
- 是否仅靠颜色区分数据系列（无形状/线型/图案辅助）？

**AI 视觉可靠性**：低（~35%）

**两条路径行为**：
- **贴图路径**：降级为**结构化自查清单**（不直接下结论）
- **代码静态分析路径**：精确分析 hex 值 + 色盲模拟（检查 `color`/`cmap` 参数、hex 是否取自公开色板）

**低可靠性自查清单模板**（贴图路径触发）：
```
⚠️ 视觉判断可靠性有限、建议自查：
  ① 是否使用红绿对比区分数据系列？（常见色盲盲区）
  ② 灰度打印下各数据系列是否仍可分辨？
  ③ 是否仅靠颜色区分系列？有无形状/线型/图案辅助？
  ④ 对比度是否充足（前景与背景、相邻系列间）？
```

### 维度 ⑤ 误差与统计标记

**检查项**：
- 误差棒类型（SE / SD / 95% CI）是否标注？是否混用？
- 统计标记（`*` / `**` / `***` vs p 值）是否规范？
- 多重比较校正（Bonferroni / Tukey / FDR）是否标记？

**AI 视觉可靠性**：极低（~20%）

**两条路径行为**：
- **贴图路径**：仅当图注/图例中显式标注时识别；否则降级为**结构化自查清单**
- **代码静态分析路径**：精确分析 `errorbar` 参数（`yerr`/`xerr` 值来源、`capsize`）、`plt.annotate` 中的星号标记

**低可靠性自查清单模板**（贴图路径触发）：
```
⚠️ 视觉判断可靠性有限、建议自查：
  ① 误差棒类型是 SE、SD 还是 95% CI？是否在图注中显式标注？
  ② 若有多组误差棒，类型是否一致（未混用 SE 与 SD）？
  ③ 统计显著性标记（*、**、***）的 p 值阈值是否在图注中说明？
  ④ 多重比较是否做了校正（Bonferroni / Tukey / FDR）？是否标注？
```

## C 建议 5 组件

### 组件 a · 图类建议

按用户数据/论断的"关系类型"陈列常见图类（陈列事实、不推荐、不排序）：

| 关系类型 | 常见图类 | 备注 |
|---|---|---|
| 比较（组间差异） | 柱状图、条形图 | 条形图（横向）适合类别名较长时 |
| 趋势（随时间变化） | 折线图 | |
| 分布（单变量） | 直方图、箱线图、小提琴图 | 箱线图/小提琴图适合多组分布对比 |
| 相关（两变量关系） | 散点图 | 可加回归线、相关系数标注 |
| 构成（占比） | 饼图、堆叠柱状图 | 堆叠柱状图适合多组占比对比 |
| 生存（时间-事件） | Kaplan-Meier 曲线 | 生物医学专项 |
| 元分析（多项研究汇总） | 森林图 | 元分析专项 |

每条建议标四层标签之一（👤 用户原话 / 📋 常见事实 / 🪞 系统归纳 / ❓ 待用户决定），
图类最终选择标 ❓ 待用户决定。

### 组件 b · 图注骨架（六槽）

图序号 / 简述 / 要素说明 / 样本量 / 统计标记 / 来源——六槽骨架，用户填措辞：

| 槽 | 占位内容 | 常见填法（📋 示例、非推荐） |
|---|---|---|
| **图序号** | `图 N` / `Figure N` | 按正文出现顺序编号 |
| **简述** | `❓ <一句话概括图表内容>` | "X 对 Y 的影响"、"A、B、C 三组比较" |
| **要素说明** | `❓ <坐标轴/图例/符号说明>` | "误差棒为 95% CI；* p<0.05，** p<0.01，*** p<0.001" |
| **样本量** | `❓ <n=?>` | "n=30/组"、"N=120 总样本" |
| **统计标记** | `❓ <统计方法与标记说明>` | "组间比较用 t 检验；多重比较经 Bonferroni 校正" |
| **来源** | `❓ <数据来源/修改自何处>` | "数据来自本研究实验"、"修改自 [Smith 2023]" |

具体措辞标 ❓ 待用户定稿；骨架是大纲结构级、用户填空。

### 组件 c · 配色方案

**色板选择规则**（📋 常见事实陈列、非推荐；用户按数据性质选择，最终决定归用户）：

| 数据性质 | 色板 | 具体 hex 值（📋 取自公开色板、非 AI 原创） | 色板来源标注格式 |
|---|---|---|---|
| **离散分类（≤8 类）** | Okabe-Ito 8 色 | `#E69F00` `#56B4E9` `#009E73` `#F0E442` `#0072B2` `#D55E00` `#CC79A7` `#000000` | `色板来源标注：Okabe-Ito 色盲友好色板，Okabe & Ito 2008` |
| **离散分类（>8 类）** | ColorBrewer Qualitative（Set2 / Paired / Dark2） | Set2 示例：`#66C2A5` `#FC8D62` `#8DA0CB` `#E78AC3` `#A6D854` `#FFD92F` `#E5C494` `#B3B3B3`（取自 8 色版、更多类别查 ColorBrewer 官网） | `色板来源标注：ColorBrewer Qualitative Set2，Brewer 2017` |
| **顺序/连续（无中心点）** | viridis / plasma / inferno / magma；或 ColorBrewer Sequential（YlOrRd / YlGnBu / Blues） | viridis 系为 matplotlib 默认连续色板（感知均匀、色盲友好），直接用 `cmap='viridis'` 即可 | `色板来源标注：viridis（matplotlib 默认），van der Walt et al. 2014` 或 `ColorBrewer Sequential YlGnBu，Brewer 2017` |
| **发散（有中心点，如 0、相关矩阵正负）** | ColorBrewer Diverging（RdBu / PiYG / BrBG） | RdBu 示例：`#67001f` `#b2182b` `#d6604d` `#f4a582` `#fddbc7` `#f7f7f7` `#d1e5f0` `#92c5de` `#4393c3` `#2166ac` `#053061`（11 级、中心为白） | `色板来源标注：ColorBrewer Diverging RdBu，Brewer 2017` |
| **地理地图（choropleth）** | ColorBrewer Sequential（YlGnBu / Reds） | 同顺序色板取单色梯度 | `色板来源标注：ColorBrewer Sequential YlGnBu，Brewer 2017` |

所有配色方案顶部声明：**"📋 色板取自公开色盲友好色板、非 AI 原创。"**

### 组件 d · 坐标轴规范提示

陈列常见坐标轴规范（📋 常见事实、非硬规则）：

- **Y 轴标零点**：柱状图、条形图 Y 轴起始值建议为 0（截断易误导）
- **对数轴标注**：使用对数轴时在轴标签或图注中显式说明（如"log scale"）
- **双 Y 轴慎用**：双 Y 轴易引起误读，必要时标注两轴对应关系
- **刻度数量适中**：主刻度建议 5-8 个，避免过密读不清、过疏难定位
- **轴标签完整**：含变量名 + 单位（如"反应时间 (ms)"、"浓度 (mol/L)"）

### 组件 e · 工具类陈列

按梯队陈列常见绘图工具（陈列、不推荐、用户拍板）：

| 梯队 | 工具 | 适合场景 |
|---|---|---|
| **编程式** | matplotlib（Python）、ggplot2（R）、plotly（交互） | 可复现、批量、版本可控 |
| **桌面式** | Origin、GraphPad Prism、Excel | 拖拽式、快速出图 |
| **学术专用** | TikZ（LaTeX） | 推导图、交换图、函数曲线（数学/理论物理） |
| **第三梯队专项** | TimelineJS（时间线）、QGIS（地理地图）、Graphviz（关系图） | 人文学科/地理可视化/概念关系图 |

工具选择标 ❓ 待用户决定。
