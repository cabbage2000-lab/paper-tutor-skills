# 起步与导航

先读[入口路由约定](../_shared/references/入口路由约定.md)，再按用户意图读取下面**一个相关流程**，直接承接用户已经提供的材料和要求。表中是内部选择依据，不是让用户逐项选择的菜单；明确意图不再问“要用哪个命令”。

覆盖：起步与导航。数据采集、实验与原创研究判断仍由研究者负责。其他阶段按[公开清单](../_shared/commands.yaml)转入对应入口。

| 用户想做什么 | 内部流程 |
| --- | --- |
| 建项目 | [init](../paper-init/WORKFLOW.md) |
| 导航与进度 | [help](../paper-help/WORKFLOW.md) |
| 环境体检 | [doctor](../paper-doctor/WORKFLOW.md) |

没有具体意图时，先读 `_shared/VERSION` 显示实际版本（读不到则省略），用一句话问“你现在想完成什么？”并给建项目、找文献、写作、检查、投稿五种日常说法。只有用户要求完整菜单时才展示 5 个公开入口。明确要求建项目或体检时直接进入该流程；看进度时读导航与进度流程。
