# 导航与研究进度（内部流程 paper-help）

用户要了解能做什么时，读取[公开清单](../_shared/commands.yaml)，展示其中五个入口的一句话用途；给一个最贴近用户情况的下一步。已明确任务时直接读取该入口并承接，不让用户再选内部命令。

## 查看进度

本分支只读，不创建 `.paper/`、不写留痕。向上寻找最近的 `.paper/`，不存在时如实说明没有可读记录，可用 `/paper-help 帮我建项目` 起步；存在但没有可识别记录时也明确说明，不编造进度。

读取[内部能力清单](../_shared/workflows.yaml)，以 `name` 为历史留痕 ID，`phase` 为研究阶段，`entry` 和 `request_zh` 为对外显示字段。扫描 `.paper/` 下的 Markdown，识别 `## 日期 · paper-xxx 描述` 与 `- 产物：路径`。同一内部能力多次执行保留所有记录，按时间倒序展示，统计活动数时按内部 ID 去重；缺日期或产物标 `—`，产物不存在标“产物缺失”，不识别的标题跳过。旧 `paper-topic`、`paper-search` 等 ID 继续识别，不能只拿五个公开入口匹配旧记录。

按 A/C/D/E 阶段显示已记录的中文任务、日期、产物和所属公开入口；B 固定说明数据采集、实验与分析由研究者完成。跨阶段区仅展示建项目与每日追踪记录，导航和体检不算研究进度。阶段 A–E 的归属由内部清单决定，与新的入口分组可以不同。

摘要仅陈述记录数、覆盖的阶段数，不把记录数称为研究完成度。用户要看全部能力时可以按目的展开中文任务与发布状态，但不得再列成一排独立旧命令。若要给下一步，最多列两个与当前材料相关的任务，以“你可能想做”表达，使用公开入口加自然语言；开发中能力不作为可执行建议，不自动开启未请求的流程。

导航不生成研究产物，因此不写 `.paper/`；真实产物流程仍按[留痕契约](../_shared/references/留痕契约.md)记录。越界请求按[边界拒绝清单](../_shared/references/边界拒绝清单.md)转化，不能把导航说成无人确认生成整篇论文的入口。
