# 题录格式说明（paper-import references）

> **陈列性、参考性**——本库陈列知网 / Zotero / EndNote 常见导出格式的字段映射，
> 供 paper-import **第 1 步解析题录**时参考。各导出工具版本可能有差异，
> 解析失败的标"⚠️ 字段解析失败"、不强猜。

## 笔记表五字段（题录通常不含、标占位）

笔记表五字段（paper-search 产物的核心）：

- **研究问题**：该文献研究什么问题
- **方法**：用什么方法
- **数据**：数据来源 / 样本
- **结论**：主要发现
- **不足**：该文献的局限 / Gap

**题录通常不含这五字段**（除非摘要里隐含研究问题 / 结论）。故 import 整理入笔记表时，五字段一律标"⚠️ 待用户或 /paper-search 补"——绝不凭题录的标题 / 摘要猜测填充（违反不变①题录不编）。

五字段需读文献全文后由用户补、或在 `/paper-search` 检索时由 AI 据全文摘要补——import 不承担五字段填充。

## 格式识别规则

- **.ris**：国际通用格式（知网 / Zotero / EndNote 都可导出），标签 `TY-` 起始、`ER-` 结束
- **.txt（知网自定义）**：知网"RefWorks"或"EndNote"导出、字段标签可能中文（"作者:""题名:"）
- **.csv（Zotero）**：表头英文（Author / Title / Publication ...）
- **.json（Zotero RDF / Better BibTeX）**：结构化 JSON、字段 key 取决于导出器
- **.bib（BibTeX）**：`@article{key, author={...}, ...}` 结构
- **.enw（EndNote）**：`%A 作者`、`%T 标题` 等百分号标签
- **粘贴文本**：无明确格式 → AI 按内容特征启发式识别、或请用户确认格式

识别失败 → 提示用户确认格式或粘贴原文、不强猜。

## 一致性核对字段对应规则（第 2 步核对用）

题录-草稿一致性核对按以下规则匹配：

1. **草稿引用 → 题录**：草稿引用（如 `[Smith 2023]`）按"第一作者姓 + 年份"匹配题录；匹配不到则按标题关键词模糊匹配；都匹配不到标"⚠️ 无对应题录"。
2. **题录 → 草稿引用**：题录按同规则反查草稿引用；未被引标"📋 未引"。
3. **字段级差异**：匹配上的条目，逐字段比作者全名 / 年份 / 标题 / 期刊；差异陈列（如草稿"Smith 2023"vs 题录"Smith J., 2022"→ 年份差异）。

**不判对错**——只陈列对应关系与差异。"无对应"不判编造（交 verify）、"字段差异"不判"哪个对"。
