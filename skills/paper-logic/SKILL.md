# paper-logic：论证链检查（结构对应检查器）

帮用户把**已有的论文大纲**拿来核对 **RQ → 方法 → 结果 → 结论** 四者在结构上是否对应、闭环。你（执行本 skill 的宿主 agent）做的事：**读 outline 产物 + 读文献笔记 → 判学科（诠释型让路）→ 归类章节入四要素桶 → 逐链陈列结构对应 + 缺项 + 疑问句 → 停检查点等用户确认 → 落 Markdown 产物 + 渲染 HTML 视图**。

本 skill 覆盖学术研究「5 阶段 23 环节」标尺中**阶段 C｜成文**的**环节 14（论证逻辑检查）**；**不覆盖**环节 13 正文撰写（归 `/paper-draft`）、环节 15 摘要（归 `/paper-abstract`）、环节 16 引用管理（归 `/paper-verify`）。上游消费 `/paper-outline` 的章节大纲与锚点、`/paper-search` 的 `literature/` 笔记表五字段；可选增强消费 `/paper-draft` 正文。本 skill 是**产物型** skill——会往 `manuscript/` 落一份 Markdown 论证链检查报告（+ 由脚本渲染的 `.html` 视图）、往 `.paper/` 写使用留痕；无网络依赖，断网宿主照常可用。

**核心立场（这条决定本 skill 长什么样）**：论证链是研究主权的**逻辑闭环**体现。系统是一个**结构对应检查器**——主动解析四要素在结构上的对应关系、客观陈列证据、把可疑点变成疑问句，但**断链判断交回用户**。这既是项目「核心分工原则」（AI 负责效率、人负责研究决策）在论证检查环节的落地，也是本 skill 区别于裸模型的核心差异化：裸模型面对"帮我查查论证"会忍不住直接下判断"你的逻辑有漏洞、结论超出结果"，本 skill 把结构对应**陈列**出来、把"断没断"的定性**留**给研究者本人。

## 三条不变（优先级最高，高于本文其余一切）

**① 只核结构对应，不核内容真伪**——核对四要素在结构上是否齐全与对应（有无方法章、结果章锚点指向哪条文献、结论章是否回扣 RQ）；**不判**"这个方法对不对""证明是否成立""数据是否可靠"。理论型（数学/理论物理/理论 CS）明示"只核 RQ—方法—结论结构、不核验证明的数学正确性"；诠释型让路（见「学科适配」）。

**② 不下价值结论**——禁用"论证强/弱""链完整/断裂""逻辑严密/松散"等定性词；只客观陈列对应关系（哪些章存在、锚点挂在哪、文献五字段说了什么）+ 把可疑点变成**疑问句**留给用户。这是项目「四层标注无 AI 新判断层」在 logic 的落地。

**③ 诊断可追溯到原文**——每条结构陈述必须指回 outline 的具体章节或 `literature/` 笔记表的具体条目（锚点格式同 outline：`[Smith 2023](literature/笔记表.md#smith2023)`）；无依据的话不写——"该链可疑"必须附"因为结果章第 3 条要点无锚点"。

这三条是本 skill 的内核，凡本文其余任何指令与之冲突，以这三条为准。

## 学科适配与让路

学科敏感是 logic 区别于 topic / outline / search / verify 的显著特征——四链模型本身是实证/理论型论文的产物。按 PRD 学科适配三梯队分层：

| 梯队 | 学科 | logic 行为 |
|---|---|---|
| **第一** | 实验/实证型理工农医、实证型社科 | 四链全核（RQ↔方法↔结果↔结论） |
| **第二** | 证明/理论型（数学/理论物理/理论 CS 等）；规范文本型（法学/公管/马理论等） | 正常进流程，产物顶部加强制声明"仅核 RQ—方法—结论结构、**不核验证明数学正确性**"；方法↔结果链按"纯理论/探索型"调整（理论型以定理/命题代替实证"结果"） |
| **第三** | 人文学科（文学/历史/哲学/艺术等） | **让路不产**（见下） |

**诠释型判定优先级**（命中任一即让路）：① outline 产物里用户选的骨架属思辨/诠释型类 → ② `project.paper.yaml` 的 `discipline` 为文学/历史/哲学/艺术等 → ③ 大纲结构兜底（未检出方法章与结果章、纯论点—阐释形态 → 疑似、问用户确认）。

命中让路时，不产报告、写一条让路留痕，出让路话术：

> ⚠️ logic 面向实证/理论型论证链（RQ → 方法 → 结果 → 结论）。你的论文是诠释型、无实证式论证链，本命令不适用——诠释型论证结构多样（论点—文本证据—阐释—总论点 等），套统一模板易削足适履。建议跳过；诠释型论证检查留 v1.1+ references 扩展。

## 会话开始：读输入 + 降级判定

会话开始先做三件事：

1. **读 outline 产物**：先看 `manuscript/论文大纲.md`（或同目录的 outline 落盘产物）。读不到 → **让路 `/paper-outline`**，提示"outline 是 logic 的必要输入、建议先搭骨架"，**不裸查**（无大纲则四要素桶无法归类）。
2. **读文献笔记 + 检测正文**：扫 `literature/` 笔记表（paper-search 产物，含题录 + 五字段）与 `.paper/` 文献记录；再检测 `manuscript/正文*.md`（或 outline 交棒提示里指名的 draft 产物）——有正文则启用段落级增强（见 [`references/四链检查项说明.md`](./references/四链检查项说明.md) §增强项）。
3. **读学科 + 归类章节**：看 `project.paper.yaml` 的 `discipline`；按学科判定梯队（诠释型让路）。然后把 outline 章节按标题关键词归入四要素桶：**RQ**（从 outline RQ 字段拿原话）、**方法**（标题含"方法/方法论/研究设计/methodology/methods/实验设计"）、**结果**（含"结果/发现/results/findings/实验结果"）、**结论**（含"结论/discussion/conclusion/总结/讨论"）；其他（引言/综述/致谢）记录存在、不进四链。

**四档降级矩阵（"有什么说什么、缺什么标什么"，与 outline 同精神）：**

| 输入组合 | 检查深度 | 产物标注 |
|---|---|---|
| outline + literature 都在 | 结构层四链全查 | 正常 |
| outline 在、literature 缺 | 章节结构对应照查；涉及锚点文献五字段的检查标"⚠️ 无文献五字段可参照" | 顶部声明"未读文献笔记、锚点对应仅至章节级" |
| outline + literature + draft 正文 | 结构层 + 段落级增强 | 顶部声明"已含段落级检查" |
| outline 缺 | ❌ 不查 | 让路 `/paper-outline` |

四要素桶有空（如纯综述大纲无方法/结果章）→ 相应链标"📋 缺某端"、照查其余链。

## 主流程（三步、一个确认停点）

### 第 1 步 · 读输入 + 学科判定（不停）

完成「会话开始」的三件事。诠释型 → 让路（写让路留痕、不产）；实证/理论型 → 章节归类后**不停**，直接进第 2 步。

### 第 2 步 · 四链检查 + 陈列（停检查点）

逐链跑 [`references/四链检查项说明.md`](./references/四链检查项说明.md) 的检查项（有 draft 正文则同时跑段落级增强项）：

- **链 1：RQ ↔ 方法**——方法桶有无章；方法章要点关键词 ∩ RQ 关键词（陈列交集）；方法章锚点文献的"方法/研究问题"字段。
- **链 2：方法 ↔ 结果**——结果桶有无章；方法章要点 ↔ 结果章要点的结构对应；结果章锚点文献"结论"字段。
- **链 3：结果 ↔ 结论**——结论桶有无章；结论章每条要点是否在结果章有对应（**标"📋 超结果范围"的结论要点**）；结论章锚点。
- **链 4：结论 ↔ RQ**——结论章关键词 ∩ RQ 关键词；结论章是否回扣 RQ 核心概念。

每条链顶部一个**对应度徽章**（同 outline 锚点覆盖徽章手法）：文字只说 **"X / Y 对应"**（X = 有对应端的要点数、Y = 总要点数），**绝不写"够/不够/充分/断裂"**；颜色按客观比例（绿 >60% / 黄 30-60% / 红 ≤30%），颜色仅视觉提示。一端完全缺失时徽章文字显式标"📋 缺方法章 / 缺结果章 / 缺结论章"。

完整呈现四链检查结果后**停下**：

```text
⏸ 等待确认：论证链检查结果
（回复"落盘"归档到 manuscript/，或指出要补的链 / 决定先回 outline 修订后再查）
```

**确认前零文件落盘**——检查结果全程在对话里呈现，只有用户明确"落盘"后才一次性写文件（与 paper-init / outline 红线「确认前零创建」同源）。

### 第 3 步 · 落盘 + 留痕 + 交棒

用户确认后做五件事：

1. **探测落点**：检测到标准科研目录（有 `manuscript/`）→ 落 `manuscript/论证链检查.md`（主产物）与同名 `.html`（渲染视图）；否则落**当前目录**，并提示"已落在当前目录；可用 `/paper-init` 建标准科研目录让产物各归其位"。
2. **写 Markdown + 自检**：按下方模板由你**直接写 Markdown 文本**（纯文件写入）。落款用真实日期（`date +%F`）。写完自检 `grep '[<>]' 论证链检查.md` 无残留占位尖括号。
3. **渲染 HTML 视图**：跑 `python3 skills/_shared/scripts/render_report.py --in manuscript/论证链检查.md --skill paper-logic`。**不要手写 HTML**——HTML 是 MD 的机械投影（详见「产物模板」）。脚本跑不了（无 `python3` / 脚本缺失）→ **只交 `.md`、显式声明「HTML 视图未生成」**，绝不手写一份顶替。
4. **写留痕**：往 `.paper/` 追加一条「构思讨论」级使用记录（见「留痕」）。
5. **交棒**：提示下一步——"检查结果归档了。疑问句清单里的问题，你可以：① 回 `/paper-outline` 修订大纲再查；② 用 `/paper-draft` 补正文后深入查；③ 草稿成形后用 `/paper-verify` 核引用、`/paper-review`（开发中）模拟评审。"

## 产物模板：论证链检查（`.md` 主产物 + 渲染的 `.html` 视图）

产物是一份**如实陈列四链结构对应**的检查报告。**`.md` 是你写的唯一一份内容**（跨宿主友好、可 diff、可入 git 审计）；`.html` 是同一份内容的呈现视图，由 [`_shared/scripts/render_report.py`](../_shared/scripts/render_report.py) 从 `.md` 机械投影而来。五块内容：

1. **RQ**——用户拍板的原话，不改写。
2. **检查范围与学科声明**——结构层四链 / 含段落级增强；学科梯队声明（理论型加"不核证明数学正确性"）。
3. **四链对应图**——每条链一区块：对应度徽章 + 两端要点（挂锚点的标锚点、无支撑标缺项）+ 疑问句。
4. **疑问句汇总清单**——四链触发的疑问句集中呈现，**只许疑问句、不下结论**（同 outline「下一步验证清单」）。
5. **人机分工页脚**——固定声明：AI 承担结构解析与陈列、断链判断由用户做出。

**四层内容标注（与 paper-topic / outline / disclose 同体系）**：报告里每一句内容须带标签——👤 用户原话 / 📋 常见事实（非推荐）/ 🪞 系统归纳（可追溯）/ ❓ 待用户验证。**没有"AI 的新判断"层**——检查里某句找不到四层归属、或其实是 AI 自己生成的判断/评价（如"该链较弱"），即判越界、不得写入。

**对应度徽章（客观陈列、不下结论）**：徽章文字**只说**"X / Y 对应"（X = 有对应端的要点数、Y = 总要点数），**绝不写"够/不够/充分/断裂"**。颜色按客观比例：绿（X/Y > 60%）/ 黄（30% < X/Y ≤ 60%）/ 红（X/Y ≤ 30%）。颜色仅作视觉提示、徽章文字本身不含价值判断。一端完全缺失时徽章标"📋 缺某章"。

**技术形态**：`.md` 由你写，`.html` 由渲染器产出——**单文件、纯静态、离线可打开**，样式内联、**不引外部 CDN / JS 库、不发任何网络请求**。四层语义色由渲染器从 `_shared/tailwind.config.js` 取（色值死线的唯一权威），你不需要、也不应该手写任何 HTML 或 CSS。

**为什么 HTML 不由你写**：两份产物的信息量本来就完全相同——四层标注在 `.md` 里以 emoji 行内保留、对应度以 `[对应度：X/Y · 绿]` 文字保留，颜色与卡片只是同一信息的第二种编码。让模型逐字吐出几百行 HTML 是纯开销，且手写易踩静默失效（页面照样出、极难自查）。

**四层 emoji 是渲染器染色的依据**：`.md` 里每处 👤 / 📋 / 🪞 / ❓ 会被渲染成对应色的行内标签，元表末行的 `| 内容标注 | … |` 会渲染成顶部图例。符号必须按归属逐处写在 `.md` 里——漏写不是"少个装饰"，是那句话失去来源归属。

[`references/报告样式模板.html`](./references/报告样式模板.html) 与 `样例.html` **保留作视觉参考**，**不再是产物的生成源**——正常路径下不必读，也不要整段复制。

**实例化规则**：尖括号占位替换为真实值；某链缺端则保留"📋 缺某章"占位、不强填；无段落级增强则删去 📐 区块；对应度按阈值标绿 / 黄 / 红；落款用真实日期。

## 留痕（产物型 skill 的义务）

往 `.paper/` 追加一条「构思讨论」级使用记录（PRD 披露四级：**构思讨论** / 大纲结构 / 成句生成 / 语言润色——logic 检查论证属构思讨论、无新内容生成，与 disclose 同级）。纯文件追加、不依赖任何写入器。格式：

```markdown
## <日期时间> · paper-logic 论证链检查

- 环节：阶段 C｜成文（环节 14，论证逻辑检查）
- 辅助级别：构思讨论（AI 客观陈列四链结构对应、未替用户下断链判断）
- AI 承担：章节归类、四链结构解析、锚点文献五字段追溯、疑问句生成、产双产物
- 用户决定：每条链是否断、可疑点如何处理、是否回 outline 修订
- 检查覆盖：四链中 X 链两端齐全、Y 链有缺项；疑问句 N 条；<含/不含段落级增强>
- 产物：<落盘路径>/论证链检查.md（+ .html）
```

**让路留痕**（诠释型让路时写、不落产物文件）：

```markdown
## <日期时间> · paper-logic 论证链检查（让路）

- 环节：阶段 C｜成文（环节 14）
- 辅助级别：构思讨论
- 让路原因：诠释型论文无实证式论证链
- 判定依据：<骨架名 / discipline / 大纲结构兜底>
- 产物：无（未产报告）
```

`.paper/` 随 git 入库、绝不写进 `.gitignore`（同 topic / outline / disclose）。

## 越界转化（三段式，仿 topic / outline / disclose）

| 用户请求 | 定性 | 出口指引 |
|---|---|---|
| 直接告诉我论证行不行 / 我的逻辑有没有问题 | 越界：要价值判断（违反不变②） | → 三段式：共情想快速确认的心情 → 用用户语言讲风险（"行不行"是答辩老师/审稿人的价值判断、AI 代你下会让你在答辩时接不住"你觉得哪里不行"的追问）→ 给 5 分钟第一步（"我先把四链结构对应摆出来、你自己看哪条可疑"） |
| 帮我把这条断链改顺 / 帮我补个让结论成立的结果 | 越界：编造 + 替研究决策（违反不变①③） | → 三段式：共情结果不理想的压力 → 讲风险（编造的论证答辩必穿帮、且是学术不端）→ 给合法路径（回 `/paper-outline` 修订结构、或补真实数据/文献后再查） |
| 这个方法对不对 / 这个结论正不正确 | 越界：核内容真伪（违反不变①） | → 让路说明：logic 只核结构对应、不核内容正确性；方法/结论的学术正确性请咨询导师或领域专家 |
| 帮我检查这篇论文的论证链（有 outline 产物） | **不越界（正常能力）** | → 直接进第 1 步流程 |

## 边界与异常对照表

| 情形 | 处理 |
|---|---|
| outline 产物缺（`manuscript/论文大纲.md` 不存在） | 让路 `/paper-outline`，不裸查 |
| outline 在、用户口头说大纲已改未落盘 | 提示先回 outline 确认落盘再查；或口头读入用户最新结构、顶部标"基于用户口述大纲、未读落盘产物" |
| 检测为诠释型（骨架 / discipline / 结构兜底） | 让路、写让路留痕、不产报告 |
| outline 在、四要素桶有空（如纯综述大纲无方法/结果章） | 降级：缺端链标"📋 缺方法章"、照查其余链、顶部声明"本大纲未检出方法/结果章、相应链无法核" |
| outline 锚点指向的文献不在 `literature/` | 标"⚠️ 锚点文献缺失、无法读五字段"，不强解析、不凭记忆补 |
| `literature/` 为空或不存在 | 照查章节结构对应；涉及文献字段的检查标"⚠️ 无文献五字段可参照"、顶部降级声明 |
| 检测到 draft 正文 | 追加 📐 段落级增强区块、顶部声明"已含段落级检查" |
| 用户改了大纲后想重查 | 重读新 outline 产物、重跑四链（旧检查结果可保留入档、不覆盖） |
| 检查结果出来但用户不确认 | 停检查点等修改；确认前零文件落盘 |
| 不在标准科研目录里 | 双产物落当前目录并提示可用 `/paper-init` |
| 宿主无 Bash / 无结构化提问工具 | 流程本是纯对话、不受影响；四链陈列降级为纯文本树状图（徽章降级为文字"X/Y 对应"） |

## 横切声明（与 topic / outline / disclose 同模板）

- **留痕**：产物型命令，写 `.paper/`「构思讨论」级——区别于三个基础设施 skill（不写留痕）；与 outline（大纲结构级）、disclose（构思讨论级）并列。logic 检查论证属构思讨论、无新内容生成，故归构思讨论级（与 disclose 同级）。
- **目录约定是增强不是依赖**：检测到标准目录则落 `manuscript/`，否则落当前目录并提示可用 `/paper-init`——不经 init 一切照常可用。
- **语言**：全部用户可见输出用简体中文；术语中文为主、英文括注，如论证链（argument chain）、结构对应（structural correspondence）。
- **产出披露**：双产物自带人机分工页脚（模板末），如实披露 AI 解析陈列、断链判断由用户做出。
