# 四链检查项说明（paper-logic references）

> 本文件陈列 RQ→方法→结果→结论 实证式论证链的**客观常见结构检查点**。**不是"唯一正确"的论证范式**——
> 用户可自行增删检查项、可只查其中几链。结构对应与否的最终判断权 100% 归用户。
> 与 paper-topic「选项死线」、paper-outline「骨架非推荐」一脉相承：摆事实、不推荐、不排序、不打分。
>
> SKILL.md 第 2 步逐链检查时引用本表——按 outline 产物实际章节结构选用对应检查项、不强求四链全跑（缺端链只标缺项）。

## 对应度徽章口径

每条链顶部一个对应度徽章（同 outline 锚点覆盖徽章手法）：

- **文字只说 "X / Y 对应"**（X = 有对应端的要点数、Y = 总要点数），**绝不写"够/不够/充分/断裂"**
- **颜色按客观比例**（仅视觉提示、不含价值判断）：
  - 🟢 绿：X/Y > 60%
  - 🟡 黄：30% < X/Y ≤ 60%
  - 🔴 红：X/Y ≤ 30%
- **一端完全缺失**：徽章文字显式标"📋 缺方法章 / 缺结果章 / 缺结论章"（客观事实、不是定性）

## 四链定义（结构层）

### 链 1：RQ ↔ 方法（方法能否回答 RQ？）

**客观检查项**：
- 方法桶有无章（无 → 📋 缺方法章）
- 方法章要点关键词 ∩ RQ 关键词（陈列交集、不判"够不够"）
- 方法章锚点文献的"方法/研究问题"字段（陈列文献方法、不判"能不能回答"）

**数据来源**：outline 方法章要点 + 锚点文献五字段

**疑问句触发（示例）**：
- "RQ 问的是 X，方法章要点用的是 Y——方法能否收集到回答 X 的数据？"
- "方法章挂的 [Smith 2023] 用问卷调研、你的 RQ 问的是机制因果——问卷能否回答因果？"

### 链 2：方法 ↔ 结果（结果是否来自方法？）

**客观检查项**：
- 结果桶有无章（无 → 📋 缺结果章）
- 方法章要点 ↔ 结果章要点的结构对应（如方法有"问卷调研"、结果有"问卷结果" → 陈列对应；无对应 → 陈列缺口）
- 结果章锚点文献"结论"字段

**数据来源**：outline 方法/结果章要点 + 锚点

**疑问句触发（示例）**：
- "方法章提到 X 方法，结果章未见 X 方法产出的结果——结果是否来自该方法？"
- "结果章第 2 条无方法章对应要点——该结果由何种方法产出？"

### 链 3：结果 ↔ 结论（结论是否由结果支撑？）

**客观检查项**：
- 结论桶有无章（无 → 📋 缺结论章）
- 结论章每条要点是否在结果章有对应（**标"📋 超结果范围"的结论要点**）
- 结论章锚点文献

**数据来源**：outline 结果/结论章要点 + 锚点

**疑问句触发（示例）**：
- "结论章第 2 条'X 导致 Y'，结果章未见该因果结果——此结论由本研究结果支撑，还是文献推测？"
- "结论章有 3 条要点、结果章仅 2 条对应——超范围的 1 条来自何处？"

### 链 4：结论 ↔ RQ（结论是否回答 RQ？闭环）

**客观检查项**：
- 结论章关键词 ∩ RQ 关键词（陈列交集）
- 结论章是否回扣 RQ 核心概念（直接引用式回扣 vs 完全不提）

**数据来源**：outline 结论章 + RQ 字段

**疑问句触发（示例）**：
- "RQ 问'X 对 Y 的影响'，结论给的是'X 与 Z 的关系'——结论回答了你的问题吗？"
- "结论章未提及 RQ 的核心概念 W——闭环了吗？"

## 段落级增强项（检测到 draft 正文时追加）

检测到 `manuscript/正文*.md`（或 outline 交棒提示里指名的 draft 产物）时，每条链追加 **📐 段落级增强检查**区块（不替换结构层、不另出报告）：

| 链 | 段落级增强检查项 | 数据来源 |
|---|---|---|
| 链 1 | 方法章正文段落是否真描述了该方法（而非仅列要点）；是否提及 RQ 的核心变量/对象 | draft 方法章段落 |
| 链 2 | 结果章正文段落是否报告了方法章所述方法产出的数据 | draft 方法/结果章段落 |
| 链 3 | 结论章正文是否引入了结果章未出现的新论据/新数据（**标"📋 超结果范围的新论据"**） | draft 结果/结论章段落 |
| 链 4 | 结论章末段是否显式回应 RQ | draft 结论章末段 |

段落级检查标 📐、与结构层检查视觉区分；其疑问句同样只许疑问句、不下结论。

## 疑问句生成规则

- **只许疑问句**（以"？"结尾），禁陈述句定性（如"该链断裂"）
- **指向具体可核查点**（章号、要点序号、锚点文献名），不泛泛而问
- **不下价值结论**（禁"强/弱/好/差"），只摆事实缺口让用户自己判
- **每条链触发的疑问句汇总到产物「疑问句汇总清单」**（同 outline「下一步验证清单」）
