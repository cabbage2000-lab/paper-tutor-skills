# 伦理审查提示清单（paper-method references）

> **陈列性、非判断性**——本清单是研究伦理**常见关注点**的提示，让用户自查。
> **绝不是伦理审查结论、更不是豁免判断。** 最终是否需要伦理审批、审批流程、合规标准，
> 一律以用户所在机构规定为准——**此项须经机构确认，AI 不能替代。**
>
> 本清单供 paper-method **涉人类被试检测命中时强制陈列**（PRD §282 / §390）。
> 检测命中即出全文，不省略、不替用户下"伦理无问题"结论。

## 触发条件（涉人类被试检测）

paper-method 会话第 1 步扫 RQ 原话 + 用户方法描述 + 学科，命中以下信号**任一**即触发本清单强制陈列：

- **关键词**：问卷 / 访谈 / 实验 / 被试 / 患者 / 学生数据 / 用户数据 / 个人信息 / 隐私 / 行为数据 / 临床 / 病历 / 生物样本
- **学科高风险**：医学 / 心理学 / 教育学 / 社会学 / 管理学（实证）/ 护理学 / 公共卫生 / 人类学
- **RQ 涉及**：人类行为 / 态度 / 心理 / 健康 / 教育成效 / 社会互动 / 个人经历

**未命中也非零风险**：自动检测基于启发式、**可能漏判**（如 RQ 措辞未明示但实际涉人）。故产物顶部固定自检声明：

> 本 RQ 与方法描述未检出涉人类被试 / 个人数据信号。自动检测基于关键词 + 学科 + RQ 形态，**可能漏判**——若你的研究实际涉人类被试（即使未在 RQ 中明示），请主动按下表自查。

## 六项伦理审查常见关注点

每项配疑问句交回用户——**清单不下结论、只提示常见关注点 + 问用户自查**。

### 1. 知情同意（Informed Consent）

**常见关注点**：研究对象是否充分知情并自愿同意参与；知情同意书是否说明研究目的、流程、风险、收益、退出权、数据用途；未成年人 / 限制行为能力人需监护人同意；欺骗性研究需事后 дебriefing。

**疑问句（交回用户）**：
- "你的被试如何被告知研究目的、风险与退出权？知情同意书拟了吗？"
- "被试是否含未成年人或限制行为能力人？是否需要监护人同意？"
- "如果研究有隐瞒 / 欺骗成分，事后如何 debriefing？"

### 2. 匿名化 / 去标识化（Anonymization）

**常见关注点**：个人可识别信息（姓名 / 学号 / 身份证号 / 联系方式 / 痕迹性陈述 / 小样本罕见特征）是否去标识化；去标识后的数据是否仍能间接追溯个人（如小样本 + 罕见特征组合）；公开材料（引文 / 案例）是否充分化名 / 改写。

**疑问句（交回用户）**：
- "你的数据如何去标识？哪些字段是可识别的？"
- "去标识后是否还有间接识别风险（如小样本 + 罕见特征组合）？"
- "论文里引用被试原话 / 案例，是否充分化名 / 改写以避免追溯？"

### 3. 机构审批（Institutional Approval）

**常见关注点**：是否须经学校 IRB（机构伦理审查委员会）/ 伦理委员会 / 院系审批；学位论文涉人类被试研究通常必审；审批号 / 豁免函是答辩与投稿的常见必备材料；不同机构审批流程与豁免标准不同。

**疑问句（交回用户）**：
- "你所在机构对涉人类被试研究是否要求伦理审批？"
- "审批号 / 豁免函拿到了吗？学位论文与投稿通常要附。"
- "你的研究是否符合你所在机构的豁免标准（如完全匿名的现有数据可能豁免）？豁免也需正式函。"

### 4. 风险评估（Risk Assessment）

**常见关注点**：身体风险（如医学实验）、心理风险（如敏感话题引发情绪困扰 / 创伤触发）、社会风险（如数据泄露导致污名化 / 歧视）、经济风险（如信息泄露影响就业）；风险程度与缓解措施（如心理支持资源、退出机制、数据保护）；风险-收益比是否可接受。

**疑问句（交回用户）**：
- "参与可能面临哪些风险（含心理与社会风险，如敏感话题引发情绪、数据泄露导致污名）？"
- "如何缓解？是否有心理支持资源、退出机制、数据保护措施？"
- "风险-收益比是否可接受？高风险研究是否需要额外保护？"

### 5. 数据安全（Data Security）

**常见关注点**：原始数据存储位置（加密存储 / 物理隔离）、传输方式（避免不加密邮件 / 即时通讯传敏感数据）、访问控制（仅研究团队）、保留期限、销毁方式；**PRD §390 警示：涉个人可识别信息的原始数据（访谈转录、问卷原始记录）不应输入本工具（含 AI 对话）**。

**疑问句（交回用户）**：
- "原始数据存哪、谁能访问、保留多久、如何销毁？"
- "传输是否加密？是否避免用不安全的渠道（如即时通讯）传敏感数据？"
- "数据是否含不应输入 AI 工具的可识别信息？AI 辅助分析前是否先去标识？"

### 6. 脆弱人群保护（Vulnerable Populations Protection）

**常见关注点**：被试是否含脆弱人群（未成年人 / 孕妇 / 患者 / 囚犯 / 认知障碍者 / 受访者中的权力弱势方如学生-教师、员工-雇主、难民）；脆弱人群需额外保护（如更严格的知情同意、更低的风险阈值、额外的监护人 / 代理人参与）。

**疑问句（交回用户）**：
- "你的被试是否含脆弱人群（未成年人 / 患者 / 囚犯 / 权力弱势方等）？"
- "如含脆弱人群，是否需要额外保护（更严格的同意、更低的风险阈值、监护人参与）？"
- "你和被试之间是否有权力关系（如导师-学生、雇主-员工）？如何避免自愿性被影响？"

## 末尾固定声明（须逐字保留、不可省略）

> ⚠️ **本清单是研究伦理常见关注点的提示，不是伦理审查结论，更不是豁免判断。**
>
> **最终是否需要伦理审批、审批流程、合规标准，一律以你所在机构（学校 IRB / 伦理委员会 / 院系）的规定为准——此项须经机构确认，AI 不能替代。**
>
> 如有疑问，请咨询你的导师或机构伦理审查委员会。涉个人可识别信息的原始数据（访谈转录、问卷原始记录）**不应输入本工具**。
