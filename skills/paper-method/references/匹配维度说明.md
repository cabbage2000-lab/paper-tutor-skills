# 方法-RQ 匹配维度说明（paper-method references）

> **陈列性、非推荐性**——本表是实证 / 理论型研究的**方法-RQ 结构匹配常见检查点**，
> 非"唯一正确"的方法学规范。用户可自行增删检查项。最终方法选择 100% 归用户与导师。
>
> 本表供 paper-method **检查模式**第 2 步引用：逐维度陈列方法与研究问题（RQ）的结构
> 对应、客观摆出缺口、把可疑点变成疑问句。**零定性词**——不写"匹配 / 不匹配""合适 /
> 不合适"，只陈列"X / Y 对应"+ 疑问句。

---

## 四匹配维度（实证型，结构层）

每条维度 = 客观陈列两端对应 + 缺口标注 + 疑问句触发。

### 维度 1：变量对应　[匹配度徽章：X/Y 对应 · <绿/黄/红>]

**客观检查项**：RQ 的核心变量（自变量 / 因变量 / 关键概念）∩ 方法能操作化 / 测量的变量；陈列交集与缺口。

**数据来源**：topic 产物 RQ 原话 + 用户方法描述；有 literature 笔记表时附文献"方法"字段先例。

**陈列格式**：
- RQ 核心变量　👤：<用户原话 RQ 里的变量，不改写>
- 方法可操作化变量　🪞：<用户方法描述里的操作化>
  - <变量> · 文献先例 [Smith 2023](literature/笔记表.md#smith2023)（方法=问卷, 测量=X 量表）
  - <变量> · 无先例参照
- 缺口　📋：<无 / RQ 的 Y 变量方法未覆盖>
- 疑问句　❓：<只许疑问句，如"RQ 问的是 X 对 Y 的影响，你的方法能测量 X 和 Y 吗？X 怎么操作化？">

**疑问句模板（示例，不穷举）**：
- "RQ 问的是 X 对 Y 的影响，你的方法能测量 X 和 Y 吗？"
- "X 这个概念在你的方法里怎么操作化？用单一指标还是多指标？"
- "RQ 里的 Z（调节 / 中介变量）你的方法控制了吗？"

### 维度 2：数据类型　[匹配度徽章：X/Y 对应 · <绿/黄/红>]

**客观检查项**：方法产出的数据类型（数值 / 类别 / 文本 / 行为记录 / 语料）能否支撑 RQ 的分析需要。

**数据来源**：用户方法描述 + literature 笔记表"方法 / 数据"字段。

**陈列格式**：同维度 1（方法端数据类型 vs RQ 分析需要、陈列对应 / 缺口 / 疑问句）。

**疑问句模板（示例）**：
- "RQ 要做因果推断，你的方法产出的是相关数据——因果需要什么额外设计（如随机分配 / 工具变量）？"
- "你的方法是访谈（文本数据），RQ 要的是 X 的发生率（数值）——文本数据能否支撑数值估计？"
- "RQ 关心 X 的长期变化，你的方法是横截面（单时点）——长期变化需要追踪设计吗？"

### 维度 3：解释力　[匹配度徽章：X/Y 对应 · <绿/黄/红>]

**客观检查项**：RQ 的意图（描述 / 相关 / 因果 / 机制解释 / 探索）∩ 方法的解释力层级。

**数据来源**：topic RQ 形态（RQ 措辞推断意图）+ 方法类常识（📋 常见事实）。

**陈列格式**：RQ 意图端（👤/🪞）vs 方法解释力端（📋/🪞）、陈列对应 / 缺口 / 疑问句。

**RQ 意图与方法解释力对应（📋 常见事实，非穷举）**：
| RQ 意图 | 典型措辞 | 能回答的方法类（常见） |
|---|---|---|
| 描述 | "X 的现状 / 分布 / 特征" | 调查 / 内容分析 / 现有数据 |
| 相关 | "X 与 Y 是否有关 / 相关" | 调查 / 现有数据（相关分析） |
| 因果 | "X 是否导致 / 影响 Y" | 实验 / 准实验 / 自然实验 |
| 机制 | "X 通过什么机制影响 Y / 为什么" | 实验 + 过程测量 / 混合方法 / 深度访谈 |
| 探索 | "X 是什么样的 / 如何理解 X" | 深度访谈 / 扎根理论 / 案例研究 |

**疑问句模板（示例）**：
- "RQ 问'为什么'（机制），实验法通常回答'是否'（因果存在）——机制需要补充什么（如过程测量 / 访谈）？"
- "RQ 是探索性的（'X 是什么样的'），问卷是结构化的（预设答案）——开放性探索是否更适合访谈？"

### 维度 4：样本与总体　[匹配度徽章：X/Y 对应 · <绿/黄/红>]

**客观检查项**：方法选取的样本能否代表 RQ 关心的总体；样本量是否合理（陈列常见区间、**不判"够不够"**）。

**数据来源**：用户方法描述 + 学科样本量常识（📋 常见事实）。

**陈列格式**：RQ 总体端（👤/🪞）vs 方法样本端（🪞/📋）、陈列对应 / 缺口 / 疑问句。

**样本量常识（📋 常见事实，陈列常见区间、不下"够 / 不够"结论）**：
- 实验研究：每组常见 30+ 起步（功效分析依效应量而定）
- 调查研究：常见数百至数千，依总体规模与抽样设计
- 访谈研究：常见 12-30 人至饱和（饱和点因研究而异）
- 内容分析：常见编码单位数百至数千

**疑问句模板（示例）**：
- "你的样本是 X 校本科生，RQ 关心的是'大学生'——外推到其他学校 / 层次有多大风险？"
- "你的访谈样本 8 人，常见饱和区间 12-30——是否需要再访谈补充，还是你的研究目的不要求饱和？"

## 理论型调整（第二梯队：数学 / 理论物理 / 理论 CS 等）

理论型研究无假设-变量-数据实证链，按"纯理论 / 探索型"调整（PRD §281），**不强套实证模板**：

| 维度 | 实证型（原） | 理论型（调整后） |
|---|---|---|
| 变量对应 | RQ 核心变量 ∩ 方法操作化 | RQ 核心概念 ∩ 推理工具（公理 / 定义 / 模型假设）|
| 数据类型 | 方法产出的数据类型 vs RQ 分析需要 | 推导前提 / 模型假设是否完备、与 RQ 核心命题对应 |
| 解释力 | RQ 意图 ∩ 方法解释力 | 证明强度（严格证明 / 启发式论证）/ 模型解释力 |
| 样本与总体 | 样本代表性 | 让路（理论型无样本概念，跳过此维度、标"📋 理论型无样本维度"）|

理论型检查顶部加强制声明（同 paper-logic 第二梯队声明）："本检查按纯理论 / 探索型调整、不强套实证模板；只核 RQ—方法—结论的结构对应、不核验证明的数学正确性。"

## 匹配度徽章规则（客观陈列、不下结论）

每维度顶部一个匹配度徽章（同 paper-outline 锚点覆盖徽章 / paper-logic 对应度徽章手法）：

- **文字只说 "X / Y 对应"**（X = 有对应的子项数、Y = 总子项数），**绝不写"够 / 不够 / 充分 / 不足 / 匹配 / 不匹配"**。
- **颜色按客观比例**（仅视觉提示、徽章文字本身不含价值判断）：
  - 绿（X/Y > 60%）
  - 黄（30% < X/Y ≤ 60%）
  - 红（X/Y ≤ 30%）
- **一端完全缺失时**徽章文字显式标"📋 缺 RQ 变量端 / 缺方法端"（客观事实、不是定性）。

## SKILL.md 怎么用本表

检查模式第 2 步：逐维度跑本表检查项，按陈列格式产出（维度名 + 徽章 + 两端子项 + 缺口 + 疑问句）。本表是静态参考文档（非脚本），SKILL.md 按 RQ 形态与学科选用对应维度、不强求四维度全跑（理论型跳过样本维度、诠释型让路不跑）。
