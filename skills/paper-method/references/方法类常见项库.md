# 方法类常见项库（paper-method references）

> **陈列性、非推荐性**——本库陈列的是各学科**常见**的方法类，
> 非"推荐的方法"。具体选哪个、怎么组合，**由用户与导师决定**。
>
> 本库供 paper-method **引导模式**第 2 步引用：摆该 RQ 类型 / 学科学界客观常见的方法类，
> 仿 paper-topic 选项死线（摆事实不推荐不排序、每组带末项"以上都不是，我自己说"）。
> 用户选定 / 自填后回切检查模式对该方法跑匹配维度。

---

## 摆出规则（仿 paper-topic 选项死线）

- **只摆该方向学界客观常见的方法类**：每组方法类前明说"这些是这个方向常见的、不是我推荐的，供你参考、也可以都不要"。
- **三不**：不排序、不打分、不标"最优 / 推荐 / 更适合 / 更好"；方法类之间无优劣序、呈现顺序不得暗示偏好。
- **每组固定带末项"以上都不是，我自己说"**：用户任何一步都能弃选、自己给，系统即以其自填为准继续。
- **四字段陈列**：每类配"研究什么 / 常见于什么学科 / 能回答什么 RQ 类型 / 局限"——摆客观事实、不评判优劣。

## 第一梯队：实证型常见方法类（实验 / 实证型理工农医、实证型社科）

### 实验法（Experimental Design）

- **研究什么**：在受控环境下操纵自变量、测量因变量、控制干扰变量，检验因果效应
- **常见于**：心理学、教育学、医学、工程技术、农学、管理学的因果检验
- **能回答什么 RQ**：X 是否导致 / 影响 Y（因果存在性与方向）
- **局限**：实验室环境外部效度受限；伦理约束部分变量不可操纵；需随机分配

### 准实验设计（Quasi-Experiment）

- **研究什么**：在自然情境下利用现成分组 / 自然事件做对照，近似因果推断
- **常见于**：教育学（教改）、政策评估、公共卫生、社会学
- **能回答什么 RQ**：政策 / 干预的近似因果效应（无法随机分配时）
- **局限**：内部效度弱于真实验（选择性偏差 / 混淆变量需统计控制）

### 问卷调查（Survey）

- **研究什么**：用结构化问卷大规模收集态度 / 行为 / 特征数据
- **常见于**：社会学、心理学、市场营销、管理学、教育学
- **能回答什么 RQ**：X 的现状 / 分布 / X 与 Y 的相关 / 群体差异（描述与相关）
- **局限**：相关非因果；自陈数据有社会期许偏差；需信效度证据

### 深度访谈（In-depth Interview）

- **研究什么**：半结构化访谈深入理解个体经历 / 观点 / 意义建构
- **常见于**：社会学、人类学、教育学、护理学、管理学（质性）
- **能回答什么 RQ**：X 是什么样的 / 人们如何理解 X（探索与机制）
- **局限**：样本小、外部效度弱；分析主观性；需编码信度

### 焦点小组（Focus Group）

- **研究什么**：6-10 人小组讨论，捕捉群体互动下的观点与共识
- **常见于**：市场营销、公共卫生、政策研究、社会学
- **能回答什么 RQ**：群体对 X 的看法 / 需求 / 反应（探索 + 群体动力）
- **局限**：群体思维风险；主持技巧敏感；不宜做个体层面推断

### 现有数据分析（Secondary Data Analysis）

- **研究什么**：分析已公开 / 已采集的数据集（政府统计、政务数据、公开数据库、网络爬取）
- **常见于**：经济学、社会学、政治学、公共卫生、计算机科学
- **能回答什么 RQ**：基于大规模真实数据的描述 / 相关 / 趋势
- **局限**：数据原本为其他目的采集、可能缺关键变量；数据质量依来源而定

### 内容分析（Content Analysis）

- **研究什么**：系统化编码文本 / 媒体 / 视觉材料，量化或主题化分析
- **常见于**：传播学、社会学、政治学、护理学、文学（实证方向）
- **能回答什么 RQ**：X 在媒体 / 文本中如何呈现 / 频次 / 主题
- **局限**：编码主观性；需编码员间信度；脱离语境风险

### 混合方法（Mixed Methods）

- **研究什么**：质性与量化结合（如先访谈建构量表、再问卷验证；或问卷 + 深访互补）
- **常见于**：教育学、护理学、公共卫生、社会学、管理学
- **能回答什么 RQ**：兼具广度与深度、机制 + 普遍性
- **局限**：设计与工作量大；质性与量化整合的方法论争议

## 第二梯队：理论型常见方法类（数学、理论物理、理论 CS 等）

### 公理化推导（Axiomatic Derivation）

- **研究什么**：从公理 / 定义出发严格推导定理 / 命题
- **常见于**：数学、理论物理、理论计算机、数理经济学、形式逻辑
- **能回答什么 RQ**：在公理体系下 X 是否成立 / 可证（理论真理）
- **局限**：结论依赖公理选择；与现实世界的对应需独立论证

### 模型构建与分析（Model Construction）

- **研究什么**：构建数学 / 计算 / 概念模型刻画现象，分析模型性质
- **常见于**：理论物理、理论经济学、理论生物学、人工智能、运筹学
- **能回答什么 RQ**：X 的理论机制 / 模型条件下的行为
- **局限**：模型假设的外部效度需实证检验；抽象可能失真

### 计算机模拟 / 仿真（Simulation）

- **研究什么**：用算法模拟系统演化、测试不同参数下的行为
- **常见于**：复杂系统、人工生命、流行病学、经济学、社会学（计算方向）
- **能回答什么 RQ**：在给定规则下系统如何演化 / 参数敏感性
- **局限**：结果依赖模型假设；非经验证据、需实证校准

### 反例构造 / 证明界限（Counterexample & Bound Proofs）

- **研究什么**：构造反例否定猜想、或证明某类问题的复杂度 / 可解性界限
- **常见于**：理论计算机、数学、算法理论
- **能回答什么 RQ**：X 是否不成立 / 某方法的根本限制
- **局限**：反例不告诉正向构造；界限证明技术性强

## 第二梯队：规范文本型常见方法类（法学、公共管理、马克思主义理论等）

### 文本分析 / 规范分析（Textual / Normative Analysis）

- **研究什么**：对法条 / 政策文本 / 经典著作系统解读，提炼规范内涵
- **常见于**：法学、公共管理、马克思主义理论、政治学（规范方向）、哲学
- **能回答什么 RQ**：X 条文 / 制度 / 理论的规范含义 / 应然要求
- **局限**：规范性而非实证性；结论依赖解释框架；主观性

### 案例比较（Comparative Case Study）

- **研究什么**：选取若干案例（国家 / 地区 / 判例 / 政策）系统比较异同
- **常见于**：法学（比较法）、公共管理、政治学、社会学（历史比较）
- **能回答什么 RQ**：X 在不同情境下的差异 / 共性 / 影响因素
- **局限**：案例选择偏差；小样本推断有限；需控制比较维度

### 历史溯源（Historical Genealogy）

- **研究什么**：追溯概念 / 制度 / 实践的历史演变与脉络
- **常见于**：法学（法制史）、马克思主义理论、政治思想史、历史学
- **能回答什么 RQ**：X 如何演变成今天的样子 / 历史脉络
- **局限**：史料依赖；古今语境差异；非规范论证

### 以上都不是，我自己说

## 第三梯队：诠释型常见方法类（文学、历史、哲学、艺术等——让路时可选陈列）

> ⚠️ 诠释 / 思辨型研究方法形态多样，paper-method 的结构化匹配检查**不适用**（见 SKILL.md
> 学科适配与让路节）。本组仅在用户确认想讨论方法选择时**可选陈列**，不进入检查模式跑
> 匹配维度。陈列仍是摆事实、不推荐。

### 文本细读（Close Reading）

- **研究什么**：对文本逐字逐句细读，分析语言 / 结构 / 修辞的意义
- **常见于**：文学、修辞学、哲学（分析传统）
- **能回答什么 RQ**：X 文本如何在语言层面运作 / 意义如何生成
- **局限**：样本通常单一；主观性；外部概括有限

### 语文学考据（Philological Criticism）

- **研究什么**：版本校勘、训诂、文本传承考据
- **常见于**：古典文学、历史学（古典 / 史料方向）、哲学（古典）、宗教学
- **能回答什么 RQ**：X 文本的原貌 / 流变 / 字词原义
- **局限**：史料依赖；技术门槛高；与现代议题对接需额外论证

### 思辨分析（Speculative Analysis）

- **研究什么**：通过概念辨析、思想实验、推理展开论证
- **常见于**：哲学、政治哲学、伦理学、美学
- **能回答什么 RQ**：X 概念的内涵 / X 命题的合理性（规范与思辨）
- **局限**：非实证；结论依赖论证质量与前提；易陷入立场之争

### 个案诠释（Hermeneutic Case Interpretation）

- **研究什么**：对单一现象 / 作品 / 经验深度诠释，挖掘多重意义
- **常见于**：文学、艺术史、文化研究、宗教学、人类学（诠释方向）
- **能回答什么 RQ**：X 意味着什么 / 如何理解 X
- **局限**：普遍性有限；诠释多元性；需反思诠释者立场

### 现象学描述（Phenomenological Description）

- **研究什么**：描述经验 / 现象的本质结构
- **常见于**：哲学（现象学传统）、护理学（现象学方向）、教育学、心理学（人本）
- **能回答什么 RQ**：X 的本质经验是什么样的
- **局限**：方法争议大；描述 vs 推论的边界模糊；非实证概括

## SKILL.md 怎么用本库

引导模式第 2 步：据 RQ 形态与学科梯队，摆该梯队对应组别的方法类四字段陈列；明说"这些是这个方向常见的、不是我推荐的"；每组带末项"以上都不是，我自己说"；用户选定 / 自填后回切检查模式对该方法跑 §4.1 匹配维度。本库是静态参考文档（非脚本），SKILL.md 按学科选用对应组、不强求全摆。

诠释型（第三梯队）让路时本组可选陈列，但不进检查模式（结构化匹配不适用）。
