# 论文骨架库（paper-outline references）

> 本文件陈列各学科 / 论文类型学界**客观常见**的章节骨架。**不是推荐的、不是最优的**——
> 用户可全弃自填、可混合、可只取一部分。结构取舍权 100% 归用户。
> 与 paper-topic「选项死线」一脉相承：摆事实、不推荐、不排序、不打分。

## ① 实证量化（IMRD）

**适用**：实证研究、量化分析、假设检验类论文。

**章节骨架**：
- 引言（研究背景 / RQ / 贡献声明）
- 文献综述（有时并入引言、有时单列）
- 方法（数据 / 样本 / 变量 / 模型）
- 结果（描述性统计 / 假设检验 / 稳健性）
- 讨论（贡献 / 局限 / 展望）
- 结论

**常见变体**：
- 文献综述并入引言（短篇期刊论文常见）vs 单列成章（学位论文常见）。
- 方法与结果之间有时插「分析框架」一章。
- 结论有时并入讨论、不单列。

## ② 学位论文（中文学位论文八股）

**适用**：硕博毕业论文（按《学位法》与各校盲审制度节点）。

**章节骨架**：
- 第 1 章 绪论（研究背景 / 意义 / RQ / 技术路线 / 论文结构）
- 第 2 章 文献综述（国内外研究现状 / Research Gap）
- 第 3 章 研究方法（理论框架 / 方法选择 / 数据来源）
- 第 4 - N 章 实证章节（每章一个独立研究 / 子研究）
- 第 N+1 章 讨论（综合发现 / 理论贡献 / 实践意义）
- 第 N+2 章 结论与展望（主要结论 / 局限 / 未来工作）

**常见变体**：
- 实证章节数因学科而异（理工科常 2-3 个串联实验、社科常 1 个深度实证）。
- 部分学校要求单列「理论框架」为独立章（介于综述与方法之间）。
- 部分学校要求「研究创新点」单列节。

## ③ 综述

**适用**：文献综述类论文、系统性综述、范围综述。

**章节骨架**：
- 引言（研究背景 / 综述范围 / 检索策略）
- 概念框架（核心概念界定 / 理论视角）
- 主题分章（按 Research Gap 类型——对象 / 场景 / 方法 / 理论 / 时间缺失，或按时间脉络）
- 综合（跨主题整合 / 主要发现 / 矛盾消解）
- 研究展望（未来方向 / 缺口清单）

**常见变体**：
- 系统性综述（PRISMA）在方法后加「筛选流程图 / 质量评估」专节。
- 范围综述常省略「综合」、止于主题mapping。
- 按时间脉络的综述常用「年代-学派」而非「主题」分章。

## ④ 案例研究 / 定性

**适用**：定性研究、单案例 / 多案例分析、扎根理论。

**章节骨架**：
- 引言（研究背景 / RQ / 案例选择理由）
- 研究背景（案例情境 / 制度脉络）
- 研究设计（案例选择标准 / 数据收集——访谈 / 观察 / 文档）
- 案例呈现（单案例纵深叙述 / 多案例分章并列）
- 跨案例分析（主题归纳 / 模式识别）
- 讨论（理论对话 / 理论贡献 / 局限）
- 结论

**常见变体**：
- 扎根理论常把「跨案例分析」拆为「开放式编码 → 主轴编码 → 选择性编码」三章。
- 行动研究在案例呈现后加「干预 → 反思 → 迭代」循环节。
- 民族志常把「田野进入 / 角色管理」单列背景章。
