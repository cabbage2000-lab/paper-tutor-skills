## 1. 占位符标准格式

### 1.1 统一标记

所有需用户替换的位置使用统一注释标记：

```
# PAPER_PLACEHOLDER: <描述>
```

示例：
```python
df = pd.read_csv("your_data.csv")  # PAPER_PLACEHOLDER: 替换为您的数据文件路径
```

### 1.2 顶部声明模板（二选一）

**用真实数据时**：
```
# 基于用户提供的真实数据（来源：<文件名/粘贴文本>）
```

**用占位符数据时**：
```
# 占位数据、需替换为真实数据。绝不编造看似真实的研究数据。
```

## 2. 数据输入格式优先级

| 优先级 | 格式 | 说明 |
|--------|------|------|
| 1 | CSV | `pd.read_csv()` / `read.csv()`；学术数据最常见格式 |
| 2 | Markdown 表 | 粘贴文本解析为 DataFrame；适合从论文/表格直接复制 |
| 3 | JSON | `pd.read_json()` / `jsonlite::fromJSON()`；API 导出数据 |
| 4 | 粘贴文本 | 最低优先级；需额外清洗与结构化 |

生成代码时按此优先级选择读取方式。用户未指定格式时默认按 CSV 处理。

## 3. 配色说明

> 📋 色板取自公开色盲友好色板、非 AI 原创。

| 色板 | 用途 | hex 值 | 来源 |
|------|------|--------|------|
| **Okabe-Ito** | 离散分类（≤8 类） | `#E69F00` `#56B4E9` `#009E73` `#F0E442` `#0072B2` `#D55E00` `#CC79A7` `#000000` | Okabe & Ito 2008，色盲友好色板 |
| **ColorBrewer Qualitative** | 离散分类（>8 类） | Set2: `#66C2A5` `#FC8D62` `#8DA0CB` `#E78AC3` `#A6D854` `#FFD92F` `#E5C494` `#B3B3B3` | Brewer 2017，ColorBrewer Qualitative Set2 |
| **viridis** | 顺序/连续（无中心点） | matplotlib 默认连续色板，直接用 `cmap='viridis'` | van der Walt et al. 2014，色盲友好 |
| **ColorBrewer Diverging** | 发散（有中心点） | RdBu: `#67001f` `#b2182b` `#d6604d` `#f4a582` `#fddbc7` `#f7f7f7` `#d1e5f0` `#92c5de` `#4393c3` `#2166ac` `#053061` | Brewer 2017，ColorBrewer Diverging RdBu |

## 5. ggplot2 代码模板

### 5.1 柱状图（geom_col）

```r
# 占位数据、需替换为真实数据。绝不编造看似真实的研究数据。
library(ggplot2)

# PAPER_PLACEHOLDER: 替换为您的数据文件路径
df <- read.csv("your_data.csv")

# PAPER_PLACEHOLDER: 替换为您的分组列名
group_col <- "group_column"
# PAPER_PLACEHOLDER: 替换为您的数值列名
value_col <- "value_column"

# 取自 Okabe-Ito 色盲友好色板
okabe_ito <- c("#E69F00", "#56B4E9", "#009E73", "#F0E442",
               "#0072B2", "#D55E00", "#CC79A7", "#000000")

p <- ggplot(df, aes(x = .data[[group_col]], y = .data[[value_col]],
                     fill = .data[[group_col]])) +
  geom_col(width = 0.7, color = "white", linewidth = 0.3) +
  scale_fill_manual(values = okabe_ito) +
  # PAPER_PLACEHOLDER: 替换为您的图表标题
  labs(title = "Group Comparison",
       # PAPER_PLACEHOLDER: 替换为您的 X 轴标签
       x = "Group",
       # PAPER_PLACEHOLDER: 替换为您的 Y 轴标签
       y = "Value") +
  theme_minimal(base_size = 12) +
  theme(legend.position = "none")

ggsave("bar_plot.pdf", p, width = 8, height = 5, dpi = 300)
```
