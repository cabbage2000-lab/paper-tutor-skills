# 中文学位论文开题报告制度节点说明（paper-proposal references）

> **陈列性、非推荐性**——本库陈列的是中文学位论文开题报告**常见制度节点**，
> 非"唯一正确"的模板。各校 / 各院系要求有差异（节点顺序、必填项、字数、是否含
> 技术路线图等），用户按本校开题报告模板增删节点、调整顺序。
>
> 本库供 paper-proposal **第 2 步摆骨架**时引用：按学位阶段（本科 / 硕士 / 博士）
> 与学科梯队选用对应节点、不强求全摆。

---

## 通用制度节点（📋 常见事实，八节点）

### 一、选题依据（研究背景与意义）

- **常见内容**：研究背景（问题从何而来）、问题的提出（为什么值得研究）、研究意义（理论意义 + 实践意义）
- **片段来源**：topic 澄清路径（RQ 如何从模糊方向收敛）+ **用户补充**（背景与意义是研究者自有判断，AI 只提问引导、不代写）
- **学位差异**：本科开题偏"问题的提出"、硕士开题要求"理论 + 实践意义"齐全、博士开题强调"理论贡献"

### 二、文献综述（国内外研究现状）

- **常见内容**：该方向学界已有研究梳理、研究缺口（Research Gap）识别、本研究在 Gap 中的位置
- **片段来源**：`literature/` 笔记表五字段提取（每条文献的研究问题 / 方法 / 结论 / 不足）+ **用户判断 Gap**（AI 陈列各文献"不足"字段供参考、Gap 判断由用户）
- **降级**：literature 缺 → 本节标"⚠️ 无文献笔记支撑、建议先跑 /paper-search"、节空

### 三、研究内容与目标

- **常见内容**：研究目标、拟研究的具体问题（可分子问题）、拟解决的关键问题
- **片段来源**：**用户自有内容**（AI 摆骨架 + 提问引导"研究目标是什么""拟分几个子问题""关键问题是什么"、**不代写**）
- **边界**：这是开题答辩核心——AI 绝不替用户定研究内容（违反三条不变①）

### 四、研究方法（研究设计）

- **常见内容**：研究对象、变量 / 核心概念、数据 / 材料、收集与分析方法
- **片段来源**：method 产物（`topic/研究设计参谋.md` 提取用户拍板的方法类 + 匹配维度陈列）或用户口述
- **学科梯队调整**：
  - **实证型（第一梯队）**：研究对象 / 变量 / 数据收集 / 分析方法（实验 / 调查 / 现有数据）
  - **理论型（第二梯队）**：研究问题 / 推理工具（公理 / 定义）/ 模型或论证框架 / 论证方式（不强套实证模板）
  - **规范文本型（第二梯队）**：研究对象（法条 / 政策 / 文本）/ 分析框架（文本分析 / 案例比较 / 历史溯源）
  - **诠释型（第三梯队）**：研究对象 / 文本或材料 / 诠释框架 / 论证方式（不让路、开题各学科都要写）

### 五、技术路线（研究步骤 / 路径）

- **常见内容**：研究步骤、流程图、关键节点与逻辑
- **片段来源**：**用户自有内容**（AI 摆常见步骤骨架"文献-设计-采集-分析-写作"、用户填具体路径；或用户自述）
- **学位差异**：部分校（尤其本科）不强制要求技术路线图

### 六、工作计划（进度安排）

- **常见内容**：各阶段时间表、里程碑节点
- **片段来源**：**用户自有内容**（AI 摆常见四阶段骨架"文献 / 设计 / 采集-实验 / 分析-写作"、用户填具体时间）
- **常见阶段**（📋 常见事实，非推荐）：
  | 阶段 | 常见任务 |
  |---|---|
  | 第一阶段 | 文献综述 / 方法定型 / 开题 |
  | 第二阶段 | 数据采集 / 实验执行 / 田野 |
  | 第三阶段 | 数据分析 / 撰写初稿 |
  | 第四阶段 | 修改 / 预答辩 / 终稿 |

### 七、参考文献

- **常见内容**：按 GB/T 7714-2015 著录的参考文献表
- **片段来源**：`literature/` 笔记表题录提取（格式检查归 `/paper-format`，proposal 只提取题录、不做格式校验）
- **降级**：literature 缺 → 本节空、标"⚠️ 无文献笔记"

### 八、创新点 / 预期成果（部分校要求）

- **常见内容**：研究的创新之处（理论 / 方法 / 应用）、预期产出（论文 / 专利 / 报告）
- **片段来源**：**用户自有内容**（AI 只引导提问"你认为你的研究新在哪""预期产出什么"、**绝不替用户总结创新点**——创新点是开题答辩核心，AI 替想的不是用户的）
- **学位差异**：博士开题必有、硕士开题多数要求、本科开题部分校不强制

## 各校差异声明

各校开题报告格式有差异：

- **节点顺序**：部分校把"研究方法"放"研究内容"前、部分校反之
- **必填项**：部分校要求"可行性分析"、部分校要求"研究基础"、部分校要求"经费预算"
- **字数**：本科开题常见 3000-5000 字、硕士 5000-10000 字、博士 10000-20000 字
- **技术路线图**：部分校要求必附、部分校不强制
- **参考文献数量**：本科开题常见 15-30 条、硕士 30-60 条、博士 60-150 条

skill 摆的是**通用八节点骨架**，产物顶部固定声明：

> 本草案按中文学位论文开题报告常见制度节点组装，**各校具体要求有差异**——请按你所在学校 / 院系的开题报告模板增删节点、调整顺序、补全必填项。

## SKILL.md 怎么用本库

第 2 步摆骨架：据学位阶段（看 `project.paper.yaml` 的 `user_role` 或问用户）+ 学科梯队，从本库选用对应节点（本科开题可能不要"创新点"、博士开题必有）；每节标明片段来源（从哪提取 / 待用户补充）；研究者自有内容节（三、五、六、八）AI 只摆骨架 + 提问引导、不代写。

本库是静态参考文档（非脚本），未来扩各校特定模板 / 学科专属节点有落点（Phase 2+ references 扩展）。
