# 评审维度与视角说明（paper-review references）

> **陈列性、非推荐性**——本库陈列的是各学科**常见评审维度**与**三视角审稿意见套路**，
> 非"唯一正确"的评审标准。真实评审标准以目标期刊 / 学校规定为准。
> 评分维度与意见套路都是 **📋 模拟常见**陈列、**非 AI 对论文的价值判断**。

---

## 一、分项评分维度（📋 模拟常见审稿维度、非 AI 判断）

### 实证型（第一梯队：实验/实证型理工农医、实证型社科）——五维、各 0-10、总分 0-50

| 维度 | 模拟审稿常见关注点 | 常见扣分点（📋 示例、非穷举） |
|---|---|---|
| **新颖性** | 研究问题 / 方法 / 视角有无新意 | 与已有文献重叠高 / RQ 不够聚焦 / 方法陈旧 |
| **方法严谨性** | 方法能否回答 RQ、设计是否妥当 | 样本量不足 / 变量操作化模糊 / 缺控制组 / 混淆变量未处理 |
| **结果可靠性** | 数据分析是否支撑结论 | 统计方法误用 / 结果与结论脱节 / 缺稳健性检验 / 效应量未报 |
| **写作清晰度** | 结构 / 逻辑 / 表达 | 论证链跳跃 / 章节失衡 / 术语混乱 / 图表不清 |
| **贡献度** | 理论 / 实践意义 | 贡献声明空泛 / 与文献 Gap 对应不清 / 局限未承认 |

### 理论型（第二梯队：数学、理论物理、理论 CS、理论经济学等）——维度调整

| 维度调整 | 原实证维度 | 理论型调整后 |
|---|---|---|
| 方法严谨性 → | 方法严谨性 | **推理严密性**（公理体系自洽 / 推导步骤完整 / 定义清晰） |
| 结果可靠性 → | 结果可靠性 | **命题正确性**（注：只陈列审稿人会质疑的常见维度、**不核验证明的数学正确性**、同 paper-logic 第二梯队声明） |

其余维度（新颖性 / 写作清晰度 / 贡献度）同实证型。

### 规范文本型（第二梯队：法学、公共管理、马克思主义理论等）——加"规范论证说服力"

| 维度调整 | 加 |
|---|---|
| 规范文本型特有 | **规范论证说服力**（规范依据充分 / 论证逻辑自洽 / 与实定法 / 政策文本对应） |

### 诠释型（第三梯队：文学、历史、哲学、艺术等）——维度调整

| 维度调整 | 原实证维度 | 诠释型调整后 |
|---|---|---|
| 方法严谨性 → | 方法严谨性 | **视角 / 框架适切性**（诠释框架是否切合文本 / 材料） |
| 结果可靠性 → | 结果可靠性 | **阐释说服力**（阐释是否基于文本证据 / 是否过度诠释） |
| 贡献度 → | 贡献度 | **诠释深度**（是否提出新理解 / 推进该领域诠释） |

新颖性 / 写作清晰度同实证型。

## 二、三视角常见套路（📋 模拟常见评审视角）

### 视角 1：期刊审稿人

**模拟关注点**：新颖性、方法严谨性、贡献度、是否符合期刊范围与定位。

**常见意见套路（📋 示例、非穷举）**：
- "与 [X 文献] 相比，本文的新贡献需进一步澄清——请明确增量在哪。"
- "方法节 [Y 部分] 描述欠详，读者难以复现——建议补充。"
- "[Z 处] 统计方法选择疑误——请说明为何用此方法、并补稳健性检验。"
- "结论部分的实践意义稍显空泛——请具体化。"
- "本文与期刊 [A/B] 范围的契合度——请作者回应是否考虑投更对口的期刊。"

### 视角 2：学位论文盲审专家（PRD §385 预设）

**模拟关注点**：是否达到学位标准、工作量、规范性、能否进入答辩。

**常见挑刺套路（📋 示例、非穷举）**：
- "文献综述覆盖不足——[某方向] 重要文献未涉及，建议补全。"
- "方法章描述欠详——样本 / 数据 / 分析过程需更详尽。"
- "工作量与 [硕士 / 博士] 学位要求是否匹配——请答辩时说明。"
- "格式规范问题——参考文献著录、图表编号、术语统一等需校对。"
- "创新点表述需更聚焦——目前的创新声明较散。"
- "结论的理论与实践意义需更明确——避免空泛。"

**学位论文盲审与期刊审稿的差异**（PRD §385）：盲审更重**工作量、规范性、是否达标**（学位标准是底线）；期刊更重**新颖性、贡献**（发表门槛是增量）。盲审挑刺常落在"是否达到学位要求"而非"是否值得发表"。

### 视角 3：答辩委员

**模拟关注点**：研究问题价值、方法妥当性、结论可靠性、答辩表现预设（追问）。

**常见追问套路（📋 示例、非穷举）**：
- "你的核心贡献是什么？请用一两句话讲清楚。"
- "为什么用这个方法、不用 [X 替代方法]？"
- "结果能否外推到 [其他群体 / 情境]？局限如何回应？"
- "你的研究与 [某文献] 的根本区别在哪？"
- "如果审稿人 / 评委质疑 [Y 点]，你怎么回应？"
- "这个研究的理论 / 实践意义，你最想强调哪一点？"

答辩委员的追问常预设答辩现场的应对——review 摆这些追问让用户预演。

## 三、评分使用规则（守"模拟视角陈列、非 AI 判断"底线）

1. **分项评分**：每维 X/10、配扣分依据（指 draft 具体段落锚点）、总分加总陈列。
2. **每项标"📋 模拟常见审稿维度"**：让评分来源可见、非 AI 黑箱判断。
3. **禁总判断词**：禁"这篇论文好/差""行/不行""值得发表/应拒稿""能否过答辩"——只陈列分项与意见。
4. **总分配文**：顶部 / 总分处固定声明"此分数是模拟练习加总、不代表论文真实水平；真实评审以导师 / 期刊审稿人 / 答辩委员会为准"。
5. **每条意见配段落锚点**：指 draft 具体段落、让意见可追溯、非空泛指责。

## SKILL.md 怎么用本库

第 2 步模拟评审：据学科梯队选维度（实证五维 / 理论型调整 / 规范文本型加说服力 / 诠释型调整）→ 据用户选视角（期刊审稿 / 学位论文盲审 / 答辩委员，选一/几/全）→ 逐维评分（📋 模拟常见维度、配锚点）→ 逐视角摆套路意见（📋 模拟常见套路、配锚点）→ 总分加总 + 配文声明。

本库是静态参考文档（非脚本），未来扩期刊特定维度（如 ICLR 评分表）/ 学科专属视角有落点。
