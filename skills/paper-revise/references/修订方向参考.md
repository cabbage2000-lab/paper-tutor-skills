# 修订方向参考（paper-revise references）

> **陈列性、非推荐性**——本库陈列的是各学科**常见修订方向**，
> 非"唯一正确"的修订标准。真实修订以目标期刊 / 答辩委员会的意见为准。
> 修订方向与归类都是 **📋 常见陈列**、**非 AI 判断**。

## 一、意见归类（📋 常见 6 类、非穷举）

| 类别 | 常见关注点 |
|---|---|
| 方法 | 研究设计 / 样本 / 变量操作化 / 推导步骤 / 框架适切性 |
| 结果 | 数据分析 / 统计方法 / 命题正确性 / 阐释说服力 / 稳健性 |
| 写作 | 结构 / 逻辑 / 表达 / 术语 / 图表 |
| 文献 | 综述覆盖 / 引用恰当性 / 与已有文献对比 |
| 贡献 | 贡献声明 / 与 Gap 对应 / 局限承认 |
| 其他 | 格式 / 伦理 / 数据共享 / 拼写 |

## 二、三梯队修订方向（📋 模拟常见、非穷举）

### 实证型（第一梯队：实验/实证型理工农医、实证型社科）

| 意见归类 | 修订方向常见维度 |
|---|---|
| 方法 | 补实验 / 补控制组 / 补稳健性检验 / 澄清变量操作化 / 处理混淆变量 |
| 结果 | 报效应量 / 补统计方法选择说明 / 稳健性检验 / 结果与结论对齐 |
| 文献 | 补对比文献 / 澄清增量贡献 / 修订 Gap 表述 |
| 写作 | 结构调整 / 论证链补全 / 术语统一 / 图表重做 |

### 理论型（第二梯队：数学、理论物理、理论 CS、理论经济学等）

| 意见归类 | 修订方向常见维度 |
|---|---|
| 方法 | 补推导步骤 / 命题澄清 / 定义补全 / 公理体系说明 |
| 结果 | 命题正确性论证补强（注：不替用户做证明） / 反例回应 |
| 文献 | 与已有定理对比 / 学术谱系补全 |
| 写作 | 推导表述清晰化 / 符号统一 |

### 规范文本型（第二梯队：法学、公共管理、马克思主义理论等）

| 意见归类 | 修订方向常见维度 |
|---|---|
| 方法 | 规范依据补强 / 论证框架补全 |
| 结果 | 与实定法 / 政策文本对应 / 反例回应 |
| 文献 | 规范文献覆盖 / 学说谱系 |

### 诠释型（第三梯队：文学、历史、哲学、艺术等）

| 意见归类 | 修订方向常见维度 |
|---|---|
| 方法 | 视角 / 框架适切性补强 / 框架与文本对应 |
| 结果 | 补文本证据 / 阐释深化 / 反例回应 / 防过度诠释 |
| 文献 | 二手文献覆盖 / 学说对话 |
| 写作 | 阐释层次清晰化 / 引文格式 |

## 三、候选回复措辞的诚实度边界（与 SKILL.md 不变② 同源）

- ✅ 允许：基于用户已有研究事实起草（澄清误解 / 说明方法理由 / 摆已有数据 / 引已读文献）
- ⚠️ 需用户补充：涉及补实验 / 补数据 / 补分析的意见、用户已有数据能否支撑不明时
- ❌ 禁止：编新结果 / 编未做分析 / 引未读文献 / 夸大已做工作 / 编引用支撑

> 诚实度自检（产物里可见）：每条候选回复须能追溯到 draft 正文事实或 verify 产物；追溯不到的标 ⚠️ 需用户补充、**不编**。
