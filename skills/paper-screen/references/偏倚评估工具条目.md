# 偏倚评估工具条目（paper-screen references）

> **陈列性、非推荐性**——本文档陈列 RoB 2 / NOS / AMSTAR 2 三套学界公开发表的偏倚评估工具的条目清单，供你对纳入研究逐条对照。**选用哪个工具、每条怎么评级、总评级是什么，都由你判定**——本文档不推荐工具、不代入判定、不产生任何评级结果。
>
> **学科让路声明**：第二梯队理论型研究**不适用**本节（理论综述无「研究偏倚」之说，参见 `paper-logic` / `paper-method` 的同类声明），第三梯队人文学科整体让路。判定所属梯队后，不适用者直接跳过本产物段，**不产空表**（即不生成一张字段全空的偏倚评估表格）。

## 一、RoB 2（随机对照试验偏倚风险评估工具，Risk of Bias 2）

📋 常见事实陈列——**评分由你填**。AI 不替你判定某条是低风险还是高风险：偏倚判定是研究判断，落在你这一侧。

**来源**：Sterne JAC, Savović J, Page MJ, et al. RoB 2: a revised tool for assessing risk of bias in randomised trials. *BMJ* 2019;366:l4898。Cochrane 官方工具与信号问题全文见 `riskofbias.info` / `methods.cochrane.org`。

**适用研究设计**：随机对照试验（RCT）。RoB 2 按**单个「结果」**评估（同一试验的不同结局、不同分析方式可能有不同判定）；唯一例外是「域 1·随机化过程」——这一域按试验整体评估一次，不随结局变化。

**5 个域**：

| 域 | 中文名（英文原名） | 常见关注点（📋） |
| --- | --- | --- |
| 域 1 | 随机化过程（Randomization process） | 分配序列是否随机产生、分配前是否对研究人员/参与者隐藏；组间基线特征是否提示随机化过程存在问题 |
| 域 2 | 偏离既定干预（Deviations from intended interventions） | 参与者/实施者/结局评估者是否知晓分组；是否存在非方案内的干预偏离、组间是否不平衡；分析方法是否恰当地估计了「意向性分配」效应或「依从」效应 |
| 域 3 | 结局数据缺失（Missing outcome data） | 结局数据是否完整；缺失比例；缺失是否可能与真实结局值本身相关 |
| 域 4 | 结局测量（Measurement of the outcome） | 测量方法组间是否一致；结局评估者是否知晓分组；测量方式是否可能受知晓分组这件事本身影响 |
| 域 5 | 报告结果的选择（Selection of the reported result） | 呈现的效应估计，是否是从多个符合条件的结局测量方式或多种分析方法中，挑选报告结果更「好看」的那一个 |

**三档评级（由你判定）**：

| 档位 | 含义 |
| --- | --- |
| 低风险（Low risk of bias） | 现有信息不支持该域存在实质性偏倚 |
| 有一些担忧（Some concerns） | 有理由怀疑该域存在偏倚，但现有信息不足以判定为高风险 |
| 高风险（High risk of bias） | 有理由相信该域存在偏倚，且偏倚的幅度或方向可能是实质性的 |

官方工具在每个域下设有一组结构化「信号问题」（signalling questions），答案经官方算法映射为域判定，评估者可基于专业判断推翻算法建议；5 个域的判定再综合为一个整体判定（**并非机械取最差域**——多个域同为「有一些担忧」也可能使整体升级为「高风险」，具体综合规则见 Cochrane 官方指南）。本文档只陈列域名、常见关注点与三档评级的含义，不代入信号问题全文与判定算法；域判定与整体判定均由你给出。

## 二、NOS（纽卡斯尔-渥太华量表，队列研究与病例对照研究）

📋 常见事实陈列——**评分由你填**。AI 不替你判定某条是低风险还是高风险：偏倚判定是研究判断，落在你这一侧。

**来源**：Wells GA, Shea B, O'Connell D, Peterson J, Welch V, Losos M, Tugwell P. The Newcastle-Ottawa Scale (NOS) for assessing the quality of nonrandomised studies in meta-analyses. Ottawa Hospital Research Institute（`ohri.ca`）。

**适用研究设计**：观察性研究——队列研究、病例对照研究。两个版本条目不同，按纳入研究的设计选用对应版本，不得混用。

**3 类 8 条、星级制**，最高 9 星（选择类每条最多 1 星、可比性类最多 2 星、结局/暴露类每条最多 1 星）：

### 队列研究版本

| 类别 | 条目 | 常见选项（📋，**加粗**为可获星选项） |
| --- | --- | --- |
| 选择（Selection，共 4 条，各 1★） | 1. 暴露组的代表性 | **真正代表**社区中该人群 / **较能代表**该人群 / 特定人群（如护士、志愿者）/ 未说明来源 |
| | 2. 非暴露组的选取 | **来自同一社区** / 来自不同来源 / 未说明来源 |
| | 3. 暴露的确定方式 | **有据可查的记录**（如手术记录）/ **结构化访谈** / 自我报告 / 未说明 |
| | 4. 证明研究开始时结局尚未发生 | **是** / 否 |
| 可比性（Comparability，共 1 条，最多 2★） | 5. 队列间可比性（按设计或分析控制混淆因素） | 控制了最重要的因素（**1★**）/ 额外控制了其他因素（**再加 1★**）|
| 结局（Outcome，共 3 条，各 1★） | 6. 结局评估方式 | **独立盲法评估** / **记录链接** / 自我报告 / 未说明 |
| | 7. 随访时间是否足够长（使结局有机会发生） | **是**（具体时长阈值由该研究领域判断）/ 否 |
| | 8. 随访的完整性 | **完整随访** / **失访比例小、不太可能引入偏倚（常见阈值随访率 >80%）** / 随访率 <80% 且未说明失访者情况 / 未说明 |

### 病例对照研究版本

| 类别 | 条目 | 常见选项（📋，**加粗**为可获星选项） |
| --- | --- | --- |
| 选择（Selection，共 4 条，各 1★） | 1. 病例定义是否恰当 | **有独立验证** / **有记录链接或自我报告依据** / 无说明 |
| | 2. 病例的代表性 | **连续病例或明显有代表性的病例系列** / 存在选择偏倚可能或未说明 |
| | 3. 对照的选取 | **社区对照** / 医院对照 / 未说明 |
| | 4. 对照的定义 | **无该病史（终点）** / 未说明来源 |
| 可比性（Comparability，共 1 条，最多 2★） | 5. 病例组与对照组的可比性（按设计或分析控制混淆因素） | 控制了最重要的因素（**1★**）/ 额外控制了其他因素（**再加 1★**）|
| 暴露（Exposure，共 3 条，各 1★） | 6. 暴露的确定方式 | **有据可查的记录** / **对病例对照状态设盲的结构化访谈** / 非盲结构化访谈 / 自我报告或仅病历 / 未说明 |
| | 7. 病例组与对照组是否用同一方法确定暴露 | **是** / 否 |
| | 8. 无应答率 | **两组应答率相同** / 描述了无应答者情况 / 应答率不同且未说明 |

**星级到质量等级的换算（📋 常见做法之一，非本文档强制、非唯一标准）**：AHRQ 常引用的一种阈值——「优」：选择 3-4★ 且可比性 1-2★ 且结局/暴露 2-3★；「一般」：选择 2★ 且可比性 1-2★ 且结局/暴露 2-3★；「差」：选择 0-1★ 或可比性 0★ 或结局/暴露 0-1★。是否采用这套阈值、阈值如何定，由你判定。

## 三、AMSTAR 2（评价既有系统综述方法学质量的工具）

📋 常见事实陈列——**评分由你填**。AI 不替你判定某条是低风险还是高风险：偏倚判定是研究判断，落在你这一侧。

**来源**：Shea BJ, Reeves BC, Wells G, et al. AMSTAR 2: a critical appraisal tool for systematic reviews that include randomised or non-randomised studies of healthcare interventions, or both. *BMJ* 2017;358:j4008。

**适用场景**：当你综述纳入的证据本身是「系统综述」时（如伞形综述 umbrella review、系统综述再评价），用 AMSTAR 2 评价这些既有系统综述的方法学质量——不用于评价单个原始研究（原始 RCT 用 RoB 2、原始观察性研究用 NOS）。

**16 条（其中 7 条为关键条目，表中标 ★）**：

| # | 条目（一句话） | 关键条目 |
| --- | --- | --- |
| 1 | 研究问题与纳入标准是否事先包含 PICO（人群/干预/对照/结局）要素 | |
| 2 | 是否有开展前预先制定的书面方案，并说明了对方案的重大偏离 | ★ |
| 3 | 是否说明了纳入研究设计类型的选择理由 | |
| 4 | 检索策略是否全面（多数据库、检索式、时间/语言限制等） | ★ |
| 5 | 研究选择（题录/全文筛选）是否由两名及以上评审员独立完成 | |
| 6 | 数据提取是否由两名及以上评审员独立完成 | |
| 7 | 是否列出全文阶段排除的研究清单并逐一说明排除理由 | ★ |
| 8 | 是否以充分细节描述每项纳入研究（PICO、研究设计等） | |
| 9 | 是否用恰当的工具评估纳入研究的偏倚风险 | ★ |
| 10 | 是否报告了纳入研究各自的资金来源 | |
| 11 | 如做了 meta 分析，统计合成方法是否恰当 | ★ |
| 12 | 如做了 meta 分析，是否评估了纳入研究偏倚风险对合并结果的潜在影响 | |
| 13 | 解读/讨论结果时是否纳入了对偏倚风险的考量 | ★ |
| 14 | 对观察到的异质性是否给出了满意的解释 | |
| 15 | 如做了定量综合，是否充分调查了发表偏倚（小样本偏倚） | ★ |
| 16 | 是否报告了本综述作者的利益冲突及资助来源 | |

**四档置信度评级（由你判定；AMSTAR 2 官方明确反对把 16 条加总成数字分数或百分比）**：

| 档位 | 判定依据（📋 官方规则） |
| --- | --- |
| 高（High） | 关键条目均无弱点，非关键条目 0-1 项弱点 |
| 中（Moderate） | 关键条目均无弱点，非关键条目 >1 项弱点 |
| 低（Low） | 关键条目 1 项弱点（无论非关键条目情况如何） |
| 极低（Critically Low） | 关键条目 >1 项弱点（无论非关键条目情况如何） |

## 四、三工具怎么选（陈列，由你判定）

| 工具 | 评估对象 | 对应你综述里的哪类纳入研究 |
| --- | --- | --- |
| RoB 2 | 单个 RCT 的某个结果 | 纳入研究本身是随机对照试验 |
| NOS | 单个队列研究或病例对照研究 | 纳入研究本身是观察性研究 |
| AMSTAR 2 | 一篇既有系统综述整体 | 你的综述是「对系统综述的再综述」（伞形综述） |

一篇纳入文献可能同时符合多个工具的适用范围（如一篇综述里既纳入了 RCT 也纳入了队列研究）——此时按各篇研究各自的设计分别选用对应工具，不强求全篇统一。选用哪个工具、每篇研究具体怎么打分，均由你逐条拍板；本文档不推荐、不预设。
