# 知网 / 万方检索方案模板（中文引导轨话术素材）

本文件是 paper-search 生成中文检索方案时的话术素材，不是给用户的成品。中文库（知网 / 万方 / 维普）无免费开放 API，故走「生成检索方案 → 用户执行 → 题录入表」的引导路径——这是产品能力的一部分，不是免责声明。

题录入表优先走**官方导出 + 脚本解析**（见下方「回填两条路径」），比逐条手抄快且题录更全。

**不程序化抓取站内接口**——理由是这两条，与技术可行性无关：

1. 知网海外版 `robots.txt` 为 `User-agent: * / Disallow: /`，明示禁止自动化访问（国内主站 `kns.cnki.net` / `www.cnki.net` 对非浏览器 UA 直接返回 HTTP 418，robots 内容读不到，本身也是主动反自动化的信号）。
2. 本产品分发给他人使用。个人写脚本自用是自己担风险；把自动化抓取做成产品默认能力，是让每个不知情的安装者承担站点 ToS 与账号风险。

### 已评估未采用的路径（留档，避免重复调研）

| 路径 | 结论 |
| --- | --- |
| 浏览器自动化抓结果表格（如 opencli 一类适配器） | 不采用。输在数据来源层：抓渲染结果必然要跟水印、`date` 语义（实测 oversea 版该字段是**入库时间**而非发表年）、时效性 token URL 缠斗，且实测 4 次请求 1 次超时 |
| 浏览器 MCP 驱动 + 站内官方导出 API（知网 `POST /dm8/API/GetExport`，`filename` 取结果页 checkbox 的 value，可回 GB/T 7714 / EndNote / elearning） | **技术上可行且题录质量与手动导出相同**，未采用的原因只是上面那两条合规与分发考量。若将来要做，它是起点，且解析仍复用 `parse_export.py`；须默认关闭 + 首次询问 + 保留本文件的手动路径作降级 |

水印本身**不是**拒绝抓取的理由——`parse_export.py` 的 `strip_invisible` 已能无损清除不可见字符（`<span class="hrc">` 包裹的可见水印词则只告警不删）。别把「洗不干净」当成理由写进任何地方。

## 知网（CNKI）高级检索字段

| 字段码 | 含义 |
| --- | --- |
| `SU=` | 主题（最常用，覆盖题名 / 关键词 / 摘要） |
| `TI=` | 篇名 |
| `KY=` | 关键词 |
| `AB=` | 摘要 |
| `AU=` | 作者 |
| `FT=` | 全文 |

- 布尔运算：`AND` / `OR` / `NOT`；同一概念的同义词用 `OR`（或知网界面的 `+`）并联，不同概念用 `AND`。
- 示例（贯穿案例 RQ「ChatGPT 是否提高大学生论文写作效率」）：

  `SU=('ChatGPT' OR '生成式人工智能' OR '大语言模型') AND ('大学生' OR '本科生' OR '研究生') AND ('写作' OR '论文写作' OR '学术写作')`

## 筛选条件（知网结果页左侧 / 高级检索选项）

- **来源类别**：CSSCI、北大核心、CSCD、AMI（据学科与用户要求选；社科多用 CSSCI / 北大核心）。
- **年份**：与英文轨同一范围（如 2018–2026）。
- **文献类型**：学术期刊 / 学位论文 / 会议。

## 万方（Wanfang）

字段与知网类似（`主题:` / `题名:` / `作者:`），检索式可复用同义词结构；库别选「期刊论文 / 学位论文」。

## 给用户的成品 · 中文检索操作卡

中文轨要用户亲自动手，所以**必须给一张自足的操作卡**：检索式能直接复制、每步都可照做、导出格式明确、回来说什么也讲清。**不许压缩成「请到知网检索后把结果给我」**——用户卡在哪一步就会整条中文轨断掉，这是中文缺口迟迟补不齐的头号原因。

下面是成品样例（贯穿案例 RQ「ChatGPT 是否提高大学生论文写作效率」）。**照这个结构填用户确认后的检索式与筛选条件**，措辞可调，六个步骤与导出格式提示不可删：

---

**📖 中文库检索操作卡（这步需要你自己做，约 5 分钟）**

知网 / 万方没有开放 API，站内检索得你来跑；导出的题录交我解析入表，和英文结果并进同一张笔记表。

**① 打开**：中国知网 → 高级检索 → 学术期刊库（校外访问先连学校 VPN 或图书馆入口）

**② 粘贴检索式**（整行复制）：

`SU=('ChatGPT' OR '生成式人工智能' OR '大语言模型') AND ('大学生' OR '本科生' OR '研究生') AND ('写作' OR '论文写作' OR '学术写作')`

**③ 设筛选**：年份 2018–2026 · 来源类别 CSSCI / 北大核心 · 文献类型 学术期刊

**④ 记下命中数**——我要写进检索日志（PRISMA-lite 要求可复现）

**⑤ 勾选要纳入的文献** → 点「导出与分析」→「导出文献」→ 格式选 **BibTex** 或 **EndNote** → 保存文件

> ⚠️ 别选 GB/T 7714 / APA / MLA：那是排好版的引文文本，字段糊在一起，脚本解析不了，只能退回逐条手抄。

**⑥ 回来告诉我文件路径**，例如「导出好了，`~/Downloads/CNKI-export.bib`，命中 87 条」——我解析后并进笔记表，带 DOI 的还能自动补全元数据。

*万方同理*：高级检索 → 检索式换 `主题:(...)` 语法 → 结果页勾选 → 「导出」→ 选 EndNote 或 BibTeX。
*站点界面偶有改版*，按钮名对不上时找语义相同的入口（「导出」「引用」「题录下载」）。
*导不出来也没关系*：条目不多就按手工模板逐条填，一样进表，只是覆盖方式记「用户回填（手工）」。

## 回填两条路径

### 路径 A · 官方导出 + 脚本解析（默认推荐，条目多时优势明显）

用户侧步骤见上方操作卡第 ⑤⑥ 步（**只在那一处写，别在别处另抄一份**）。拿到文件路径后宿主执行：

```bash
python3 scripts/parse_export.py --in <导出文件> --source cnki    # 万方用 --source wanfang
```

读回 JSON 的 `results`（与 `search.py` 同形，可直接并入同一张表）、`coverage`（`mode=user_export`）、`warnings`、`stats`。**`warnings` 非空时原文呈现给用户，不要吞掉**——里面是跳过的条目、疑似水印题名、无 DOI 条目数三类如实声明。

导出的题名若含「知网」「版权」等字样，脚本会告警但**不会替用户删**——它可能是真实题名的一部分（如《数字出版版权保护研究》），请用户自己核对。

### 路径 B · 手工回填（条目少、或导出功能不可用时）

```text
标题：
作者：
年份：
期刊（含核心类别）：
DOI（若有，可用 scripts/search.py --lookup-doi 补全元数据）：
研究问题 / 方法 / 数据 / 结论 / 不足：（阅读后自填）
```

**被引数与摘要两列留空**：站内导出的题录不含这两项（知网结果页上有"被引频次"，但那是页面显示、不进导出文件）。备注写"中文库导出不含"，**不去猜、不用英文库同名文献的数顶替**——顶替出来的数字对不上任何一个库的口径，用户拿它写进综述就是错的。用户自己想补，让他照结果页抄，并在备注注明是人工抄录。

## 提示与红线

- 生成检索方案时只摆**客观常见**的同义词供用户增删，不替用户判断哪个词「更好」、不替用户删词。
- 回填的 PRISMA-lite 日志行由宿主补：数据库 = 中国知网、检索式 = 用户实际用的式子、命中数 = 用户报的数、覆盖方式 = **用户回填（官方导出）** 或 **用户回填（手工）**（按实际路径写，两者不混同）。
- 无论走哪条路径，覆盖方式**都不是「自动检索」**——检索由用户在站内执行，把它说成自动检索会违反覆盖声明的如实要求。
- **中文条目不能滚雪球**：`--snowball` 靠 OpenAlex / Semantic Scholar 的引文图谱，中文库不在其中。回填的中文条目若带 DOI 且恰好被 OpenAlex 收录，滚雪球能碰运气命中；否则如实记「未覆盖（无 API，滚雪球不适用）」，别把「滚不出来」说成「没有后续研究」。
- 绝不代替用户「凭记忆」列中文文献——只生成检索方案，真实结果由用户检索回填。
- 不为了「让脚本能解析」去程序化抓取站内接口或替用户绕过水印：站点明示禁止，且抓回的题名不可靠（见文件开头）。
