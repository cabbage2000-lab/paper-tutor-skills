# 知网 / 万方检索方案模板（中文引导轨话术素材）

本文件是 paper-search 生成中文检索方案时的话术素材，不是给用户的成品。中文库（知网 / 万方 / 维普）无免费开放 API，故走「生成检索方案 → 用户执行 → 回填题录」的引导路径——这是产品能力的一部分，不是免责声明。

## 知网（CNKI）高级检索字段

| 字段码 | 含义 |
| --- | --- |
| `SU=` | 主题（最常用，覆盖题名 / 关键词 / 摘要） |
| `TI=` | 篇名 |
| `KY=` | 关键词 |
| `AB=` | 摘要 |
| `AU=` | 作者 |
| `FT=` | 全文 |

- 布尔运算：`AND` / `OR` / `NOT`；同一概念的同义词用 `OR`（或知网界面的 `+`）并联，不同概念用 `AND`。
- 示例（贯穿案例 RQ「ChatGPT 是否提高大学生论文写作效率」）：

  `SU=('ChatGPT' OR '生成式人工智能' OR '大语言模型') AND ('大学生' OR '本科生' OR '研究生') AND ('写作' OR '论文写作' OR '学术写作')`

## 筛选条件（知网结果页左侧 / 高级检索选项）

- **来源类别**：CSSCI、北大核心、CSCD、AMI（据学科与用户要求选；社科多用 CSSCI / 北大核心）。
- **年份**：与英文轨同一范围（如 2018–2026）。
- **文献类型**：学术期刊 / 学位论文 / 会议。

## 万方（Wanfang）

字段与知网类似（`主题:` / `题名:` / `作者:`），检索式可复用同义词结构；库别选「期刊论文 / 学位论文」。

## 生成给用户的检索方案（结构）

1. **库别**：中国知网 高级检索（学术期刊库）。
2. **检索式**：`SU=(...) AND (...) AND (...)`（把用户确认的概念块 / 同义词填入）。
3. **筛选**：来源类别 = CSSCI / 北大核心；年份 = 用户确认范围；类型 = 学术期刊。
4. **步骤**：① 打开知网高级检索 → ② 粘贴检索式 → ③ 设筛选条件 → ④ 记录命中数 → ⑤ 逐条读题录与摘要。
5. **回填模板**（用户查到后回填，进同一张文献笔记表，覆盖方式记「用户回填」）：

```text
标题：
作者：
年份：
期刊（含核心类别）：
DOI（若有，可用 scripts/search.py --lookup-doi 补全元数据）：
研究问题 / 方法 / 数据 / 结论 / 不足：（阅读后自填）
```

## 提示与红线

- 生成检索方案时只摆**客观常见**的同义词供用户增删，不替用户判断哪个词「更好」、不替用户删词。
- 回填的 PRISMA-lite 日志行由宿主补：数据库 = 中国知网、检索式 = 用户实际用的式子、命中数 = 用户报的数、覆盖方式 = 用户回填。
- 绝不代替用户「凭记忆」列中文文献——只生成检索方案，真实结果由用户检索回填。
