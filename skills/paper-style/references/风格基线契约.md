# `manuscript/风格基线.md` 契约

| 项 | 内容 |
| --- | --- |
| 类型 | **跨 skill 数据契约**（生产者 / 消费者约定） |
| 生产者 | `paper-style` 模式 b（建立个人风格基线） |
| 消费者 | [`paper-draft`](../../paper-draft/SKILL.md) 的「风格样本机制」A+ 档——起草前读本文件对齐句长 / 虚词 / 引用习惯 |
| 落盘位置 | `manuscript/风格基线.md`（不在标准科研目录时落当前目录） |
| 守卫 | **无自动守卫，人工核**——字段名改动会静默破坏 draft，改前先看本文档 |

## 为什么要有这份契约

`paper-draft` 现状：每次会话都要用户重贴风格样本，给不出就落 C 档降级（产物顶部声明「未模仿用户风格、建议改写」）。基线持久化后，draft 下次直接读——**把 draft 的常态降级档变成常态正常档**。

代价是产生了一个跨 skill 的文件契约。契约没有自动守卫（它是 markdown、不是代码），所以字段名的稳定性靠这份文档维持：**改字段名前先确认 `paper-draft/SKILL.md` 的风格样本机制段怎么读它**。

## 三条底线

1. **基线只从用户自写样本算**——绝不从 AI 起草的文字算。从 AI 草稿算出的基线会让 draft 去对齐 AI 自己的风格，形成回音室：第一次起草的偏差被固化成"用户风格"，之后每次起草都朝这个偏差收敛，而用户以为系统在模仿自己。这是本契约最重要的一条。
   - 落实动作：模式 b 收样本时**明确问一句**「这几段是你自己写的、还是 AI 起草过的？」AI 起草过的部分请用户剔除或标出，标出部分不计入基线。
2. **样本规模与可靠性如实写**——`样本规模` 与 `可靠性` 两行必填。句数 < 30 时 `可靠性` 必须写「样本偏小」并说明后果（特征仅供参考、draft 对齐力度有限），**不得为了让基线"看起来可用"而省略这行**。
3. **近似项必须带标注**——术语密度与四字格密度两行必须带「近似」字样与依据（见 [`风格特征解读口径.md`](风格特征解读口径.md) §5、§6 的固定声明措辞）。

## 字段表

| 字段 | 必填 | 含义 | `paper-draft` 如何消费 |
| --- | --- | --- | --- |
| `日期` | 是 | 基线建立日期（`date +%F` 真实值） | 显示给用户确认基线新鲜度 |
| `样本来源` | 是 | 👤 用户原话描述的来源（哪篇、哪几段、是否本人自写） | 产物顶部声明「风格已对齐 `manuscript/风格基线.md`」时引用 |
| `样本规模` | 是 | `N 章节 / M 句 / K 有效字` | 顶部声明里带上句数，让读者判断对齐力度 |
| `可靠性` | 是 | `可用` / `样本偏小（M < 30 句）——特征仅供参考` | 「样本偏小」时 draft 仍用基线，但产物顶部同时提示样本偏小 |
| `句长均值` / `句长中位数` / `句长标准差` | 是 | 有效字符数口径（剔标点空白） | 起草时的目标句长区间 |
| `虚词密度` | 是 | 每百字次数 + 高频前 5 | 控制连接词投放密度与选词 |
| `引用位置分布` | 是 | 句首 / 句中 / 句末各自次数与占比 | 决定正文引用放句首还是句末 |
| `人称用法` | 是 | 各人称词次数 + 每千字密度 | 决定用「本文」还是「我们」还是不用人称 |
| `四字格密度` | 是 | 每千字次数 + **近似标注** | 弱参考（近似值，不作硬约束） |
| `术语密度` | 是 | 每百字次数 + **近似标注** + `来源：用户术语表 / 重复串近似` | 弱参考；`用户术语表` 来源时可作强参考 |
| `用户补充的风格偏好` | 否 | 👤 用户原话的口头补充（如「引用一律放句末」「不用第一人称」） | **优先级高于数字**——用户明说的规则压过统计值 |

**字段名后用全角冒号 `：`；表格形态与其余产物一致。** 消费者按字段名读，忽略不认识的字段、不报错——扩展不需要改契约（与 `_shared/references/留痕契约.md` 同规矩）。

## 完整示例

````markdown
# 风格基线

| 项 | 内容 |
| --- | --- |
| 日期 | 2026-07-27 |
| 样本来源 | 👤 用户已定稿的自写文字：硕士论文第 3 章前半（用户确认全部本人自写，无 AI 起草） |
| 样本规模 | 2 章节 / 86 句 / 3204 有效字 |
| 可靠性 | 可用 |

## 特征基线　🪞 系统归纳（由 scripts/style_metrics.py 机械计算）

| 特征 | 基线值 |
| --- | --- |
| 句长均值 | 34.2 字 |
| 句长中位数 | 31.0 字 |
| 句长标准差 | 12.8 |
| 虚词密度 | 每百字 1.4 次（高频前 5：因此 12 / 然而 8 / 此外 6 / 同时 4 / 基于 3） |
| 引用位置分布 | 句首 3 次（12%）· 句中 5 次（20%）· 句末 17 次（68%） |
| 人称用法 | 本文 14 次 · 本研究 6 次 · 我们 0 次 · 笔者 0 次（每千字 6.2 次） |
| 四字格密度 | 每千字 1.9 次（⚠️ 近似值：基于固定词表命中计数，非全量四字格识别） |
| 术语密度 | 每百字 3.1 次（⚠️ 近似值：来源「重复串近似」，无术语表时会把部分常用词误当术语） |

## 用户补充的风格偏好　👤 用户原话

- 「引用一律放句末，不要塞在句子中间。」
- 「不用『我们』，一律用『本文』。」

---

*本基线由 `/paper-style` 模式 b 从用户自写样本机械计算，特征值未经模型主观判断。`/paper-draft` 起草时读本文件对齐句长 / 虚词 / 引用习惯——**只学风格、不抄内容**。用户补充的风格偏好优先级高于统计值。*
````

## 更新与失效

- **更新**：用户提供新样本时重新生成，**覆盖**本文件（基线是当前快照，不是追加台账）；覆盖前告知用户旧基线的日期与样本规模，让其确认。
- **失效**：用户说「这个基线不对 / 我风格变了」→ 重建，不修补个别数字（手改数字会让基线与样本脱钩，失去"算出来的"这一唯一可信来源）。
- **临时偏离**：用户在 draft 会话里临时说「这一章我想写得更口语」→ **以当次口头为准，不改基线文件**（临时偏好不是基线变更）。
