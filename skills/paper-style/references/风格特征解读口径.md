# 风格特征解读口径

| 项 | 内容 |
| --- | --- |
| 类型 | 解读规范（宿主 agent 读数字时的可说 / 不可说边界） |
| 服务对象 | `paper-style` 主流程第 2 步（跑脚本后陈列特征） |
| 上游 | `scripts/style_metrics.py` 的 `--json` 输出 |
| 死线 | 三条不变② —— 风格特征是**算出来的**，不是感觉出来的 |

脚本只产数字，数字本身不说话。本文档规定每个数字**是什么**、解读时**可以说什么**、**不得说什么**。凡本文档与你的直觉冲突，以本文档为准。

## 0. 三条通用禁令（高于逐项口径）

1. **禁无依据判断**——「读起来像 AI」「文风不够学术」「这章写得不好」「语言比较生硬」全部禁止。你手上只有句长、虚词、引用位、人称、四字格、术语密度六组数字，它们**不能**推出上述任何一句。
2. **禁替用户改写定稿**——默认只陈列偏移与着力点。用户明确说「给我个示例改法」时才给 1–2 句，标「示例、非定稿」，且该次留痕升「语言润色」级（见 SKILL.md 留痕段）。
3. **禁把偏移说成缺陷**——章节间有偏移是常态（引言与方法的语体本就不同）。你能说的是「哪个特征偏移量最大」（客观排序），不能说「所以这章有问题」。是否要改是用户的研究判断。

## 1. 句长分布（`len_mean` / `len_median` / `len_std`）

**是什么**：按中文句末标点（。！？；…）与英文（`.!?;`）切句后，每句**剔除标点与空白**的字符数的均值 / 中位数 / 总体标准差。切句是引号感知的——引号内的句号不切，`……` 算一个边界，小数点与 `et al.` 不切（实现见 `split_sentences` 的 docstring）。

**可以说**：「第 3 章句长均值 42 字，全文中最高；第 1 章 26 字，最低。」「第 2 章标准差 6.1，是各章中最小的——句子长度较为整齐。」

**不得说**：「句子太长了，建议拆分。」「句长过于整齐，像机器生成。」——后者尤其危险，它把一个中性统计量翻译成了检测器口吻的判断，直接踩三条不变③。

**`reliable: false` 时**（句子数 < 5）：必须先说「该节仅 N 句，标准差不具解释力」，再陈列均值与中位数（这两项在小样本下仍可读）。**不得**把小样本的标准差拿去参与章节间比较。

## 2. 虚词密度（`function_word_per_100` / `function_word_top`）

**是什么**：脚本词表（然而 / 因此 / 此外 / 值得注意的是 / 综上所述 …）的命中次数，归一为每百有效字。长词优先匹配——「除此之外」不会被「此外」重复计一次。

**可以说**：「第 4 章每百字 1.8 次，高频前三为『因此』『然而』『此外』；第 1 章 0.6 次。」

**不得说**：「连接词用得太多，AI 味重。」「虚词偏少，逻辑衔接不足。」——后一句是对论证质量的判断，那归 `/paper-logic`，不归本命令。

## 3. 引用位置分布（`citation_pos` / `citation_end_ratio`）

**是什么**：三种引用形态（`（作者, 年）`、`(Author, Year)`、`[N]` 含 `[1,2]` `[1-3]`）在句中的位置计数。句首 = 起点在前 8 字或前 15%；句末 = 终点距句末标点 ≤ 2 字；两端都像时算句末。

**可以说**：「第 2 章 12 处引用中 10 处置句末；第 3 章 8 处中 5 处置句首——两章的引用习惯不一致。」

**不得说**：「引用位置不规范。」——引用位置是学科惯例与个人习惯，没有「规范」可言；本命令只查**同一文内是否一致**。

**一处局限**：脚本只认上述三种形态。脚注式引用（`[^1]`）在预处理阶段被剥离、不计入。若用户全文走脚注制，此项会全为 0——**必须如实说「本文未检出可识别的行内引用，该项不可用」**，不得因为数字是 0 就说「引用偏少」。

## 4. 人称密度（`person_counts` / `person_per_1000`）

**是什么**：本研究 / 本课题 / 本文 / 笔者 / 我们 / 该研究 / 作者认为 / 本人的逐词计数与每千字密度。「本文献」已被屏蔽，不会让「本文」多计。

**可以说**：「第 1 章用『本文』9 次、『我们』0 次；第 4 章『我们』7 次、『本文』1 次——两章的自称方式不同。」

**不得说**：「学术写作应避免第一人称。」——这是**学科惯例问题**，且各梯队规范相反（见 §7），不是本命令能下的判断。

## 5. 四字格密度（`quad_per_1000`）⚠️ 近似值

**是什么**：24 条常见学术四字格（至关重要 / 不可忽视 / 综上所述 / 广泛应用 …）的命中数与每千字密度。

**固定声明措辞（可整段复制进产物）**：

> 四字格密度为近似值：基于固定词表命中计数，非全量四字格识别（技术栈约定零第三方依赖，不引分词）。实际四字格用量高于此数。

**不得说**：把它当成「文采」或「AI 味」的指标。它只是一个词表命中数。

## 6. 术语密度（`term_density_per_100` / `term_source`）⚠️ 近似值

**是什么**：两条路径——用户给了术语表（`--terms`）走**精确**计数；没给则退到「文中重复出现 ≥3 次的 2–6 字汉字串」估算，首尾结构助词已剪除、常用噪声词已屏蔽，但**减不干净**。

`term_source` 字段告诉你走的是哪条路：`用户术语表` / `重复串近似`。**走近似路径时必须用下面的措辞，不得省略**：

> 术语密度为近似值：技术栈约定零第三方依赖（不引 jieba 分词），无用户术语表时退到「文中重复出现 ≥3 次的 2–6 字汉字串」估算，会把部分常用词误当术语。产物引用此项须标注「近似」。

**主动给用户升级路径**：「你若给我一份术语表（一行一个），这项就能算准。」这是把近似变精确的唯一办法，值得每次都提一句。

这条近似标注是 CLAUDE.md 唯一保留的代码层约束在本命令的落点：**降级必须明确标注，不静默用近似值顶替精确值**。

## 7. 章节间偏移与变异系数（`comparison`）

**是什么**：每个特征在各章节间的 min / max / 极差 / 标准差 / **变异系数 CV**（= 标准差 / 均值）。`ranked_by_cv` 按 CV 降序。

**为什么看 CV 而不是极差**：句长（几十字）与虚词密度（每百字几次）量纲不同，直接比极差会把「句长差 8 字」说成比「虚词密度差 3 次」更重要。CV 无量纲，是「哪个特征在章节间抖得最厉害」的唯一可辩护排序依据。

**可以说**：「按 CV 排序，人称密度偏移最大（CV 1.80，第 1 章 0.0 → 第 4 章 5.7）。」

**不得说**：「所以第 4 章需要改。」——脚本只排序，取舍归用户。着力点陈列后每条配疑问句，如「第 4 章的『我们』是有意的写法，还是与第 1 章的『本文』不统一？」

**`available: false` 时**（只有一个章节）：如实说「只切出一个章节，无章节间偏移可算」，并给出路——用 `--dir manuscript/` 传多个文件，或确认正文的标题层级（脚本按能切出 ≥2 节的最浅层级切）。

## 8. 学科三梯队：梯队只改解读口径，不改脚本算什么

脚本永远只算数，梯队差异全在你怎么读：

| 梯队 | 解读侧重 | 一致性判据 |
| --- | --- | --- |
| 第一梯队（实证理工 / 社科） | 第三人称客观语体、时态一致 | 人称密度在各章间应接近；「我们」与「本文」混用值得提问 |
| 第二梯队（理论型 / 规范文本型） | 论证性语体、**术语一致优先** | 术语密度与用词一致比句长一致更值得看 |
| 第三梯队（人文） | **允许第一人称与文采** | 判据放宽到「同一文内不跳档」——只在某章突然从散文体切到公文体时才值得提问 |

## 9. 词表的权威位置与维护

`_FUNCTION_WORDS` / `_QUAD_PHRASES` / `_PERSON_WORDS` / `_COMMON_NOISE` 四张表的**权威在 `scripts/style_metrics.py` 的同名常量**，本文档不复制副本——两份必然漂移。改词表只改脚本。

**选词依据**：中文学术写作的常见连接与限定成分，取自写作惯例。**不取自任何 AIGC 检测器的特征工程**——本命令不服务规避检测（见 [`误判申诉口径.md`](误判申诉口径.md)），词表若照着检测器的特征做，本命令就变成了调参工具。这条约束比词表的完备性更重要。

## 10. 脚本跑不了时

无 `python3`、脚本缺失、退出码 3：**显式声明「风格特征不可用」**，把用户原文原样陈列交其自查。**绝不凭感觉说文风像不像**（三条不变②）——那正是本命令存在的理由所要否定的东西。
