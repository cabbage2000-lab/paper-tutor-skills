# 期刊要求与材料清单（paper-submit references）

> **陈列性、非推荐性**——本库陈列的是各期刊生态**常见投稿要求类目**与**常见投稿材料项**，
> 非"唯一正确"的投稿标准、非"该投哪个期刊"的推荐。真实要求以目标期刊官网 / 作者须知为准。
> 所有陈列都是 **📋 常见陈列**、**非 AI 判断**、**非穷举**。

## 一、投稿材料 checklist 常见项（📋 通用、非穷举）

| 材料项 | 常见说明 | 状态判定 |
|---|---|---|
| 正文 | 主稿件、字数按期刊要求 | ✅ 已有（manuscript/正文.md）/ ⚠️ 待补 |
| 摘要 | 中英文摘要、字数与结构化要求按期刊 | ✅ 已有（manuscript/摘要.md，归 /paper-abstract）/ ⚠️ 待补 |
| 关键词 | 数量按期刊要求（3-8 个常见） | ✅ 已有 / ⚠️ 待补 |
| 图表 | 分辨率 / 格式 / 是否单独上传 | ✅ 已有 / ⚠️ 待补 |
| 附录 / 补充材料 | 数据 / 推导 / 代码（按期刊） | ✅ 已有 / ❓ 该期刊是否需要 |
| 参考文献 | 格式按期刊（GB/T 7714 归 /paper-format） | ✅ 已有（literature/笔记表.md）/ ⚠️ 待补 |
| cover letter | 研究亮点 / 与期刊契合 / 未同时投递声明 | ⚠️ 待补（要点骨架由 submit 产、整段归 /paper-draft） |
| 利益冲突声明（COI） | 是否有利益冲突 | ❓ 待用户决定（通用模板：无可写"无"） |
| 版权协议 / 出版协议 | 期刊投稿系统填写 | ❓ 投稿时填写 |
| AI 使用说明 | 期刊政策差异大、部分强制披露 | ⚠️ 待补（若需要 → /paper-disclose）/ ❓ 该期刊政策 |
| 推荐审稿人 | 数量与领域按期刊 | ❓ 待用户填、AI 不替选 |
| 数据可得性声明 | 数据存放位置 / 是否公开 | ❓ 待用户决定 |
| 基金项目声明 | 基金编号 / 资助方 | ❓ 待用户填 |
| 作者简介 | 姓名 / 单位 / 邮箱 / ORCID | ❓ 待用户填 |

## 二、三梯队期刊生态常见投稿要求类目（📋 陈列、非穷举、以官网为准）

### 第一梯队：实证型理工农医、实证型社科（英语期刊 / SCI / SSCI 主场）

| 要求类目 | 常见范围（📋 通用、以官网为准） |
|---|---|
| 摘要字数 | 150-250 字、部分要求结构化（Background / Methods / Results / Conclusions） |
| 关键词数量 | 3-8 个 |
| Highlights | 3-5 条、每条 ≤85 字符（Elsevier 系常见） |
| Graphical Abstract | 一张图概括研究（部分期刊可选 / 必选） |
| Cover Letter | 研究亮点 / 与期刊范围契合 / 未同时投递声明 / 推荐审稿人 |
| 推荐审稿人 | 3-5 位、姓名 / 单位 / 邮箱 / 领域（部分期刊要求回避审稿人） |
| Data Availability Statement | 数据存放位置（Zenodo / Dryad / 机构库 / 合规理由） |
| Conflict of Interest | 利益冲突声明（ICMJE 表常见） |
| AI 使用披露政策 | 期刊政策差异大、部分要求披露 AI 使用（如 Nature / Science 系强制）、部分禁止（如部分期刊禁用 AI 写作） |
| 参考文献格式 | APA / Vancouver / IEEE / 期刊特定（GB/T 7714 归 /paper-format） |
| 图表分辨率 | 300 dpi 以上、矢量图 EPS/PDF 常见 |
| 投稿系统 | Editorial Manager / ScholarOne / 投稿邮箱 |

### 第二梯队：实证型社科、规范文本型（CSSCI / 中文核心主场）

| 要求类目 | 常见范围（📋 通用、以官网为准） |
|---|---|
| 中文摘要字数 | 200-300 字 |
| 英文摘要 | 与中文对应、部分要求 longer abstract |
| 关键词数量 | 3-5 个 |
| 中图分类号 | 按学科分类（部分期刊要求） |
| 文献标识码 | A（理论与应用研究）/ B（实用性技术成果）/ C（业务指导）/ D（动态信息）/ E（文件资料） |
| 基金项目声明 | 基金名称 + 编号 |
| 作者简介 | 姓名 / 出生年 / 性别 / 籍贯 / 单位 / 职称 / 学位 / 研究方向 / 邮箱 |
| 参考文献 | GB/T 7714-2015（归 /paper-format） |
| 投稿方式 | 在线投稿系统 / 投稿邮箱 |
| 字数要求 | 通常 8000-15000 字、按期刊 |

### 第三梯队：人文社科（中文核心、集刊、专刊）

| 要求类目 | 常见范围（📋 通用、以官网为准） |
|---|---|
| 摘要 | 中文摘要为主、部分要求英文摘要 |
| 关键词 | 3-5 个 |
| 基金项目 | 基金名称 + 编号 |
| 作者简介 | 姓名 / 单位 / 职称 / 研究方向 |
| 中文注释体例 | 脚注（当页注）vs 尾注、按体例（如《历史研究》脚注、《文学评论》脚注） |
| 字数要求 | 通常 10000-20000 字、集刊可能更长 |
| 投稿方式 | 邮箱 / 在线系统 / 纸质（少） |

## 三、cover letter 要点骨架的诚实度边界（与 SKILL.md 不变③ 同源）

- ✅ 允许：列研究亮点 bullet（锚点指 draft 正文真实存在的章节）/ 列通用结构（与期刊契合 / 未同时投递声明 / 推荐审稿人占位）
- ⚠️ 需用户填充：与期刊范围的具体契合点（用户最了解自己研究）、推荐审稿人（AI 不替选）、未同时投递声明（用户如实声明）
- ❌ 禁止：替用户整段写 cover letter（归 /paper-draft）/ 编期刊政策（如"该期刊欢迎 X 类研究"——AI 不编、用户去官网查）/ 编审稿周期 / 编接收率

> 诚实度自检（产物里可见）：每条"研究亮点"须能追溯到 draft 正文真实存在的章节；追溯不到的标 ⚠️ 待用户确认、**不编**。

## 四、出版伦理与合规提示清单（陈列性、不出具判断）

> **本节是陈列项、不是 AI 的判断**。涉及具体伦理判断时，固定声明"以所属机构与期刊政策为准、AI 不出具伦理豁免判断"（PRD §360）。

| 伦理类目 | 常见关注点（📋 陈列、以期刊政策为准） |
|---|---|
| 作者署名 | 按 ICMJE / 期刊作者定义（如实质性贡献 / 草稿修改 / 最终同意） |
| 利益冲突（COI） | 财务 / 个人 / 职业关系可能影响研究 |
| 数据伪造 / 篡改 | 学术不端底线（PRD §88） |
| 重复发表 / 自我抄袭 | 已发表内容再投需声明 |
| 同时投递（salami slicing / 一稿多投） | 同一稿件不可同时在多期刊审稿 |
| AI 使用披露 | 期刊政策差异大、部分强制披露、部分禁止 AI 写作 |
| 人类被试 / 动物实验伦理 | IRB / 伦理委员会批准（与 method 伦理审查提示清单衔接） |
| 数据可得性 | FAIR 原则 / 期刊数据政策 |

> 涉及上述任一类目的具体判断，固定声明"以所属机构与期刊政策为准、AI 不出具伦理豁免判断"（PRD §360 不出具伦理豁免判断）。指路机构学术伦理委员会 / 期刊编辑部。
