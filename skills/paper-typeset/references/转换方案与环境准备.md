| 项 | 内容 |
| --- | --- |
| 类型 | 环境准备指引 + 转换方案说明 |

## 1. 三个外部依赖，各管什么

| 依赖 | 缺了会怎样 | 哪些目标格式需要 |
| --- | --- | --- |
| `pandoc` | 什么都转不了 | docx / tex / pdf **全部** |
| `xelatex` | docx 与 tex 照常，**pdf 产不出** | pdf |
| 中文字体 | 中文稿的 pdf 会**整篇缺字**（方框） | pdf（中文稿）；tex 也需要字体名写进导言区 |

**它们是外部二进制，不是 Python 包**——所以不违反本仓库「零第三方运行时依赖」的技术栈约束，但也因此**必须有完备降级路径**：缺了就如实说缺了，绝不假装成功。

## 2. 安装（按平台）

### macOS

```bash
brew install pandoc
# 完整 TeX（约 4 GB，含 xelatex 与中文支持）
brew install --cask mactex-no-gui
# 或轻量方案：basictex + 按需装宏包
brew install --cask basictex
sudo tlmgr update --self && sudo tlmgr install xetex xecjk ctex
```

中文字体：系统自带 PingFang / Songti / Heiti，通常无需额外安装。

### Windows

```powershell
winget install --id JohnMacFarlane.Pandoc      # 或 choco install pandoc
winget install --id MiKTeX.MiKTeX              # 或安装 TeX Live
```

中文字体：系统自带 SimSun（宋体）/ Microsoft YaHei（微软雅黑）。

### Linux

```bash
apt install pandoc texlive-xetex texlive-lang-chinese fonts-noto-cjk
# 或
dnf install pandoc texlive-xetex texlive-xecjk google-noto-serif-cjk-fonts
```

## 3. 验证装好了

```bash
python3 skills/paper-typeset/scripts/export.py --probe
```

输出三项的 `available` / `version` / `fonts`。`paper-doctor` 的 `typeset` 分组读的是同一个探测——**只有这一处实现**，不会出现两处结论不一致。

## 4. 三个必须写对的转换参数（写错会静默出问题）

### 4.1 `--citeproc` 必须显式给

pandoc **2.11 起** `--csl` 与 `--bibliography` **不再自动启用 citeproc**。只给这两个参数会让引用原样输出成 `[@smith2023]`——**产物"生成成功"了，参考文献却没渲染**。这是本命令最容易静默错的一处，`export.py` 在有 `--bib` 时一律附加 `--citeproc`。

### 4.2 中文 PDF 必须 `--pdf-engine=xelatex` + `CJKmainfont`

pandoc 默认的 PDF 引擎是 `pdflatex`，**不支持中文**。中文稿必须：

```bash
pandoc 正文.md -o 正文.pdf --pdf-engine=xelatex -V 'CJKmainfont=Songti SC'
```

`CJKmainfont` 的值必须是**字体族名**（`Songti SC`），不是字体文件名（`Songti.ttc`）——传文件名 xelatex 找不到。族名由 `toolchain.probe_cjk_fonts()` 探测得出，优先序为宋体系 → 黑体系（学术正文惯例）。

macOS 的 `fc-list` 会列出以 `.` 开头的系统内部字体（`.PingFang SC`、`.LastResort`），**这些 XeLaTeX 拿不到**，探测层已过滤；`.LastResort` 尤其危险，它是专门显示方框的兜底字体。

### 4.3 `.tex` 必须 `--standalone`

不加产出的是**无导言区的片段**，没法单独编译。`export.py` 对 `tex` 目标一律附加。

## 5. 著录制式：两个内置 CSL

| `--csl` 简写 | 文件 | 制式 |
| --- | --- | --- |
| `numeric` | `csl/gbt7714-2015-numeric.csl` | GB/T 7714-2015 **顺序编码制**（`[1]` `[2]`） |
| `author-date` | `csl/gbt7714-2015-author-date.csl` | GB/T 7714-2015 **著者-出版年制**（`（张某, 2023）`） |

两个文件是 CSL 官方仓库的**官方文件**，许可与出处见 [`csl/LICENSE`](csl/LICENSE)。

**CSL 路径写错时 `export.py` 报错而非静默跳过**：跳过 CSL 会产出非国标著录，而用户正是为了国标才来的——静默降级在这里等于交付一个错东西。

### 与 `paper-format` 的闭环

`paper-format`（内建于 `/paper-verify`）**查**参考文献著录是否符合 GB/T 7714；`paper-typeset` 用同一标准的 CSL **产**合规著录。一个查、一个产，构成本仓库中文引用链的闭环——这是出版链在中文场景下的真实增量，而非照抄英文出版链。

用法上的先后：先 `/paper-verify` 核验引用存在性与著录格式 → 再 `/paper-typeset` 转格式并由 CSL 生成著录。

## 6. 正文一致性校验能校到什么（诚实边界）

三条不变①承诺「不改一个字」。这个承诺的**可校验程度按产物类型不同**：

| 产物 | 校验强度 | 说明 |
| --- | --- | --- |
| `.tex`（无 bib） | **强**：源正文汉字序列与产物**逐字相等** | LaTeX 命令都是 ASCII、不含汉字，所以汉字序列应原样出现 |
| `.tex`（有 bib） | **中**：源汉字序列是产物的**连续子串** | 参考文献条目由 CSL 生成并追加，产物必然多字，要求相等会误报 |
| `.docx` / `.pdf` | **无法校验** | zip / 二进制。只校验「源文件转换前后 md5 未变」+ 产物非空 |

**绝不对 docx / pdf 谎称做过字符级校验**——那比不校验更坏，用户会以为有保障。产物声明与 `submission/转换记录.md` 都必须如实写这一条。

校验前会剥离 HTML 注释（`<!-- -->`）：pandoc 默认丢弃它们，不剥会把注释里的汉字算成"丢失"而误报。

## 7. 常见失败与对策

| 现象 | 原因 | 对策 |
| --- | --- | --- |
| 引用输出成 `[@key]` | 缺 `--citeproc`（pandoc ≥ 2.11） | 本命令已自动加；手工执行时别漏 |
| PDF 中文全是方框 | 缺 `CJKmainfont` 或字体名写成了文件名 | 用 `--probe` 看探测到的族名，或 `--cjk-font '字体族名'` 指定 |
| `! LaTeX Error: File 'xeCJK.sty' not found` | TeX 发行版缺中文宏包 | `sudo tlmgr install xecjk ctex`（MiKTeX 会提示自动装） |
| 图片不显示 | md 里的图片是相对路径，pandoc 以**工作目录**解析 | 在项目根跑，或把图片路径改成相对项目根 |
| `.tex` 编译报缺字体 | 字体族名在当前系统不存在 | `--cjk-font` 换本机确有的族名（`--probe` 可查） |
| 退出码 4（正文校验失败） | 转换改动了正文 | **该产物不可信、勿投稿**；核对源 md 是否有 pandoc 会重解释的语法（如裸 HTML） |

## 8. 明确不做

- **期刊 / 高校排版模板库**（PRD §448）：各刊模板差异极大、更新频繁，内置必然过期，且用错模板的代价由用户承担。要具体刊物模板请到**期刊官网**下载，本命令只保证正文与著录正确转出。
- **改写正文以适配格式**：只换容器（三条不变①）。
- **查重降重**（PRD §446）：指路知网等官方查重。
- **替用户决定投什么格式**：期刊要求什么由用户读投稿指南确认。
