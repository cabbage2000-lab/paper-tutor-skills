## 目录约定

- `fixtures/` — 跨 skill 测试语料（[语料规约](fixtures/README.md)）；
- `paper-init/` — 脚手架行为验收清单（人工执行：六场景 + 确认前零创建 + 只增不删 + 产物红线 + project.paper.yaml 与宿主文件生成，[清单](paper-init/README.md)）；
- 各验收的执行载体（清单 / 脚本）随对应 skill 的开发任务落地，归入本目录，形态届时按技术栈决定（ADR·4.4）。
