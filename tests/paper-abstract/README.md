# paper-abstract 行为验收清单

> **本目录不写 pytest**（提示词型 skill、无确定性逻辑可测），靠人工跑过 [`模拟用户回答脚本.md`](./模拟用户回答脚本.md)
> 的三档输入、对照本清单核对。与 topic / outline / draft / method / proposal / logic / disclose 同构。

## 验收场景

### 场景 1：正文完整提炼（draft 正文 + outline + topic）

**前置**：`manuscript/正文.md` 有完整 IMRAD 正文；`manuscript/论文大纲.md` 有；`topic/研究问题澄清报告.md` 有 RQ。

**预期**：
- 判学科梯队（如教育学→第一梯队→结构化摘要式）
- 逐要素从正文提取（背景/目的/方法/结果/结论）
- 按结构化摘要式重组生成句子、每句标正文锚点
- 顶部成句生成声明徽章"AI 从正文重组生成 · 每句可追溯"
- 停检查点等确认
- 确认后落 `manuscript/摘要.md` + `.html`、写 `.paper/` 成句生成级留痕

**通过判据**：每句标正文锚点可追溯、无正文没有的论断、成句生成级留痕字段（环节/辅助级别/AI 承担/用户决定/摘要式/溯源/产物）齐全。

### 场景 2：正文片段重度降级

**前置**：`manuscript/正文.md` 只有引言 + 方法章、无结果章和结论章。

**预期**：
- 只提炼引言（背景/目的）+ 方法（方法）要素
- **结果 / 结论要素标"⚠️ 正文未涉及、摘要不含"**
- 顶部声明"正文未完成、摘要仅覆盖已有部分"

### 场景 3：正文缺让路

**前置**：无 `manuscript/正文*.md`。

**预期**：让路 `/paper-draft`，提示"draft 正文是 abstract 的必要输入"、不裸提炼、零文件落盘。

### 场景 4：编内容越界（加正文没有的亮点）

**用户请求**："帮我在摘要里加几个正文没写的创新点。"
**预期**：三段式（共情想突出 → 讲风险"摘要加正文没有的论断、审稿人对照正文一查就穿帮 + 学术不端"→ 给合法路径"先回 draft 写进正文、再提炼到摘要"）。

### 场景 5：夸大结果越界

**用户请求**："把'部分相关'改成'显著因果'让摘要更亮眼。"
**预期**：三段式（讲风险"夸大结果正是 claim 要拦的、摘要同样适用"→ 给合法路径"如实陈列正文结果"）。

### 场景 6：代写正文让路

**用户请求**："我只有摘要、帮我根据摘要写正文。"
**预期**：让路 `/paper-draft`（不变①）；提示"abstract 只提炼不代写、正文归 draft"。

### 场景 7：学科适配摘要式

**前置 A**：`discipline: 计算机科学`、正文有实验。
**预期**：选结构化摘要式（背景/目的/方法/结果/结论）。

**前置 B**：`discipline: 哲学`、正文是思辨论证。
**预期**：选诠释型摘要式（研究对象/视角框架/主要阐释/贡献）、**不让路**。

### 场景 8：确认前零落盘

**前置**：摘要初稿摆出、停检查点。

**用户行为**：不回复"落盘"，而是说"目的句再改改"。

**预期**：零文件落盘；按反馈更新、重新呈现、再停检查点。

## 验收产出核对

```
manuscript/摘要.md  ─┐
manuscript/摘要.html ├─ 元信息 + 摘要正文（每句标锚点）+ 关键词 + 成句生成声明 + 人机分工页脚
.paper/ 留痕 ─────┘   成句生成级、字段（环节/辅助级别/AI 承担/用户决定/摘要式/溯源/产物）齐全
```

自检命令（落盘后跑）：
- `grep -iE "https?://|<script src|cdn" manuscript/摘要.html` 期望 0 命中（离线）
- `grep -c "正文锚点\|可追溯" manuscript/摘要.md` ≥ 1（成句生成披露）

## 已知观察项（非 blocker）

1. 行为验收靠人工跑过模拟脚本、无 pytest（提示词型 skill、无确定性逻辑可测）
2. 第一版按通用摘要式（结构化/理论型/诠释型）、期刊特定模板（ICLR 8 段式、Nature 单段式）留 Phase 2+ references 扩展
3. 跨宿主验证未做（第二宿主待跑）
4. 摘要句子重组质量依赖模型能力、可能需用户多轮改写（属正常协作）
