# paper-abstract 模拟用户回答脚本（三档输入）

> 人工验收用：在真实宿主里贴下面对话的用户台词，对照 [`README.md`](./README.md) 核对 skill 行为。
> 三档覆盖正文完整 / 正文片段 / 正文缺让路。

---

## 档 1：正文完整提炼（验收场景 1）

**前置准备**：

```
项目根/
├── project.paper.yaml   # discipline: 教育学; user_role: 硕士研究生
├── topic/
│   └── 研究问题澄清报告.md  # RQ: ChatGPT 辅助写作对本科生论文写作效率的影响
├── manuscript/
│   ├── 论文大纲.md          # outline 产物（IMRAD 结构）
│   └── 正文.md              # draft 产物（完整 IMRAD 正文）
```

`manuscript/正文.md` 含完整的引言（背景 + RQ）、方法（问卷 N=250）、结果（正相关发现）、结论（AI 辅助提升效率 + 局限）。

**用户台词序列**：

1. "帮我从正文提炼摘要。"
   - **预期**：读正文 + outline + topic → 判教育学第一梯队 → 选结构化摘要式 → 逐要素从正文提取（背景/目的/方法/结果/结论）→ 重组生成摘要句子、每句标正文锚点 → 顶部成句生成声明徽章 → 停检查点。
2. "目的句用我的 RQ 原话。"
   - **预期**：更新目的句为 RQ 原话（从 topic 提取）、重新呈现、再停检查点。
3. "落盘。"
   - **预期**：落 `manuscript/摘要.md` + `.html`、写 `.paper/` 成句生成级留痕、交棒。

**预期产物字段**：
- 摘要式：结构化
- 留痕辅助级别：成句生成
- 留痕 AI 承担：正文要点提取、摘要句子重组生成、要素组织、产双产物
- 留痕溯源：每句标正文锚点、可追溯；正文未涉及要素 0 个

## 档 2：正文片段重度降级（验收场景 2）

**前置准备**：

```
项目根/
├── project.paper.yaml   # discipline: 计算机科学
└── manuscript/
    └── 正文.md              # 只有引言 + 方法章、无结果章和结论章
```

**用户台词序列**：

1. "帮我提炼摘要。"
   - **预期**：读正文（只有引言 + 方法）→ 判 CS 第一梯队 → 提炼背景/目的/方法要素 → **结果 / 结论要素标"⚠️ 正文未涉及、摘要不含"** → 顶部声明"正文未完成、摘要仅覆盖已有部分" → 停检查点。
2. "那我先去补结果和结论，这份先落盘留着。"
   - **预期**：落双产物（结果/结论节保留 ⚠️ 占位）、写留痕（溯源：正文未涉及要素 2 个）、交棒（提示先回 draft 补正文）。

**核对重点**：正文未涉及要素显式标 ⚠️、不编结果和结论、降级声明到位。

## 档 3：正文缺让路（验收场景 3）

**前置准备**：空目录或无 `manuscript/正文*.md`。

**用户台词序列**：

1. "帮我写摘要。"
   - **预期**：检测 draft 正文缺 → 让路 `/paper-draft`，提示"draft 正文是 abstract 的必要输入、建议先完成正文"、不裸提炼、零文件落盘。

**核对重点**：无正文时不进提炼流程、零文件落盘、让路指向 draft。

## 档 3 变体：学科适配（验收场景 7）

**前置**：`discipline: 哲学`；`manuscript/正文.md` 是思辨论证（问题→文本分析→主要命题→意义）。

**用户台词**：

1. "帮我提炼摘要。"
   - **预期**：判哲学第三梯队 → 选**诠释型摘要式**（研究对象/视角框架/主要阐释/贡献）→ 逐要素从正文提取 → 重组生成 → 停检查点。**不让路**（摘要各学科都要写）。

**核对重点**：哲学摘要用诠释式、不用实证结构化式、不让路。
