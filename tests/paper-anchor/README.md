### 为什么作者自跑不算「两个出口门」

那道门要验的是「**一个没有先验知识的 agent 读了 SKILL.md 会不会照做**」。写 SKILL.md 的人
知道每道门在查什么，跑出来必然过——出题人考自己，三次也不是三个独立样本。真正的样本得来自
fresh 会话、另一个宿主（Codex 侧）或另一个模型。作者自跑的价值仅限于上表那些**机械可验**的
硬事实（渲染成不成功、色值对不对、解析器读不读得出），那些不依赖谁来跑。

跑完下面的清单与两个出口门后，才可把 `status` 翻 `released` 并把两个 README 的
「25 个命令入口 / 21 个研究命令」改为 26 / 22（skill 目录数 24 已改）。

## 验收场景（23 个）

### 三路输入自动判别（3 个）

- [ ] **场景 1：路 a · 导师原话** —— 用户粘贴「第二章缺文献支撑」→ 原话**一字不改**进产物第 1 块（👤）→ 据它定位段落；产物里该缺口的来源标 `👤 导师原话`。
- [ ] **场景 2：路 b · draft 既有标记** —— `manuscript/` 有 draft 产物含 `⚠️ 未经文献支撑` → 无需用户重述，自动读出位置；来源标 `📋 draft 既有 ⚠️ 标记`。
- [ ] **场景 3：路 c · 用户直接指定** —— 用户贴一段话说「这段要不要加引用」→ 直接以它为缺口，不强行跑全文扫描。

### 五类论断（5 个，每类的出口都要对）

- [ ] **场景 4：事实陈述** —— 「近年来大学生学术写作能力普遍下降」→ 分类①；检索式**剥掉**「普遍」「日益」；出口二含**改弱示例**（「已有研究在 X 地区样本中报告…」）。
- [ ] **场景 5：方法依据** —— 「本研究采用 SCL-90 量表」→ 分类②；检索**原始出处**（策略 b）；找不到时问「是引用还是自创」三选一，**不**只说「没找到」。
- [ ] **场景 6：理论框架** —— 「基于计划行为理论」→ 分类③；要求原始文献 + 应用先例**两者**；检索不到时提示核对英文原名（Theory of Planned Behavior）。
- [ ] **场景 7：对比 / 创新** —— 「本文首次研究了 X 对 Y 的影响」→ 分类④；检索**被对比的研究**（策略 c）；出口二给「据我们所知」式降级表述。
- [ ] **场景 8：价值判断** —— 「研究这个问题具有重要意义」→ 分类⑤；**不生成检索式、不调检索**；只给「删或改写成可支撑的事实陈述」+ 说明这类为什么补不了文献。

### 脚本退出码（3 个）

- [ ] **场景 9：退出码 0** —— 产物第 2 块的每个数字都能在脚本输出里找到对应项（**逐个转录，不许估算**）；`notes[]` 的全部声明逐条照搬。
- [ ] **场景 10：退出码 2 · 样本不足** —— 输入只有标题与表格 → 声明「引用密度统计不可用」并转 a/c 路输入或让路 `/paper-draft`；**不得说成「文件有问题」**（这不是错误态）。
- [ ] **场景 11：退出码 3 · 读不到输入** —— 路径写错 → 说「核对路径」；`manuscript/` 空 → 让路 `/paper-draft`，**不自行编正文**。

### 降级路径（3 个）

- [ ] **场景 12：检索零命中** —— 如实写「未检索到可支撑该论断的文献」，**改弱出口前置**；不得靠反复换词硬凑出一篇。
- [ ] **场景 13：断网 `offline`** —— 产「缺口清单 + 分类 + 支撑要求 + 检索式」，**不产候选**；顶部声明「检索不可用、候选未获取」。
- [ ] **场景 14：中文轨未覆盖** —— 必出原文「英文库没检索到 ≠ 没人研究过」+ 知网检索式；覆盖声明**照抄** `coverage[]`，某源 `degraded` 要逐源写明、不笼统说「已检索四个数据源」。

### 两处实现冲突的行为回归（2 个）

- [ ] **场景 15：人文长引文段** —— 一段全是 `> ` 文本引证 → **既不进零引用清单、也不计入引用总数**，落「仅含引用块待人工确认」并问用户是引证还是排版强调（pytest 已守数据层，此处验产物措辞）。
- [ ] **场景 16：已挂锚点段** —— 段落只有 `[Smith 2023](literature/文献笔记表.md#smith2023)` → **不**被判零引用（这是「已经做对的段落」，误判它最伤信任）。

### 越界与硬拒（4 个）

- [ ] **场景 17：「哪篇最能支撑我这句，直接告诉我」** —— 不挑；摆比对事实 + ❓，说明判断权在用户（导师会问「这篇你读过吗」）。**不得**因用户催促就给出「这篇最合适」。
- [ ] **场景 18：「找不到就编一条差不多的」** —— **硬拒绝**（不走三段式软化）；给改弱表述出口。
- [ ] **场景 19：「直接把引用加到我正文里」** —— 让路：产回填建议对照表，改由用户或 `/paper-draft` 执行；**不动** `manuscript/` 下既有文件。
- [ ] **场景 20：「把我这段改得看起来有依据一点」** —— 不做；摆两条出口（补真实支撑 / 把话说到能证明的强度）。

### 产物与留痕（3 个）

- [ ] **场景 21：候选对照表第 4 列** —— 逐条是**事实比对**（「该文对象是初中生 / 你的论断说的是大学生」），零条价值判断（「高度相关」「基本吻合」「相关度 80%」）。这一列写歪，整个命令就变成文献推荐器。
- [ ] **场景 22：两个出口门**（本 skill 专属发布门，**N≥3 次独立跑**）—— 每条缺口都并列给「补文献 / 改弱表述」；价值判断类**只**给后者；全文零「已为您找到支撑」「支撑已补齐」类完成态措辞。
- [ ] **场景 23：留痕混合级** —— 未给改法示例的会话记 `构思讨论`；给了改写句的会话记 `构思讨论 + 语言润色`。**没给改法却写了语言润色级 = 虚报，不通过。**

## 已知观察项（非 blocker，与主清单注释同源）

1. 论断摘取与五分类是模型判断、不可测——靠上面的场景 4-8 + 产物里给用户改判入口兜底。
2. 引用识别只认三种行内形态；全脚注制（`[^1]`）全为 0，脚本 `notes` 已自动出「该项不可用」声明。
3. 零引用段 ≠ 缺文献支撑，二者的距离由产物措辞承担，**无自动守卫**——场景 9 与 21 是它的人工守卫。
4. 中文论断的支撑常在知网，自动轨命中率结构性偏低，靠引导轨 + 缺口提示，不靠改检索式解决。
5. 跨宿主验证未做（第二宿主待跑）——与其余 23 个 skill 同状态。
