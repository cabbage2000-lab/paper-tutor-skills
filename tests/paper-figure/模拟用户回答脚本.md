# paper-figure 模拟用户回答脚本

> 人工跑过验证用。四档输入各一份模拟对话脚本，照着念用户台词即可。

## 档 1：贴图 B 诊断

**前置**：建 `.paper/`、`project.paper.yaml`（`discipline: 计算机科学`）、`manuscript/` 目录；准备一张柱状图截图（Y 轴从 0.8 起始、三组柱子、有误差棒但未标注类型、红绿配色）。

**用户台词序列**：

1. "帮我看看这张图有什么问题。"（贴图触发 skill）
2. （skill 读图 + 学科判定第一梯队 + 跑 5 维度检查 + 陈列 + 停检查点）"落盘。"

**预期产物**：`manuscript/图表诊断.md` + `manuscript/图表诊断.html`，含：
- 顶部视觉诊断局限性声明
- 5 维度逐项陈列：①图类适配（柱状图表达比较→匹配）高可靠性；②图注与图例完整性（中可靠性）；③坐标轴与刻度（低可靠性→降级为自查清单："自查：Y 轴起始值是否为 0"）；④配色与可读性（低可靠性→降级为自查清单："自查：红绿配色是否色盲友好/灰度打印可分辨"）；⑤误差与统计标记（极低可靠性→降级为自查清单："自查：误差棒类型是否在图注中标注"）
- 每维度诊断覆盖徽章（只说「X / Y 项可视觉识别」）
- `.paper/` 留痕（混合级别、模式标 B 诊断）

## 档 2：代码静态分析 B 诊断

**前置**：建 `.paper/`、`project.paper.yaml`（`discipline: 生物医学`）；准备一段 matplotlib 脚本（含 `plt.ylim(0.8, 1.0)`、`plt.bar` 三组、`plt.errorbar` 用 SD 但图注写 95% CI、红绿 hex 配色 `#E64B35` / `#4DBBD5`... 等实际用 `['red', 'green']`）。

**用户台词序列**：

1. "帮我检查这段绘图代码的规范性。"（贴代码触发 skill）
2. （skill 读代码 + 学科判定第一梯队 + 跑 5 维度精确静态分析 + 陈列 + 停检查点）"生成代码。"
3. （进 paper-plot f 子命令、问库）"matplotlib。"
4. （生成代码、停检查点）"落盘。"

**预期产物**：
- `manuscript/图表诊断.md` + `.html`，含：
  - 顶部声明「已基于代码精确分析、可靠性高」
  - ①图类适配：柱状图匹配（代码 `plt.bar`）
  - ②图注完整性：中可靠性但可从代码标注提取
  - ③坐标轴：精确检出 `plt.ylim(0.8, 1.0)` 截断 → 陈列「Y 轴起始值 0.8、非零点、可能造成视觉放大差异」
  - ④配色：精确检出 `['red', 'green']` hex 值 → 色盲模拟分析 → 陈列「红绿对比在 deuteranopia 下难以区分」
  - ⑤误差标记：精确检出 errorbar 用 SD 但注释写 95% CI → 陈列「误差棒参数为 SD、图注标注为 95% CI、不一致」
  - **无**自查清单降级（代码路径精确分析）
- `manuscript/绘图代码_柱状图.py`（paper-plot 产物，成句生成级留痕）

2. （skill 模式自适应判定进 C 设计建议、学科第一梯队、给 a/b/c/d/e 五组件 + 陈列 + 停检查点）"柱状图和箱线图都可以，我先用柱状图。"

**前置**：建 `.paper/`、`project.paper.yaml`（`discipline: 心理学`）；无图无代码无数据文件。

**用户台词序列**：

1. "我的散点图 X 轴是学习时间、Y 轴是成绩，大概是个正相关，帮我看看有没有问题。"
2. （skill 检测无图无代码 → 口述降级路径 + 顶部强制声明「基于用户口述描述、未读实际图表，诊断依据受限」+ 禁止还原图 + 跑可诊断维度 + 陈列 + 停检查点）"帮我生成绘图代码。"

**预期产物**：
- `manuscript/图表诊断.md` + `.html`，含：
