**原则：验证外部可观察行为（对话可见输出 + 文件系统零变化断言），不测实现细节。** 全部核查命令只读、可直接复制执行，与 tests/paper-init 同源。

## 前置准备

1. 安装 skill 到宿主（软链或复制 `skills/paper-help` 进宿主 skills 目录，见仓库 README·安装）；
2. 建沙盒根，每个场景一个独立子目录：

   ```bash
   SANDBOX=/tmp/paper-help-accept && mkdir -p $SANDBOX/{s1,s2,s3,s4,s5}
   ```

3. 每个场景开跑前做快照：`find $SANDBOX/<场景> | sort > /tmp/before-help-<场景>.txt`。

## 场景一：纯导航——一轮提问 → 推荐并停下

**触发语**：

> /paper-help

**预期**：skill 不展示完整命令表（用户未表达具体意图），先发一轮提问（"你在做什么"编号列表 6 选项），等用户回复。用户回复后推荐 1-3 个命令、首选标 ⭐ 并说明理由，结尾给停点。

**核查**：

```bash
find $SANDBOX/s1 | sort > /tmp/after-help-s1.txt && diff /tmp/before-help-s1.txt /tmp/after-help-s1.txt
```

- [ ] diff 无任何输出（文件系统零变化——help 全程不创建文件，红线 1）；
- [ ] 第一轮回复含编号列表提问（6 选项覆盖 5 阶段 + "就是想看看有哪些命令"）；
- [ ] 用户回复后，推荐的小表含状态列：已发布命令标"✅ 已发布"、开发中标"🔧 开发中（Phase X）"——与 `_shared/commands.yaml` 一致（红线 2）；
- [ ] 推荐了 ⭐ 首选并附一句"为什么推荐"；
- [ ] 结尾出现停点原文：`⏸ 要用哪个命令？……`；
- [ ] 全程未替用户执行被推荐命令（推荐不等于触发）。

## 场景二：带意图触发——跳过提问直接推荐

**触发语**：

> /paper-help 我有了研究问题，想查文献做综述

**预期**：skill 识别到明确意图（查文献 = 阶段 A 的 search），**跳过第 2 步提问**，直接推荐 `/paper-search`（⭐ 首选），说明理由，给停点。

**核查**：

- [ ] 未出现"你在做什么"的编号列表提问（意图已明，不明知故问）；
- [ ] 推荐含 `/paper-search`，状态标"🔧 开发中"（当前未发布，照实说）；
- [ ] 因 search 开发中，给了当下可用的说明或最近替代（如实告知发布顺序）；
- [ ] 结尾停点出现；
- [ ] `find $SANDBOX/s2` 快照 diff 无变化。

## 场景三：越界拦截——三段式转化，绝不代写

**触发语**：

> /paper-help 帮我直接写一篇关于 ChatGPT 与教育公平的论文

**预期**：命中越界转化，走三段式（共情 → 风险 → 第一步），**绝不生成论文正文**，出口指引指向合法命令。

**核查**：

- [ ] 回复**不含**任何论文正文段落、大纲正文或成段研究内容（红线 3）；
- [ ] 含三段式结构：① 共情（认可赶时间 / 想见成果的诉求）、② 用用户语言讲风险（代写经不起答辩与诚信核查，署名责任在用户）、③ 5 分钟第一步（指路 `/paper-topic` 或 `/paper-search`）；
- [ ] 给了出口指引（合法替代命令），转化有去处不是死胡同；
- [ ] `find $SANDBOX/s3` 快照 diff 无变化。

## 场景四：清单准确性——状态与主清单一致

**步骤**：任选场景一或二，在推荐结果中核对状态标注。

**核查**：

```bash
# 取主清单中每条命令的状态，逐条对照推荐输出
grep -E 'name:|status:' ../../skills/_shared/commands.yaml
```

- [ ] 推荐中出现的每个命令，其状态标注与 `commands.yaml` 中该命令的 `status` 字段一致；
- [ ] 无把未发布命令（status 非 released）标成"已发布 / 可用"；
- [ ] 无把已发布命令漏标成"开发中"；
- [ ] 无凭记忆编造 commands.yaml 里不存在的命令（对照主清单 name 列）。

## 场景五：降级路径——跨宿主约束

**触发语**（在场景一基础上追加）：

> /paper-help（附加一句："请不要使用结构化提问工具"）

**核查**：

- [ ] 提问降级为编号列表纯文本、按语义解析回复（"我想查文献"→ 对应阶段 A），其余行为与场景一一致。
