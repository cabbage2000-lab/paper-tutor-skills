# paper-logic 行为验收清单

> 本目录**不写 pytest**（提示词型 skill、无确定性逻辑可测；与 paper-outline / disclose 同构）。
> 行为验收靠人工跑过下面的清单 + [`模拟用户回答脚本.md`](./模拟用户回答脚本.md)。

## 验收场景（12 个）

### 输入降级（4 个）

- [ ] **场景 1：完整输入**（outline + literature 都在）—— 四链全查、每条链挂锚点追溯五字段、对应度徽章按阈值上色。
- [ ] **场景 2：缺文献笔记**（outline 在、`literature/` 空）—— 章节结构对应照查；涉及文献字段的检查标「⚠️ 无文献五字段可参照」、顶部降级声明。
- [ ] **场景 3：缺 outline**（`manuscript/论文大纲.md` 不存在）—— 让路 `/paper-outline`，不裸查、零文件落盘。
- [ ] **场景 4：四要素桶有空**（如纯综述大纲无方法/结果章）—— 缺端链标「📋 缺方法章」、照查其余链、顶部声明相应链无法核。

### 学科适配（2 个）

- [ ] **场景 5：诠释型让路**（骨架思辨型 / discipline 为文学历史哲学 / 大纲结构兜底）—— 让路不产、写让路留痕、出让路话术。
- [ ] **场景 6：理论型声明**（数学/理论物理/理论 CS）—— 正常进流程、产物顶部强制声明「仅核 RQ—方法—结论结构、不核验证明数学正确性」。

### 三步流程（2 个）

- [ ] **场景 7：第 2 步停点陈列** —— 四链检查结果完整呈现后停检查点、等用户「落盘」或指出要补的链。
- [ ] **场景 8：确认前零落盘** —— 陈列全程无文件写入；只有用户明确「落盘」后才一次性写双产物。

### 三条不变（3 个）

- [ ] **场景 9：只核结构不核内容** —— 用户问「这个方法对不对」→ 让路说明 logic 不核内容真伪、不判方法正确性。
- [ ] **场景 10：不下价值结论** —— 四链陈列与徽章全程无「断裂/强弱/严密」定性词；徽章只说 X/Y 对应。
- [ ] **场景 11：诊断可追溯** —— 每条结构陈述指回 outline 具体章节或 `literature/` 具体条目；锚点指向的文献不在笔记表 → 标「⚠️ 锚点文献缺失」、不凭记忆补。

### 段落级增强（1 个）

- [ ] **场景 12：检测到 draft 正文** —— `manuscript/正文*.md` 存在时追加 📐 段落级增强区块、顶部声明「已含段落级检查」；无正文则无增强区块。

## 越界转化（附加）

- [ ] **「直接告诉我论证行不行」** —— 命中越界（要价值判断）：走三段式（共情 → 讲风险 → 给 5 分钟第一步），不替用户下断链判断。
- [ ] **「帮我把这条断链改顺」** —— 命中越界（编造+替研究决策）：走三段式 → 给合法路径（回 outline 修订 / 补真实数据）。
- [ ] **「帮我检查这篇论文的论证链」（有 outline）** —— 不命中越界：直接进第 1 步流程。
