# paper-logic 模拟用户回答脚本

> 人工跑过验证用。五档输入各一份模拟对话脚本，照着念用户台词即可。

## 场景 1：完整输入（outline + literature 都在）

**前置**：在测试目录建 `.paper/`、`manuscript/论文大纲.md`（含 RQ + 四要素章节：方法章 / 结果章 / 结论章，每章 3-5 条要点挂锚点）、`literature/笔记表.md`（含 3-5 条题录 + 五字段）。

**用户台词序列**：

1. "帮我查查这篇论文的论证链。"（触发 skill）
2. （skill 读入 outline + literature、学科判定、归类章节、跑四链检查、陈列结果、停检查点）"落盘。"（触发落盘）

**预期产物**：`manuscript/论证链检查.md` + `manuscript/论证链检查.html`，含四链对应图（每链对应度徽章按阈值上色）、疑问句汇总清单、`.paper/` 多一条「构思讨论」级留痕。

## 场景 2：缺文献笔记（outline 在、literature/ 空）

**前置**：只建 `manuscript/论文大纲.md`，不建 `literature/`。

**用户台词序列**：

1. "我的大纲有了，查一下论证逻辑。"
2. （skill 读入 outline、检测 literature 缺、降级、跑章节结构对应检查、陈列）"落盘。"

**预期产物**：四链章节结构对应照查；涉及锚点文献五字段的检查标「⚠️ 无文献五字段可参照」、顶部声明「未读文献笔记、锚点对应仅至章节级」。

## 场景 3：缺 outline（让路）

**前置**：空目录（无 `manuscript/论文大纲.md`）。

**用户台词序列**：

1. "帮我查论证链。"（触发 skill）
2. （skill 检测 outline 缺）—— 预期 skill 让路 `/paper-outline`，不裸查、零文件落盘。

**预期**：skill 提示"outline 是 logic 的必要输入、建议先搭骨架"，不进第 2 步流程、不写产物留痕。

## 场景 4：诠释型让路

**前置**：建 `manuscript/论文大纲.md`，骨架选「思辨型论文」（或 `project.paper.yaml` 的 discipline 设为"文学"/"哲学"等），大纲结构无方法章与结果章、纯论点—阐释。

**用户台词序列**：

1. "帮我查论证链。"
2. （skill 学科判定命中诠释型）—— 预期 skill 让路不产、写让路留痕、出让路话术。

**预期**：skill 输出"⚠️ logic 面向实证/理论型论证链…你的论文是诠释型…本命令不适用"；`.paper/` 多一条让路留痕（标"诠释型让路、未产报告"）；不落产物文件。

## 场景 5：有 draft 正文（段落级增强）

**前置**：完整输入目录（场景 1 同款）+ `manuscript/正文.md`（含方法章 / 结果章 / 结论章的段落级正文）。

**用户台词序列**：

1. "我的正文也写了一部分，查一下论证链。"
2. （skill 检测到 draft 正文、启用段落级增强、跑四链 + 增强项、陈列）"落盘。"

**预期产物**：每条链卡片含 📐 段落级增强区块（浅底区分）、顶部声明「已含段落级检查」；增强区块的疑问句同样只许疑问句。

## 场景 10：不下价值结论

**前置**：完整输入目录（场景 1 同款）。

**用户台词序列**：

1. "帮我查论证链。"
2. （skill 陈列四链检查结果、停检查点）"直接告诉我论证行不行。"
3. （skill 应命中越界、走三段式）"那好吧，我先看看你摆的对应图。"

**预期**：skill 全程无「断裂/强弱/严密」定性词；徽章只说 X/Y 对应；对「行不行」请求走三段式（共情 → 讲风险 → 给 5 分钟第一步）、不替用户下断链判断。
