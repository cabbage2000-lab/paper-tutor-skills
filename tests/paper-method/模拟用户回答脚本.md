# paper-method 模拟用户回答脚本（三档输入）

> 人工验收用：在真实宿主里贴下面对话的用户台词，对照 [`README.md`](./README.md) 验收场景
> 核对 skill 行为。三档覆盖检查模式完整 / 引导模式 / 诠释型让路。

---

## 档 1：检查模式完整（验收场景 1）

**前置准备**（手工建目录与文件）：

```
项目根/
├── project.paper.yaml   # discipline: 教育学; user_role: 研究生
├── topic/
│   └── 研究问题澄清报告.md  # 含 RQ（见下）
└── literature/
    └── 笔记表.md            # 含若干文献 + 方法字段
```

`topic/研究问题澄清报告.md` 的 RQ 字段：
> 「ChatGPT 辅助写作对本科生论文写作效率的影响」

`literature/笔记表.md` 含一条（示例）：
> Smith 2023 · 方法=问卷调查, N=250 · 结论=AI 工具使用与写作效率正相关

**用户台词序列**：

1. "我想用问卷调查来研究这个 RQ，帮我看看方法行不行。"
   - **预期**：skill 进检查模式（检出"问卷调查"方法意图）→ 读 topic RQ + literature 方法字段 → 逐维度陈列匹配（变量对应 / 数据类型 / 解释力 / 样本与总体）→ 涉人检测命中（问卷 + 教育学）→ 强制陈列六项伦理清单 + 末尾"须机构确认，AI 不能替代" → 停检查点。
   - **核对**：四维度陈列齐全、徽章无"够/不够"定性词、伦理清单六项 + 末尾声明逐字、未落盘。
2. "维度 2 的数据类型缺口再展开说说。"
   - **预期**：不落盘，按反馈更新维度 2 陈列、重新完整呈现、再停检查点。
3. "落盘。"
   - **预期**：落 `topic/研究设计参谋.md` + `.html`、写 `.paper/` 构思讨论级留痕、交棒（proposal / outline / 伦理审批提示）。

**预期产物字段**：
- 模式：检查模式（用户草案=问卷调查）
- 学科梯队：第一（实证社科）
- 伦理检测：命中（已陈列六项清单）
- 留痕 AI 承担：RQ 解析、匹配维度陈列、伦理审查提示清单、产双产物
- 留痕用户决定：选哪个方法（问卷调查）、方法行不行、伦理合规判断

## 档 2：引导模式（验收场景 2）

**前置准备**：

```
项目根/
├── project.paper.yaml   # discipline: 计算机科学; user_role: 研究生
└── topic/
    └── 研究问题澄清报告.md  # 含 RQ（见下）
# 无 literature/ 目录（降级场景）
```

`topic/研究问题澄清报告.md` 的 RQ 字段：
> 「大语言模型上下文窗口大小对代码生成准确率的影响」

**用户台词序列**：

1. "帮我看看这个 RQ 该用什么方法。"
   - **预期**：skill 进引导模式（未检出方法意图）→ 据 RQ 形态（因果：窗口大小→准确率）+ 学科（CS 第一梯队）摆实证组方法类（实验法 / 准实验 / 现有数据分析 等）→ 明说"常见的、不是我推荐的"、不排序、末项"以上都不是，我自己说" → 顶部声明"未读文献笔记、方法类陈列基于 RQ 形态推断"（literature 缺降级）→ 涉人检测未命中（无人类被试）→ 产物将标自检声明 → 停检查点（或先等用户选方法）。
2. "我选实验法。"
   - **预期**：弹性回切检查模式，对实验法跑四匹配维度（变量：窗口大小 ∩ 实验可操纵、数据：准确率数值 ∩ 实验产出、解释力：因果 ∩ 实验解释力、样本：任务集 ∩ 代码生成任务总体）→ 停检查点。
3. "落盘。"
   - **预期**：落双产物（引导模式 + 检查模式两段都呈现：方法类陈列 + 实验法匹配维度）、写留痕、交棒。

**预期产物字段**：
- 模式：引导模式 → 回切检查模式（实验法）
- 学科梯队：第一（实证理工）
- 伦理检测：未命中（自检声明）
- 留痕模式字段：引导模式：摆常见方法类 → 用户选实验法 → 检查模式

## 档 3：诠释型让路（验收场景 4）

**前置准备**：

```
项目根/
├── project.paper.yaml   # discipline: 哲学; user_role: 研究生
└── topic/
    └── 研究问题澄清报告.md  # 含 RQ（见下）
```

`topic/研究问题澄清报告.md` 的 RQ 字段：
> 「庄子'齐物'思想对当代生态伦理的启示」

**用户台词序列**：

1. "帮我设计这个题的研究方法。"
   - **预期**：skill 判诠释型（discipline=哲学 + RQ 形态"启示/意涵"无假设变量）→ 出让路话术（"method 的匹配检查面向实证/理论型，你的研究是诠释型...建议跳过；如需讨论方法选择可摆常见方法类供参考"）→ 涉人检测未命中（纯思辨）→ 不附伦理清单 → 写让路留痕（让路原因：诠释型、判定依据：discipline+RQ 形态、产物：无）。
   - **核对**：未产匹配检查报告、让路留痕字段齐全、零文件落盘（除 .paper/ 让路留痕）。
2. "那给我摆摆思辨分析这类方法吧。"
   - **预期**：可选进引导式摆诠释型组方法类（文本细读 / 思辨分析 / 现象学描述 等，第三梯队组），仍明说"常见的、不是我推荐的"、不进检查模式跑匹配维度（结构化匹配不适用诠释型）。
3. （用户结束会话）
   - **预期**：不落产物文件（让路不产报告）；如用户在引导式陈列后选定一个方法，仍不产匹配报告、仅在对话里讨论。

**预期让路留痕**：
- 环节：阶段 A｜选题与立项（环节 5）
- 辅助级别：构思讨论
- 让路原因：诠释 / 思辨型研究无实证式方法-RQ 匹配链
- 判定依据：discipline=哲学 + RQ 形态"启示/意涵"
- 伦理检测：未命中（无）
- 产物：无

## 档 3 变体：让路 + 伦理义务（验收场景 4 前置 B）

**前置**：`discipline: 文学`；RQ"某当代作家作品中读者接受反应的实证研究——基于深度访谈"。

**用户台词**：

1. "帮我看看这个研究的方法设计。"
   - **预期**：判诠释型（文学 + RQ 形态偏接受研究）→ 出让路话术；**涉人检测命中（访谈）→ 附伦理审查提示清单六项 + 末尾"须机构确认，AI 不能替代"**（让路不让伦理义务）→ 写让路留痕（伦理检测：命中、附清单）。

**核对重点**：即使学科让路、伦理清单仍强制陈列——验证"让路不让伦理义务"例外（PRD §282 跨梯队硬约束）。
