# paper-plot 模拟用户回答脚本

> 人工跑过验证用。三档输入各一份模拟对话脚本，照着念用户台词即可。

## 档 1：贴 CSV 数据生成柱状图

**前置**：建 `.paper/`、`project.paper.yaml`（`discipline: 计算机科学`）、`manuscript/` 目录；准备一个 CSV 文件 `data/results.csv`，内容如：

```csv
group,mean,sd
Control,3.2,0.8
Treatment A,5.1,1.1
Treatment B,4.7,0.9
```

**用户台词序列**：

1. "/paper-plot 帮我画一张柱状图，数据在 data/results.csv。"
2. （skill 第 1 步读输入 + 问库："matplotlib / ggplot2 / 别的"）"matplotlib。"
3. （skill 第 2 步生成代码 + 陈列 + 停检查点）"落盘。"

**预期产物**：`manuscript/绘图代码_柱状图.py`，含：
- 顶部声明「基于用户提供的真实数据（来源：data/results.csv）」
- `pd.read_csv("data/results.csv")` 读取真实数据（**非** PAPER_PLACEHOLDER）
- `plt.bar` + `plt.errorbar`（误差棒用 SD 列）
- 配色 hex 值 + 注释「取自 Okabe-Ito 色盲友好色板，Okabe & Ito 2008」
- 每段代码注释指明对应数据来源、配色色板
- 自检 `grep -iE "p\s*<\s*0\.|N\s*=\s*[0-9]+"` 0 命中
- `.paper/` 留痕（成句生成级·重、字段齐全：环节/辅助级别/图类=柱状图/工具库=matplotlib/配色=Okabe-Ito/数据来源=用户提供真实数据/用户决定=图类+工具库+是否采用/产物路径）

## 档 2：无数据占位生成散点图

**前置**：建 `.paper/`、`project.paper.yaml`（`discipline: 教育学`）、`manuscript/` 目录；无数据文件。

**用户台词序列**：

1. "/paper-plot 帮我画一张散点图，X 轴是学习时间、Y 轴是成绩。"
2. （skill 第 1 步检测无数据文件 + 问库："matplotlib / ggplot2 / 别的"）"ggplot2。"
3. （skill 第 2 步生成占位代码 + 陈列 + 停检查点）"落盘。"

**预期产物**：`manuscript/绘图代码_散点图.R`，含：
- 顶部声明「占位数据、需替换为真实数据。绝不编造看似真实的研究数据」
- `# PAPER_PLACEHOLDER: 替换为您的数据文件路径`
- `# PAPER_PLACEHOLDER: 替换为您的 X 轴列名`（如 study_time）
- `# PAPER_PLACEHOLDER: 替换为您的 Y 轴列名`（如 score）
- 占位符格式符合 spec §3.4 标准（`# PAPER_PLACEHOLDER: <描述>`）
- 配色 hex 值 + 注释「取自 Okabe-Ito 色盲友好色板，Okabe & Ito 2008」
- **不出现**任何口述数值（无「学习时间」「成绩」被硬编码为具体数值）
- 自检 `grep -iE "p\s*<\s*0\.|N\s*=\s*[0-9]+"` 0 命中
- `.paper/` 留痕（成句生成级·重、数据来源=显式占位符 PAPER_PLACEHOLDER）
