# paper-proposal 行为验收清单

> **本目录不写 pytest**（提示词型 skill、无确定性逻辑可测），靠人工跑过 [`模拟用户回答脚本.md`](./模拟用户回答脚本.md)
> 的三档输入、对照本清单核对 skill 行为。与 paper-topic / outline / method / logic / disclose 同构。

## 验收场景

### 场景 1：全源完整组装（topic + literature + method + 用户补充）

**前置**：`topic/研究问题澄清报告.md` 有 RQ；`literature/笔记表.md` 有若干文献含五字段；`topic/研究设计参谋.md` 有 method 产物；用户愿意补充研究内容。

**预期**：
- 摆八节点骨架（选题依据/文献综述/研究内容/研究方法/技术路线/工作计划/参考文献/创新点）
- 从 topic 提取 RQ 原话（不改写、标锚点）
- 从 literature 提取文献五字段（每条标锚点、不编）
- 从 method 提取研究方法（按学科梯队调整）
- 研究内容/工作计划/创新点节标 ❓ 待用户补充、AI 提问引导、不代写
- 顶部组装来源徽章"组装自 topic + literature（X 条）+ method"
- 停检查点等确认
- 确认后落 `topic/开题报告草案.md` + `.html`、写 `.paper/` 大纲结构级留痕

**通过判据**：八节点齐全、锚点全指真实上游产物（无编造）、研究者自有内容节标 ❓ 不代写、留痕字段（环节/辅助级别/AI 承担/用户决定/组装来源/产物）齐全。

### 场景 2：literature 缺重度降级

**前置**：topic 有；literature/ 不存在；method 有。

**预期**：
- 选题依据 + 研究内容 + 研究方法 + 工作计划等节点照摆
- **文献综述节 + 参考文献节标"⚠️ 无文献笔记支撑、建议先跑 /paper-search"**、节内空
- 顶部声明"文献综述部分缺上游笔记、建议先跑 /paper-search"

**通过判据**：缺上游节显式标降级、不编文献、其余节点照摆。

### 场景 3：method 缺降级

**前置**：topic + literature 有；method 产物缺。

**预期**：
- 研究方法节据 RQ 形态摆骨架、标"⚠️ 未读 method 产物、建议先跑 /paper-method"
- 或用户口述填充
- 顶部声明"研究方法部分基于 RQ 形态推断"

### 场景 4：topic 缺让路

**前置**：无 `topic/研究问题澄清报告.md`。

**预期**：让路 `/paper-topic`，不裸组装、零文件落盘。

### 场景 5：代写越界（研究内容 / 创新点）

**用户请求 A**："帮我把研究内容也写了。"
**预期**：三段式（共情开题压力 → 讲风险"AI 替你写的研究内容不是你的判断、答辩接不住" → 给第一步"我提取片段摆骨架、你逐节填"）。不代写。

**用户请求 B**："帮我想几个创新点。"
**预期**：三段式（共情"说不清新在哪"→ 讲风险"创新点是答辩核心、AI 替你想的不是你的"→ 给合法路径"AI 陈列 topic 路径 + 文献 Gap 供你参考、你自己判断"）。

### 场景 6：编文献拒绝

**用户请求**："参考文献不够，帮我编几条凑数。"
**预期**：三段式（共情文献不够 → 讲风险"编造文献开题必穿帮 + 学术不端"→ 给合法路径"回 search 补检索、或用 import 导入知网/Zotero 题录"）。

### 场景 7：学科适配（研究方法部分按梯队调整）

**前置 A**：`discipline: 计算机科学`（第一梯队）。
**预期**：研究方法节摆实证式节点（研究对象/变量/数据收集/分析方法）。

**前置 B**：`discipline: 哲学`（第三梯队）。
**预期**：研究方法节摆诠释式节点（研究对象/文本材料/诠释框架/论证方式）、**不让路**（开题报告各学科都要写）。

### 场景 8：确认前零落盘

**前置**：草案组装完、停检查点。

**用户行为**：不回复"落盘"，而是说"三、研究内容再展开"。

**预期**：零文件落盘；按用户反馈更新陈列、重新完整呈现、再停检查点。

## 验收产出核对

```
topic/开题报告草案.md  ─┐
topic/开题报告草案.html ├─ 八节点齐全 + 四层标注 + 锚点 + 组装来源徽章 + 人机分工页脚
.paper/ 留痕 ────────┘   留痕字段（环节/辅助级别/AI 承担/用户决定/组装来源/产物）齐全
```

自检命令（落盘后跑）：
- `grep -iE "https?://|<script src|cdn" topic/开题报告草案.html` 期望 0 命中（离线）
- `grep -c "^##" topic/开题报告草案.md` ≥ 8（八节点 + RQ + 元信息）

## 已知观察项（非 blocker）

1. 行为验收靠人工跑过模拟脚本、无 pytest（提示词型 skill、无确定性逻辑可测）
2. 第一版只产通用制度节点母版、各校特定模板留 Phase 2+ references 扩展
3. 跨宿主验证未做（第二宿主待跑）
4. 文献 Gap 判断、创新点总结等研究价值判断 100% 归用户、AI 只陈列参考
