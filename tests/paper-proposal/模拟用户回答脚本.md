# paper-proposal 模拟用户回答脚本（三档输入）

> 人工验收用：在真实宿主里贴下面对话的用户台词，对照 [`README.md`](./README.md) 验收场景
> 核对 skill 行为。三档覆盖全源完整 / literature 缺降级 / topic 缺让路。

---

## 档 1：全源完整组装（验收场景 1）

**前置准备**：

```
项目根/
├── project.paper.yaml   # discipline: 教育学; user_role: 硕士研究生
├── topic/
│   ├── 研究问题澄清报告.md  # 含 RQ
│   └── 研究设计参谋.md      # method 产物（用户拍板问卷调查）
└── literature/
    └── 笔记表.md            # 含若干文献 + 五字段
```

`topic/研究问题澄清报告.md` 的 RQ：
> 「ChatGPT 辅助写作对本科生论文写作效率的影响」

`literature/笔记表.md` 含：
> Smith 2023 · 研究问题=AI 工具与写作效率 · 方法=问卷调查 N=250 · 结论=正相关 · 不足=仅一所大学

**用户台词序列**：

1. "帮我组装开题报告。"
   - **预期**：读 topic RQ + literature 五字段 + method 产物 → 摆八节点骨架 → 选题依据/文献综述/研究方法从上游提取、研究内容/工作计划/创新点标 ❓ → 停检查点。
2. "研究内容我想分三个子问题：使用频率、感知效率、成绩变化。"
   - **预期**：更新第三节研究内容、重新完整呈现、再停检查点。
3. "工作计划时间我再想想，先落盘吧。"
   - **预期**：落 `topic/开题报告草案.md` + `.html`（工作计划节保留 ❓ 占位）、写留痕、交棒。

**预期产物字段**：
- 组装来源：topic（RQ）+ literature（X 条）+ method（有）
- 留痕辅助级别：大纲结构
- 留痕 AI 承担：制度节点骨架、上游片段提取、引导提问、产双产物
- 留痕用户决定：研究内容（三子问题）、工作计划、创新点、Gap 判断

## 档 2：literature 缺重度降级（验收场景 2）

**前置准备**：

```
项目根/
├── project.paper.yaml   # discipline: 计算机科学; user_role: 硕士研究生
├── topic/
│   └── 研究问题澄清报告.md  # 含 RQ
# 无 literature/ 目录、无 method 产物
```

RQ：
> 「大语言模型上下文窗口大小对代码生成准确率的影响」

**用户台词序列**：

1. "帮我组装开题报告。"
   - **预期**：读 topic RQ → literature 缺、method 缺 → 选题依据/研究内容/技术路线/工作计划节点照摆 → **文献综述节 + 参考文献节标"⚠️ 无文献笔记支撑、建议先跑 /paper-search"** → 研究方法节标"⚠️ 未读 method 产物"→ 顶部声明两处降级 → 停检查点。
2. "那我先去跑 search 补文献，这份草案先落盘留着。"
   - **预期**：落双产物（降级节保留 ⚠️ 占位）、写留痕（组装来源：topic 单、literature 缺、method 缺）、交棒（提示先回 search 补）。

**核对重点**：缺上游节显式标降级、不编文献、降级声明到位。

## 档 3：topic 缺让路（验收场景 4）

**前置准备**：空目录或无 `topic/研究问题澄清报告.md`。

**用户台词序列**：

1. "帮我组装开题报告。"
   - **预期**：检测 topic 缺 → 让路 `/paper-topic`，提示"topic 是 proposal 的必要输入、建议先聚焦 RQ"、不裸组装、零文件落盘。

**核对重点**：无 topic 时不进组装流程、零文件落盘、让路指向 topic。

## 档 3 变体：学科适配（验收场景 7）

**前置 A**：`discipline: 哲学`；topic RQ"庄子齐物思想的当代生态伦理意涵"；literature 有哲学文献。

**用户台词**：

1. "帮我组装开题报告。"
   - **预期**：学科判定第三梯队（哲学）→ 研究方法节摆**诠释式节点**（研究对象/文本材料/诠释框架/论证方式）、**不让路**（开题各学科都要写）→ 其余节点照摆 → 停检查点。

**核对重点**：哲学研究方法部分不套实证模板、用诠释式节点、不让路。
