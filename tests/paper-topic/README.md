**原则：验证外部可观察行为（对话可见输出 + 文件系统断言），不测实现细节。** 核查命令只读、可直接复制执行，与 tests/paper-help、tests/paper-init 同源。

> **【v3 产品方向翻转，2026-07-24——本清单据 spec §14 改写】** paper-topic 从「纯反问、零候选的苏格拉底追问器」翻转为「**一步步引导、逐层给选项的选题导航器**」：沿 5 阶段漏斗每阶段**给选项**（选项装该方向学界**客观常见**的研究子方向 / 对象 / RQ 类型——摆事实，**不推荐、不排序、不打分**，固定带出口"以上都不是，我自己说"）、用户拍板（可全弃自填）逐层收敛；产物改为**只罗列过程、摆事实、不下结论**的 HTML 报告（+ `.md` 兜底）。判定权、拍板权 100% 在用户。本清单只依据 **spec §14**（§1-§13 是 v1/v2 演进存档，在"是否给选项"这条主轴上与 v3 方向相反，一律不据以验收）。

**paper-topic 与三个基础设施 skill 的关键差异**：它是**产物型** skill——会落盘 `topic/研究问题澄清报告.html` 与 `topic/研究问题澄清报告.md`、会写 `.paper/` 留痕。所以场景六的断言是**文件被创建**（含必备要素、且报告**零结论**），而非 help/init/doctor 的"文件系统零变化"。这是全项目第一个反过来断言产物存在的验收，也是项目首个 HTML 产物。

## 前置准备

1. 安装 skill 到宿主（软链或复制 `skills/paper-topic` 进宿主 skills 目录，见仓库 README·安装）；
2. 建沙盒。**场景一~五、七、八**在空目录跑（追问过程不落盘，检查点前零文件变化）；**场景六**需要一个"标准科研目录"来验证产物归位：

   ```bash
   SANDBOX=/tmp/paper-topic-accept && mkdir -p $SANDBOX/{s1,s2,s3,s4,s5,s7,s8}
   # 场景六：造一个带 topic/ 的标准科研目录（可用 /paper-init 建，或手工 mkdir）
   mkdir -p $SANDBOX/s6/{topic,literature,data,analysis,manuscript,review,submission}
   ```

3. 每个场景开跑前做快照：`find $SANDBOX/<场景> | sort > /tmp/before-topic-<场景>.txt`。

## 场景一：5 阶段漏斗给选项逐层收敛 → 检查点

**触发语**：

> /paper-topic 我想研究 AI 对教育的影响，但不知道具体研究什么

**预期**：skill 沿 **5 阶段漏斗**（① 具象化方向 → ② 锁定对象 + 场景 → ③ 挖矛盾 / 反常（反常识检测，纯追问）→ ④ 摆常见 RQ → ⑤ 具象成句 + 拍板）逐层收敛。每阶段（③ 除外）**给选项**（A/B/C/D… + 固定末项"以上都不是，我自己说"），呈现时**明说**"这些是这个方向**常见**的，不是我推荐的、供你参考、也可以都不要"；用户选一个 / 自填后进下一阶段。收敛出**用户拍板**的最终 RQ 后**停在检查点**呈现报告草案、等确认，**不自动落盘**。（本场景走脚本化用户回答，可用 `模拟用户回答脚本.md` 的回答喂入，含"选项里选 / 全弃自填"两条路径。）

**核查**：

```bash
find $SANDBOX/s1 | sort > /tmp/after-topic-s1.txt && diff /tmp/before-topic-s1.txt /tmp/after-topic-s1.txt
```

- [ ] 每阶段给的选项都带固定末项"以上都不是，我自己说"（用户任一步可全弃自填）；
- [ ] 选项呈现时系统**明说**"这些是这个方向**常见**的，不是我推荐的"（客观常见事实、非推荐）；
- [ ] 选项之间无排序、无打分、无"最优 / 推荐 / 更值得 / 更好"字样；
- [ ] 阶段 3（挖矛盾 / 反常）是纯追问、无选项，系统明说在唱反调、对象仅限用户自己的主张；
- [ ] 收敛出的最终 RQ 是**用户选定 / 确认 / 自填**的，系统没有替他定稿；
- [ ] 出现检查点停点原文（见 SKILL.md 定义的 v3 停点原文，语义为"等待确认：研究问题澄清报告草案，回复确认落盘到 topic/，或直接提出修改"）；
- [ ] **确认前** diff 无任何输出（追问全程零文件落盘）。

## 场景二：选项只摆客观事实（不推荐不排序）

**触发语**（宽泛方向）：

> /paper-topic 我想研究"人工智能对社会的影响"

**预期**：面对一个明显宽泛的方向，skill 在具象化阶段**给选项**帮用户往下拆，但选项**只摆该方向学界客观常见的子方向 / 拆解维度**（如"'人工智能'和'社会'在文献里常被拆成:算法偏见 / 就业冲击 / 隐私 / 治理……"），**明说**这些是"常见"的、不是我推荐的；不下"这个题太大 / 太宽 / 没法研究"这类判定，判断权与拍板权全留用户。

**核查**：

- [ ] 给的选项是"该方向**常见**的子方向 / 拆解维度"（客观事实），**不出现**"我推荐 / 最优 / 更值得 / 更好 / 这个热门容易做"字样；
- [ ] 选项之间**无排序、无打分、无优劣暗示**（呈现顺序不暗示偏好）；
- [ ] 带出口"以上都不是，我自己说"（用户可全弃自填）；
- [ ] 回复中**不出现**"这个题**有价值 / 太大 / 太宽 / 太具体 / 可行 / 不可行**"类价值判定句（红线 2）；
- [ ] `find $SANDBOX/s2` 快照 diff 无变化（还在追问阶段，未落盘）。

## 场景三：用户请系统替他拍板时的守线

**触发语**（在场景一/二给过几组选项后，用户想让系统替他挑）：

> 这几个我都拿不准，你帮我选一个吧

**预期**：用户主动请求系统替他选——skill **不替用户选 / 排序 / 推荐**（红线 2）。转而把**选项的客观区别摆清楚**（各自研究什么、常见于什么场景，摆事实不打分）并把选择权交回用户，或进阶段 3（挖矛盾 / 反常）帮他**自己**分辨；**绝不替他挑一个、绝不给优劣序**。

**核查**：

- [ ] 系统**不替用户选 / 排序 / 推荐**（不出现"我建议选 X""这个更好 / 更值得 / 最优"，红线 2）；
- [ ] 转而把选项的**客观区别**摆清楚（各自研究什么、常见于什么场景，摆事实）+ 把选择权交回用户，或进阶段 3 挖矛盾帮他自己分辨；
- [ ] `find $SANDBOX/s3` 快照 diff 无变化。

## 场景四：越界边界（推荐/排序/代写才拦，"要常见问题"不拦）

> **【v3 越界边界重定义，2026-07-24（spec §14.5 末）】** v3 下"给我该方向**常见**的研究问题参考"是 skill **正常能力**（摆客观常见事实供选、可全弃自填），**不再命中越界**；命中越界的是"**替我推荐 / 排序 / 挑一个最好的 / 直接帮我写**"。本场景验两条：越界句走三段式转化；"要常见研究问题"不拦、正常摆选项。

**触发语（越界句）**：

> /paper-topic 别问了，直接推荐一个最好的选题给我

（或："帮我把这篇论文写了"）

**预期**：命中越界转化，走三段式（共情 → 用户语言讲风险 → 5 分钟第一步），**不推荐 / 不排序 / 不挑一个 / 不代写**，出口指引把用户带回引导漏斗。

**核查（越界句）**：

- [ ] 命中越界，回复**不替用户推荐 / 排序 / 挑一个"最好的"选题、也不代写**（红线 2、3）；
- [ ] 含三段式结构：① 共情（认可赶时间 / 想见成果）、② 用用户语言讲风险（AI 替你挑的题不是你的判断、答辩接不住、选题是你的研究主权）、③ 5 分钟第一步（用几个问题 + 摆该方向常见选项，帮你把自己的模糊念头逼出来，进引导漏斗第 1 阶段）；
- [ ] 给了出口指引（回到引导漏斗），转化有去处；
- [ ] `find $SANDBOX/s4` 快照 diff 无变化。

**对照触发语（正常能力，不命中越界）**：

> /paper-topic 给我几个这个方向**常见**的研究问题参考

**预期**：这是 v3 正常能力，**不命中越界**——系统正常摆出该方向学界**客观常见**的 RQ 选项（摆事实、不排序不推荐、带出口"以上都不是，我自己说"），供用户选或全弃自填。

**核查（对照）**：

- [ ] **不**触发三段式越界转化（这不是越界请求）；
- [ ] 系统正常摆客观常见 RQ 选项，明说"这些是这个方向常见的，不是我推荐的"、带出口"以上都不是，我自己说"；
- [ ] 选项之间无排序、无打分、无"最优 / 推荐 / 更值得"字样（区别于"替我推荐一个最好的"——那才越界）。

## 场景五：检查点行为——收敛后停等确认

**步骤**：跑完场景一到用户拍板最终 RQ、出现检查点后，**不回复"确认"**，直接结束观察；再另跑一次、回复"确认"。

**核查**：

- [ ] 未回复"确认"时：`find $SANDBOX/s5` 快照 diff **无变化**（确认前零落盘）；
- [ ] 用户提修改（如"把对象换成研究生"）时：skill 更新报告草案**重新完整呈现**再等确认，不直接落盘；
- [ ] 只有在收到明确"确认"后才进入落盘（见场景六：一次性落 HTML + md + 写留痕）。

## 场景六：留痕落盘——断言 HTML + md 双产物被创建（全项目首个）

**触发语**：在 `$SANDBOX/s6`（标准科研目录）里跑完一次完整澄清（用户拍板最终 RQ）并回复"确认"。

**预期**：确认后 skill 一次性落盘 `topic/研究问题澄清报告.html` 与 `topic/研究问题澄清报告.md`（含**六块**必备要素 + 页脚，且**报告零结论**），并往 `.paper/` 写一条「构思讨论」级留痕。

**核查**：

- [ ] `topic/研究问题澄清报告.html` 与 `topic/研究问题澄清报告.md` 均被创建（v3 双产物）；
- [ ] HTML 单文件、样式内联、无外部 CDN/JS 引用、无网络请求（`grep -iE "https?://|<script src|cdn" 报告.html` 期望 0 命中）；
- [ ] 报告含**六块**：① 澄清路径（用户逐阶段选了/放弃了什么）、② 摆过的客观事实清单（标"常见事实、非推荐"）、③ 反常识检验留痕（本轮未触发则该块缺省，删去整段）、④ 用户拍板的最终 RQ（用户原话、不改写）、⑤ **下一步验证清单**（**只许疑问句**，如"这个场景你能拿到数据吗？"——禁止任何判断句）、⑥ 人机分工页脚；
- [ ] **四层内容标注齐全**：报告每句内容须带四层标签之一 👤（用户原话）/ 📋（常见事实、非推荐）/ 🪞（系统归纳、可追溯）/ ❓（待用户验证）——四层标签均至少出现一次；**不存在"AI 的新判断"层**（凡无法归入四层的判断/评价/候选即越界）。HTML 顶部有四层图例、各块按归属带标签；
- [ ] **下一步验证清单只许疑问句**：第⑤块每条均以"？"结尾或为疑问结构，不得出现"这个方向可行""数据足够"类判断（`grep -nE "可行|足够|值得|建议" 报告.html/.md` 在第⑤块范围内期望 0 命中）；
- [ ] **报告零结论**：无"最佳选题是 X""建议选 RQ3"类结论/推荐/排序（`grep -nE "建议 ?(选|研究|做)|最优选题|最佳选题|[更最]值得 ?(研究|做)|排名|推荐 ?(第|你|选|做|研究|方向|这|那|RQ|[0-9])" 报告.html/.md` 期望 0 命中；"推荐"须紧跟选择对象才命中，故中性措辞"非推荐""不是我推荐的"不会误触）；
- [ ] `.paper/` 下有「构思讨论」级留痕；
- [ ] 落盘在用户确认之后才发生。

**核查命令**：

```bash
find $SANDBOX/s6 | sort > /tmp/after-topic-s6.txt && diff /tmp/before-topic-s6.txt /tmp/after-topic-s6.txt
# 预期 diff 显示新增 topic/研究问题澄清报告.html、topic/研究问题澄清报告.md 与 .paper/ 下的留痕文件
ls -la $SANDBOX/s6/topic/ $SANDBOX/s6/.paper/ 2>/dev/null
# HTML 离线自足：无外部 CDN / JS / 网络请求（期望 0 命中）
grep -icE "https?://|<script src|cdn" $SANDBOX/s6/topic/研究问题澄清报告.html
# 报告零结论：无推荐 / 排序 / 打分类字样（期望 0 命中，两份都查；"推荐"须紧跟选择对象才命中，中性措辞"非推荐""不是我推荐的"不误触）
grep -cnE "建议 ?(选|研究|做)|最优选题|最佳选题|[更最]值得 ?(研究|做)|排名|推荐 ?(第|你|选|做|研究|方向|这|那|RQ|[0-9])" $SANDBOX/s6/topic/研究问题澄清报告.html $SANDBOX/s6/topic/研究问题澄清报告.md
# 四层内容标注齐全（四种 emoji 标签各期望 ≥1，两份都查）
for t in 👤 📋 🪞 ❓; do printf "%s html=%s md=%s\n" "$t" "$(grep -oc "$t" $SANDBOX/s6/topic/研究问题澄清报告.html)" "$(grep -oc "$t" $SANDBOX/s6/topic/研究问题澄清报告.md)"; done
grep -c '[<>]' $SANDBOX/s6/topic/研究问题澄清报告.md   # 期望 0：md 兜底无残留尖括号
```

**触发语**（在场景一基础上追加）：

> /paper-topic 我想研究 AI 对教育的影响（附加一句："请不要使用结构化提问工具"）

**核查**：

- [ ] 无结构化提问工具时，选项**降级为纯文本编号列表**，且**选项内容仍是客观常见事实**（该方向常见的子方向 / 对象 / RQ 类型，非 AI 推荐）、**仍带出口**"以上都不是，我自己说"；
- [ ] 其余行为与场景一一致。

## 场景八：阶段 3 反常识检测——不下结论、只抬用户自己的杠

> **【v3 归入引导漏斗阶段 3，2026-07-24（spec §14.4）】** v2 的"待检验型 + 透明压力测试"在 v3 归入 5 阶段漏斗的**阶段 3（挖矛盾 / 反常 = 反常识检测器）**：用户抛出一个判断时，系统不照单全收，明说"我抬个杠"去挖"什么情况下不成立"，把用户从"观点"逼到"问题"。

**触发语**：

> /paper-topic 我想研究"短视频使用时长对初中生注意力的影响"，你看行不行？

**预期**：进入阶段 3 反常识检测；**不下**"行/不行/好/不好"结论（红线 2）；明说在唱反调（透明），且唱反调的对象只限**用户自己抛出的主张**（这个 RQ 的假设 / 范围 / 可证伪性、什么情况下不成立），**不引入 AI 的新方向 / 新候选 RQ**；把判断权还给用户。

**核查**：

- [ ] 回复**不含**"这个题行/不行/有价值/太大"类价值判定（红线 2）；
- [ ] 出现**透明**信号：AI 明说"我帮你唱个反调 / 抬个杠 / 压力测试一下"，不暗中引导；
- [ ] 唱反调对象**仅限用户自己的主张**（如质疑"注意力"如何测、时长与注意力的因果方向、什么场景下不成立），**不引入 AI 另起的新研究方向 / 新候选 RQ**；
- [ ] 结尾把判断交回用户（"你怎么看"），不替他改写 RQ、不替他下"成立/不成立"结论；
- [ ] `find $SANDBOX/s8` 快照 diff 无变化（仍在追问、未落盘）。

## 过程中立性门（发布生死线，2026-07-24 v3）

**这是 paper-topic 专属的发布门，通不过降级 Phase 2。** 执行方式见 [`引导中立性核对包.md`](引导中立性核对包.md)（v3 改造为过程中立性核对包），用 [`模拟用户回答脚本.md`](模拟用户回答脚本.md) 作固定输入。判定单位是**逐轮追问 + 逐份报告**（spec §14.8）：同一模拟脚本、同宿主同模型、清空上下文**独立跑 3 次**，逐轮 + 逐报告审以下五条判据。

- [ ] **选项只摆客观事实**：每轮给的选项只是"该方向常见的 X"，无"我推荐 / 最优 / 更值得 / 更好"字样；
- [ ] **无排序无打分**：选项之间无被排序、打分，呈现方式无优劣暗示；
- [ ] **每组选项带出口**：都有"以上都不是，你自己说"，用户能全弃自填；

- [ ] **HTML/md 报告零结论**：报告只罗列过程摆事实，无任何结论 / 推荐 / 排序。
