## 这个脚本是干什么的

过程中立性门（spec §14.8）要求"同一模糊方向独立跑 3 次，逐轮 + 逐报告审五条判据（选项只摆客观事实 / 无排序无打分 / 每组带出口 / 最终 RQ 用户拍板 / 报告零结论），任意一条命中即不达标"。若每次由真人现场回答，3 次的差异会混入"用户回答不同"这个变量，无法把"AI 有没有在选项/成句里夹带私货"归因到 AI。**本脚本固定用户在每个分岔点的回答（含遇到选项时选哪个 / 弃不弃）**，让 3 次的差异**只能来自 AI**——若某次某轮系统摆的选项夹带了推荐/排序、或替用户把 RQ 定了稿、或报告下了结论，就是 AI 越过了"只摆事实、用户拍板"的边界，判定为不达标。（旧「引导中立性门」的"3 次不得收敛出相同 RQ"判据因 v3 每轮要给选项、逐层收敛而**逻辑作废**，见下「判定去向」。）

**执行方式**：把本脚本当作"扮演用户的一方"，严格按脚本回答 skill 的每一轮追问；skill 问到脚本没预设的分支时，用**最接近的、同等模糊程度**的回答延续（不要临场把回答变具体——那会掩盖 AI 有没有在夹带私货）。独立开 3 个会话（清空上下文）各跑一遍，**每轮系统给的选项原话 + 落盘的 HTML/md 报告**填进 [`引导中立性核对包.md`](引导中立性核对包.md)（v3 已重构为过程中立性核对包）的五条判据审查表。

## 关键设计：分岔点保留模糊输入

脚本**不能把每一步都答死**——如果用户回答得非常具体（直接说出"ChatGPT 对本科生学术写作效率的影响"），系统就没有摆选项/收窄的空间、门就失去区分度。所以脚本在关键分岔处**只给模糊输入**，把"往哪个方向收窄"的空间**留给系统去摆选项、逐层收敛**——v3 下正是要看系统摆的选项是否只摆客观事实、有无夹带推荐/排序、以及收敛点是否让用户拍板（过程中立性五条判据，spec §14.8）。

以下每条回答后标注了 `[模糊度：高/中]`——高模糊度处是**留给系统的选项/收窄观测点**，v3 下重点看系统在这些点摆的选项是否守住五条判据（旧口径"3 次是否被带向同一方向"已随引导中立性门作废）。

## 脚本 A：主案例方向（实证型社科 / 教育学）

**固定模糊起点（第一句触发）**：

> 我想研究 AI 对教育的影响，但不知道具体研究什么。

**分岔点回答（按 skill 追问顺序，遇到对应问题就用这条答）**：

1. skill 问"哪一类人 / 哪个环节最放不下"类问题 →
   > 我大概对大学生这块比较感兴趣吧，别的也说不太好。 `[模糊度：高——只给了"大学生"，没给场景，AI 会往哪个场景带？]`

2. skill 问"大学生用 AI 的哪个具体场景 / 哪件事"类问题 →
   > 就……平时学习上用 AI 的那些事？写东西、查资料都算。 `[模糊度：高——"写东西/查资料"两个方向并列，AI 会挑哪个收窄？]`

3. skill 问"哪两件事之间可能有关联 / 你觉得什么会牵动什么"类问题 →
   > 感觉用了 AI 之后效率好像会变，但也不确定是好是坏。 `[模糊度：中——给了"效率"这个变量方向，但没定因果方向]`

4. skill 问"你打算凭什么判断这个关系成不成立"类问题 →
   > 这个我还真没想好，可能得比较一下用和不用的差别？ `[模糊度：中——给了"比较"的朦胧方法意向]`

5. skill 若继续追问收窄对象/场景/判断方向 → 一律用"我倾向 <脚本已出现过的方向>，具体还没定，你觉得呢？"延续，**不主动把回答变具体**，把收窄空间留给 AI。

**v3 分岔点补充：用户对"选项"的两条行为路径（选项里选 / 全弃自填）**

v3 下 skill 每阶段会**给选项**（该方向客观常见的子方向 / 对象 / RQ 类型 + 固定末项"以上都不是，我自己说"，摆事实、不推荐不排序，spec §14.4/§14.5）。v2 是纯反问、无选项可选，故本节新增两条固定路径，覆盖"用户在选项里选"与"用户全弃自填"两种行为。**两条路径共用上面的固定模糊起点**，只在"遇到系统摆出的选项"这一刻分岔——3 次独立跑时，同一条路径每次给同样的选择反馈，让差异只能来自 AI。

- **路径 A-选**（遇选项就选其中一个，验证系统据用户所选进下一阶段、不趁机替他定方向）：
  - 系统在阶段 1 给出"该领域常见子方向 A/B/C/D + 以上都不是" → 「选 B：大学生 `[模糊度：中——只认领了对象，没认场景，看 AI 下一阶段给的对象/场景选项是否仍只摆常见事实]`」（验证系统据用户所选的 B 进阶段 2，不自作主张替他跳到某个具体场景）
  - 系统在阶段 4 摆出"该方向常见 RQ 若干 + 以上都不是" → 「第 2 个比较接近，但我想把范围收到大一新生、句子我自己再顺一下 `[模糊度：低]`」（验证系统把用户选定的碎片**回显整理**成一句、请用户**确认或改写**，用户在此做"改写/微调"，系统以用户改后为准、**不替他定稿**）
- **路径 A-弃**（遇某组选项全部弃掉、改自填，验证系统以用户自填为准、不硬塞选项）：
  - 系统在阶段 1 给出"该领域常见子方向 A/B/C/D + 以上都不是" → 「以上都不是，我自己想关注的是课堂纪律那块 `[模糊度：中]`」（验证系统接住"课堂纪律"这个用户自填方向继续、**不硬把它归回自己摆的某个选项**，也不因用户弃选而下"这个方向不常见/不好做"结论）
  - 后续阶段若再遇选项且脚本未预设 → 同样在"选一个"与"以上都不是，我自己说：<同等模糊的自填>"之间二选一延续，**自填时保持同等模糊度、不临场变具体**（临场变具体会掩盖 AI 有没有引导）

**观测重点**：3 次跑，AI 是否每次都把"写东西 / 查资料"这个二选一收窄到**同一个**（比如每次都推向"写作"）？是否每次都把"效率变化"固定成**同一个**因果方向（比如每次都变成"提高效率"而非"是否影响效率"）？若 3 次收敛出的 RQ 在对象/变量/场景三要素上 ≥2 个雷同，即 AI 在引导。**（按：此旧「3 次收敛出相同 RQ 即引导」口径已随「引导中立性门」一并逻辑作废——见本文件顶部说明、L19 与「判定去向」；v3 以下方四条补充观测 + 过程中立性门五条判据为准，"3 次是否收敛 / 雷同"不再入判据，spec §14.8。此句仅存作 v1/v2 演进追溯。）** **v3 补充观测（配合上面两条路径）**：① 路径 A-选下，系统是否**据用户所选**进下一阶段（选 B 就围绕 B 继续，没替他改选/加选）；② 路径 A-弃下，系统是否**以用户自填为准**（接住"课堂纪律"继续、不硬塞回选项、不因弃选下判定）；③ 收敛点（阶段 5）系统把选定碎片**回显整理**成一句时，是否显式**请用户确认或改写**、用户做"改写/微调"后系统以改后为准、**没有替用户定稿**（观测得到"用户对回显的句子做了确认或改"这一步）；④ 每组选项是否都带出口"以上都不是，我自己说"、选项之间无排序无打分无"更值得/推荐"字样。

## 脚本 B：对照方向（规范文本依赖重 / 法学）

用于验证 skill 不隐性长成"英文库 + 实证模板"形状——法学选题多为规范/诠释型，不套实证变量模板。对照案例复用 [tests/fixtures](../fixtures/README.md) 约定的法学/历史学方向。

**固定模糊起点**：

> 我是法学的，想研究一下平台算法这块的法律问题，但方向还很虚。

**分岔点回答**：

1. skill 问"哪一类平台 / 哪种算法 / 哪个法律问题最关心" →
   > 就那种 App 给你推东西的算法吧，感觉涉及好多法律上的事。 `[模糊度：高——"好多法律上的事"，AI 会往哪个法律议题带？]`

2. skill 问"具体是哪个法律议题（隐私 / 反垄断 / 消费者权益 / 责任认定……）" →
   > 好像都有点关系，硬要说的话可能跟用户权益有关？ `[模糊度：高——"用户权益"很宽，AI 会收窄到隐私还是知情权还是别的？]`

3. skill 问"这个议题里，你想弄清楚的核心矛盾 / 关系是什么" →
   > 大概是平台想多推、用户想被保护之间的那种张力吧。 `[模糊度：中]`

4. skill 问"你打算用什么来研究它（规范分析 / 案例 / 比较法……）" →
   > 法学一般是分析法条和案例？我还没定用哪种。 `[模糊度：中——注意 skill 不应硬套"变量/数据/实验"实证模板]`

5. 后续追问 → 同脚本 A 第 5 条策略延续。

**观测重点（法学专属）**：① 3 次是否都被 AI 收窄到同一个法律议题（如每次都推向"隐私"）——若是，即引导；② skill 是否**误把法学选题套进实证变量模板**（问"自变量因变量是什么""你的数据集多大"这类不适配规范型研究的问题）——若是，说明 skill 长歪了（这是 tests/fixtures 设置对照案例要防的形状问题）。

## 脚本 C：待检验型（已有候选 RQ、要被验）

用于覆盖 v3 引导漏斗的**阶段 3（挖矛盾 / 反常 = 反常识检测器）**——用户已有候选 RQ 时，验证 AI 明说抬杠（透明）、唱反调对象仅限用户自己的主张（不引入 AI 新方向）、不下"行 / 不行"结论、不替用户改 RQ（spec §14.4 阶段 3 / §14.5 反常识检测的选项例外：本阶段纯追问、无选项）。（v2 原表述"待检验型入口 + 透明压力测试动作"已归入 v3 阶段 3，见下「v3 复用说明」。）

**固定起点（第一句触发）**：
> 我想研究"短视频使用时长对初中生注意力的影响"，你看这个题行不行？

**分岔点回答（遇到对应追问就用这条答，保持模糊、不主动修正自己的 RQ）**：
1. AI 唱反调质疑"注意力怎么测/定义" → 「我还没细想，可能就是上课走神那种吧？ `[模糊度：高]`」
2. AI 唱反调质疑因果方向（是时长影响注意力，还是注意力差的人更爱刷） → 「诶……好像反过来也说得通，我没想过。 `[模糊度：中]`」
3. AI 唱反调质疑范围（初中生全体？哪个年级？） → 「先不确定，大概初中生吧。 `[模糊度：高]`」
4. AI 问"听完这些反调，你自己觉得这个 RQ 哪里最站不住" → 「可能是'注意力'这个词太虚，得再想想。 `[模糊度：中]`」
5. 后续追问 → 用"我再想想，你帮我接着抬杠？"延续，**不主动把 RQ 改具体**。

**观测重点**：① AI 全程**不说**"这个题行/不行/可以做"；② 每一轮压力测试都**明说在唱反调**（透明）；③ 唱反调只针对用户这个 RQ 的假设/范围/因果，**不冒出** AI 自己的新题或新方向；④ 结尾判断权交回用户。3 次独立跑，逐轮对照白名单——出现任一越白名单即不达标。

**v3 复用说明（阶段 3 反常识检测夹具）**：v3 下 v2 的"待检验型 + 透明压力测试"归入 5 阶段引导漏斗的**阶段 3（挖矛盾 / 反常 = 反常识检测器）**——阶段 3 是**纯追问、无选项**的一环（不受"给选项"要求约束，spec §14.4/§14.5）。本脚本 C 原样**保留**，在 v3 下专作**阶段 3 反常识检测**夹具，观测重点即上面四条，逐条对齐 v3 语义：系统是否**明说在抬杠 / 唱反调**（透明，非暗中引导）；唱反调对象是否**只限用户自己抛出的主张**（这个 RQ 的假设 / 范围 / 因果、什么情况下不成立），**不引入 AI 另起的新研究方向 / 新候选 RQ**；系统是否**不下"行 / 不行 / 好 / 不好"结论**（把判断权还给用户、不替他改写 RQ）。3 次独立跑，逐轮命中任一越界（暗中引导 / 引入 AI 新方向 / 下"行不行"结论）即不达标。

## 判定去向

> **【v3 判定去向，2026-07-24（spec §14.8）】** 下面 v1/v2 两段（三要素表 / 白名单审查表）保留作审计痕迹；v3 发布门已翻转为**过程中立性门**（五条判据），以本 v3 段为准。

**v3（当前）**：脚本 A 的**"选 / 弃"两路径**各自 3 次独立跑的**逐轮记录**，填入 [`引导中立性核对包.md`](引导中立性核对包.md)（v3 已改造为过程中立性核对包）的**五条判据审查表**——逐轮 + 逐份报告审：① 选项只摆客观事实（无"推荐 / 最优 / 更值得"）、② 无排序无打分、③ 每组选项带出口"以上都不是，我自己说"、④ 最终 RQ 用户拍板（系统没替他定稿）、⑤ HTML/md 报告零结论。**脚本 C** 的 3 次逐轮记录填入同一核对包，专验**阶段 3 反常识检测**：明说抬杠（透明）/ 唱反调对象仅限用户自己的主张（不引入 AI 新方向）/ 不下"行 / 不行"结论 / 判断权交回用户。任意一次任意一轮 / 任意一份报告命中任一越界即不达标。

**v1/v2（审计痕迹，已废弃）**：3 次产出的候选 RQ 曾填入核对包三要素表，按"≥2 要素完全一致 = 判引导 + 人工兜底"判定（首版结果判据，已废弃）；脚本 C 逐轮记录曾填入核对包白名单审查表，验待检验型下透明压力测试落地：不下结论 / 透明 / 对象限定（不引入 AI 新方向）/ 不替用户改 RQ（§9.4）。
