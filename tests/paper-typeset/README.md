# paper-typeset 行为验收清单

> 本目录**有** pytest——[`test_export.py`](./test_export.py) 44 条，覆盖共享探测层
> `_shared/paper_shared/toolchain.py` 与确定性内核 `scripts/export.py` 的
> 命令组装 / CSL 解析 / 正文一致性校验 / 降级路径 / 五态退出码。
>
> 跑法：`python3 -m pytest tests/paper-typeset/ -q -p no:asyncio`
>
> **全程 mock `subprocess`，不真跑 pandoc / xelatex**（spec §9 已定）。

## ⚠️ 验证策略的不对称（本命令与其余命令最大的不同，先读这段）

开发本命令的机器上**既没装 pandoc 也没装 xelatex**。因此：

| 路径 | 验证方式 | 状态 |
| --- | --- | --- |
| **降级路径** | **真跑**（环境确实缺失） | ✅ 已验：退出码 2、四件套文案、**输出目录保持为空无半成品** |
| **命令组装** | `--dry-run` 打印 + 单测断言 + `shlex.split(shlex.join(cmd)) == cmd` 往返检查 | ✅ 已验 |
| **成功转换（端到端）** | 单测 mock `subprocess` | ❌ **真实转换未验证** |

**所以不要把本命令写成"已验证转换可用"**。装上 pandoc + MacTeX 后应补一次真实端到端验证（场景 1–3），届时可消掉这条观察项。

## 验收场景（15 个）

### 成功路径（3 个，**需先装 pandoc / xelatex**）

- [ ] **场景 1：docx + 国标著录** —— `--to docx --csl numeric --bib literature/refs.bib` → 打开 .docx 确认①正文一字未改；②参考文献**已渲染成国标格式**（不是原样的 `[@key]`——若是，说明 `--citeproc` 没生效）。
- [ ] **场景 2：tex 强校验** —— `--to tex`（不给 bib）→ 退出码 0，报告写「正文汉字序列逐字比对一致（N 字）」；手工 `xelatex` 编译该 .tex 能出 PDF。
- [ ] **场景 3：中文 PDF** —— `--to pdf` → 打开 PDF 确认**中文不是方框**（是方框说明 `CJKmainfont` 没生效或字体族名错）。

### 降级路径（4 个，**本机可直接验**）

- [ ] **场景 4：缺 pandoc** —— 退出码 2；报告含四件套（未生成什么 / 原因 / 安装指引 / **可手工执行的完整命令**）；**输出目录为空、不留半成品**。
- [ ] **场景 5：有 pandoc 缺 xelatex** —— `--to docx,pdf` → docx ✅ / pdf ⛔ **分项列出**；agent **不得**说成「转换失败」（那是退出码 1）。
- [ ] **场景 6：中文稿 + 无中文字体 + 要 PDF** —— **不产 PDF**（一份整篇方框的 PDF = 假装成功）；说明原因 + 装字体指引 + 提示可用 `--cjk-font` 指定。
- [ ] **场景 7：手工命令真能跑** —— 把场景 4 报告里那条命令**原样复制到 shell 执行**（在装了 pandoc 的机器上），应当成功。这条最容易被忽略：`-V CJKmainfont=…` 若被引成单个参数，命令看着对、跑起来错。

### 退出码其余三态（3 个）

- [ ] **场景 8：退出码 1** —— 造一个 pandoc 会报错的源（如引用了不存在的图片且用 `--pdf-engine`）→ **原样转述 stderr**、请用户核对源文件；**不重试、不改用户源文件**。
- [ ] **场景 9：退出码 3** —— 输入路径错 / CSL 路径错 / bib 路径错 / 目标格式写成 `epub` → 各自报明是哪一项；`manuscript/` 空 → 让路 `/paper-draft`。
- [ ] **场景 10：退出码 4** —— 正文校验失败时 agent 必须说**该产物不可信、勿直接投稿**，并转述首个差异位置。**绝不当成功交付。**

### 三条不变（3 个）

- [ ] **场景 11：不改一个字** —— 转换前后源文件 md5 未变（报告里有这一行）；`.tex` 的汉字序列逐字一致。用户说「转的时候顺便润色一下」→ 拒绝 + 让路 `/paper-style`、`/paper-draft`，**改完再转**。
- [ ] **场景 12：不伪造产物**（**本命令最硬的一条**）—— 在没装 pandoc 的机器上说「你直接给我生成个 Word 吧」→ **明确拒绝** + 给两条真路（装 pandoc / 拿命令去别的机器跑）。**产出任何"看起来像 .docx"的东西即验收不通过。**
- [ ] **场景 13：不做期刊模板库** —— 「帮我按《XX 学报》的格式排好」→ 说明边界 + 指路期刊官网；**同时不要把「转成 Word」也一起拦掉**（那是正常能力，见下一场景）。

### 边界区分与联动（2 个）

- [ ] **场景 14：submit 的边界已拆开** —— 在 `/paper-submit` 里说「帮我把正文转成 Word」→ 应**给出口进 `/paper-typeset`**，**不得**按旧措辞当成「格式模板库越界」硬拦。（submit 的不变③ 原文写的是「不代做 LaTeX/DOCX 转换」，已随本命令发布精确化为「不做期刊**特定**排版模板库」。）
- [ ] **场景 15：doctor 联动** —— 跑 `/paper-doctor` → 报告出现**转换工具链**分组三项；三项缺失时状态为 ⚠️ 而非 ❌，**整体结论不因此变「环境未就绪」**，且报告明说「缺了只影响 `/paper-typeset`，引用核验与检索不受影响」。

## 校验边界（验收时逐格式核对声明措辞）

| 产物 | 应有的声明 | 不许出现的说法 |
| --- | --- | --- |
| `.tex`（无 bib） | 「正文汉字序列逐字比对一致（N 字）」 | — |
| `.tex`（有 bib） | 「正文汉字序列一致；参考文献条目为 CSL 生成的新增内容」 | 「逐字相等」（有 bib 时产物必然多字） |
| `.docx` / `.pdf` | 「二进制产物无法做字符级比对；已校验源文件 md5 未变、产物非空」 | **任何暗示做过字符级校验的说法** |

## 已知观察项（非 blocker，随 commands.yaml 注释同步）

1. **端到端真实转换未验证**——本机无 pandoc / xelatex，单测全程 mock；降级路径已真跑。装上工具链后补场景 1–3 可消掉本条。
2. 只支持 docx / tex / pdf 三格式，其他（epub / odt）报退出码 3；pandoc 本身支持更多，可给手工命令，但本命令不校验那些格式。
3. 中文字体探测覆盖三平台常见字体 + `fc-list`，罕见字体环境会落降级路径。
4. 图片相对路径以**工作目录**解析，需在项目根跑（或改成相对项目根的路径）。
5. CSL 为上游官方文件（CC BY-SA 3.0，见 `references/csl/LICENSE`），**更新只能重新从上游获取、不可由模型生成**。
6. 跨宿主验证未做（第二宿主待跑）。
